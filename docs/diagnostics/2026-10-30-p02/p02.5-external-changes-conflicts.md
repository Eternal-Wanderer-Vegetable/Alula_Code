# P02.5 外部变更、冲突、只读与孤儿文档

日期：2026-10-30
状态：已实现并通过提交前完整门禁
ABI：v10

## 行为交付

- 文件监听发现磁盘变化时，干净文档自动重载；恢复 selection base/extent、affinity、方向与该文档的滚动位置。
- 文档已有本地修改时，磁盘内容与本地缓冲都保持不变并显示持久状态条。重载、覆盖与另存为都要用户明确选择；取消冲突对话框不写入任一侧。
- journal 恢复的本地文本与当前磁盘文本不同时，恢复本地未保存编辑并保留磁盘版本为 savepoint；首次保存仍进入显式冲突处理。
- 被删除/重命名的路径标记为 missing，保留可编辑缓冲。Ctrl+S 不会静默创建旧路径；用户可以另存为。重命名后的新路径不被自动当成旧文件。
- Rust 原子保存在临时文件创建/替换前检查只读目标并返回 `ReadOnlyTarget`；FFI 将其映射为 `ReadOnlyFile`。失败保留原文件字节和本地文本，并提供另存为。
- 每个已打开文档独立保留编辑器滚动位置；关闭文档和销毁工作台时释放对应 controller。

变更前，fresh index 上执行了 upstream impact：`_checkExternalChanges` HIGH（1 个直接关系，影响 3 个模块）；`_onWorkspaceChanged` LOW；`_saveDocToPath` LOW（含 1 条执行流）；`_revertActive` UNKNOWN（调用点通过源代码确认）；`OpenDoc`、`WorkspaceWatcher`、`_buildEditor` LOW；`atomic_save_bytes` CRITICAL（两个直接调用者、五条执行流）；`alula_doc_save_file` UNKNOWN（Dart 调用边未解析）。HIGH/CRITICAL 已明确记录，未用 shared axes 抵消风险。保存调用者、旧/新 ABI 错误映射、文件监听回调及 UI 动作均由目标用例覆盖。
