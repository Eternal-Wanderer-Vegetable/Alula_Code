## 行为

- 注册 file.saveAs、file.revert，并加入 File 菜单；Save As 默认 Ctrl+Shift+S。对未命名文档执行 Ctrl+S 会进入 Save As。
- Save As 将当前 Rust 权威缓冲区原子保存到目标路径；保存成功后更新文档路径、URI、标题名、磁盘 savepoint、文件树和 session journal。保存到同一路径按普通保存处理；目标路径已被其他打开文档占用时拒绝迁移；已存在的目标文件必须明确确认覆盖，取消时来源和目标都不改动。
- 文档已挂接 LSP 且路径变化时，先对旧 URI 发送 didClose，再设置新 URI 并 didOpen；更新语言 ID。新增的 didClose FFI 保留 Rust 文档缓冲区，Rust/Dart ABI 同步升为 v8。
- Revert 对脏文档先要求确认；从当前路径读回磁盘内容，先同步 Rust buffer，再更新 Flutter controller、savedText、syncText 与 dirty 状态；清空 undo/redo 历史并刷新语法、大纲和 journal。取消确认保留编辑内容。

另存为使用对话框输入完整路径。本切片没有接入平台原生文件选择器。
