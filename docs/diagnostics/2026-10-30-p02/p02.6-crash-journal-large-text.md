# P02.6 崩溃 journal 与大文本恢复

日期：2026-10-30

范围：`docs/03` P02.6；会话状态 journal、坏数据与超大未保存文本恢复。

## 结果

会话 journal 增加 `alula-session` v1 envelope、generation 和 FNV-1a 32-bit checksum。写入时先将 JSON 分块编码到同目录 `.tmp` 并 flush；主文件仍有效时将上一代复制到 `.bak`，最后用临时文件替换主文件。启动时验证主文件、备份和临时副本，并从校验通过的副本中恢复 generation 最新者。原始无 envelope 的 session JSON 仍可读取，下一次保存升级格式。

移除了工作台原有的 2,000,000 UTF-16 单元 journal 文本上限。untitled 或 dirty 文档的完整文本进入 journal；写 JSON 与计算 checksum 使用分块编码，避免另建完整序列化 JSON 字符串。journal 损坏、版本不支持、从备份/临时副本恢复和写盘失败都有可见状态；写盘失败会在编辑区显示提示。

## 边界

checksum 用于识别意外损坏，不提供防恶意篡改的密码学保证。恢复测试覆盖进程在临时文件 flush 后被强杀，不等同于断电时目录元数据持久性证明。读取 JSON 时仍需将恢复后的 payload 解码到内存；极大文档会按其自身大小消耗内存。大型端到端 Flutter widget fixture 在本 WSL 环境约运行 5 分钟；性能/内存调优依照新优先级留到 P14，P02.6 只确认编辑状态可持久化并可恢复。
