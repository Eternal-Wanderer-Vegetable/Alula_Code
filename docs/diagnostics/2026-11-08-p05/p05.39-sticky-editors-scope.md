# P05.39 / feat-091 / LAY-09b — Sticky editors, Pin/Unpin, and close behavior

## Fixed baseline and upstream behavior

- Baseline: Code-OSS commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`.
- The pinned `editorGroupModel.ts` represents sticky editors as a contiguous prefix. Sticking first pins the editor (which clears preview state), moves it to the end of the sticky prefix, then increments the prefix boundary. Unstick moves it to the first non-sticky position. The serialized group model carries sticky state.
- The pinned `editorGroupView.ts` exposes stick/unstick operations to the tab control. `editor.ts` defaults `pinnedTabsOnSeparateRow` to `false`, so sticky tabs share the normal tab row.
- The pinned editor commands use `workbench.action.pinEditor` / `workbench.action.unpinEditor`; both use Ctrl/Cmd+K, Ctrl/Cmd+Shift+Enter. With default `preventPinnedEditorClose: keyboardAndMouse`, keyboard Close skips sticky tabs and activates the next non-sticky editor. A context-targeted tab close closes its target; Close All Editors excludes sticky tabs, while Close All Editor Groups includes them.
- Sources: [editorGroupModel.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/common/editor/editorGroupModel.ts), [editorGroupView.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorGroupView.ts), [editor.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editor.ts), [editorCommands.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorCommands.ts), and [editorActions.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorActions.ts).

## Registered scope

- Add group-local sticky state distinct from preview state. Sticky editors form an ordered prefix in each group's tab order.
- Pin/Unpin the selected tab through an accessible tab context menu and command actions. Pinning a preview clears its preview state. Pin/Unpin preserves the editor view, document identity, active tab, dirty state, selection, input window, and Rust document state.
- Sticky status is serialized in the existing session journal and restored after restart. Existing split and move operations carry sticky status with the tab; closing a sticky tab removes its status.
- Sticky and ordinary tabs share the existing single row under the default non-wrapping layout. Preserve the current `wrapTabs` behavior and existing tab sizing/action/label policies.
- With the fixed default close policy, keyboard Close on the active sticky tab keeps it open and activates the most-recent non-sticky tab in the same group, then another group if needed. An explicit tab close action closes its target. Close All Editors preserves sticky tabs; closing all editor groups may close them.
- No Rust, FFI, ABI, or document-text protocol changes.
