# P05.31 / LAY-08b：普通编辑器标签自动换行

状态：本地实现与完整 DoD 通过；产品 PR CI 与三平台 hosted 验收待提交后验证

## 范围

实现固定 Code-OSS `workbench.editor.wrapTabs` 的布尔设置，默认 `false`，并在现有 View > Appearance 中加入可访问的互斥/checked 状态开关。设置存入现有 session journal，运行中对所有 editor groups 即时生效；不写入 editor layout JSON。

当 `showTabs == multiple` 且启用换行时，普通文档标签在当前组可用宽度不足时折到后续行；窗口或组宽度改变后重新排布。标签栏高度随实际行数增加/收缩，并将新高度用于编辑器内容区布局。若多行内容超过组可用高度，则保留有界回退行为，不遮挡编辑器动作区。关闭换行时维持单行横向滚动。点击、关闭、标签拖放等现有操作在换行期间必须仍能命中正确标签。

覆盖多个 editor groups、窄/宽尺寸切换、无文档以及 `multiple`/`single`/`none` 三种显示模式；保存与恢复设置时继续保留活动文档顺序和 Rust 编辑器视图状态。独立测试必须证明没有标签重复、遮挡、越界和动作区重叠。

### 明确不包含

- `pinnedTabsOnSeparateRow` 的固定标签独立行；Code-OSS 使用另一种 `MultiRowEditorControl`，本项目的 pin/sticky tab 模型另行登记。
- `tabSizing`、固定宽度、标签最大/最小宽度、compact/close button、图标、路径消歧、自定义标签、徽标和标题栏布局。
- 跨组拖放或重排语义的改变；本切片只验证换行后现有交互命中正确标签。
- Settings UI、workspace/user settings 优先级及跨 workspace 的全局配置；本原型按现有 tab mode 做 session journal 持久化。

## 固定上游语义（Code-OSS 1.145.0）

- [`editor.ts`](https://github.com/microsoft/vscode/blob/1.145.0/src/vs/workbench/browser/parts/editor/editor.ts#L31-L65)：`wrapTabs` 默认值为 `false`；选项由 `workbench.editor` 配置读取并验证为 boolean。
- [`editorTitleControl.ts`](https://github.com/microsoft/vscode/blob/1.145.0/src/vs/workbench/browser/parts/editor/editorTitleControl.ts#L56-L70)：普通 `multiple` 模式使用 `MultiEditorTabsControl`；`pinnedTabsOnSeparateRow` 才换用独立 `MultiRowEditorControl`，所以本切片不把两者合并。
- [`multiEditorTabsControl.ts`](https://github.com/microsoft/vscode/blob/1.145.0/src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts#L1842-L1904) 与 [换行计算](https://github.com/microsoft/vscode/blob/1.145.0/src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts#L2028-L2102)：换行开启时只有在宽度溢出且多行布局可容纳时才应用 `.wrapping`；行高变化会触发 group relayout；动作区宽度计入末标签间距，不能覆盖工具栏。
