## Registered scope

- Add group-local tab context actions: Close, Close Others, Close to the Left, Close to the Right, and Close Saved. Resolve the clicked tab and its group at menu-open time; never fall back to a different active editor group if the target is stale.
- Close Others retains the clicked editor and all sticky editors. Close to the Left/Right uses the clicked tab’s current sequential position, retains the clicked tab, and does not close sticky editors. Close Saved closes only clean non-sticky tabs in the target group. Explicit Close may close a sticky tab, preserving P05.39 behavior.
- Route tab close button, middle click, Ctrl/Cmd+W, Close All Editors, and Close All Groups through the same dirty-safe close decision path. Preserve the existing merge-result-specific close flow and compare-view close routing.
- For each operation, gather the actual final-view dirty documents before closing. Show Save / Don't Save / Cancel once for the affected standard documents. Cancel or a failed/cancelled Save-As keeps every candidate tab open; Save waits for an authoritative clean savepoint before any candidate closes; Don't Save discards only after explicit choice. A close operation must never silently discard Rust-authoritative dirty text.
- Apply close choices to the originating group and preserve unaffected document IDs, undo state, view state, editor focus, sticky order, active-editor MRU, and session journal. Closing one view while another group still owns the shared document must not prompt or dispose the remaining view.
- Register the upstream command IDs and supported default keybindings for the mapped actions; do not claim unsupported global/user/workspace/profile settings.
- No Rust/FFI/ABI/text protocol changes, no drag/drop redesign, no overflow/MRU navigation redesign, and no changes to Open Editors or multi-window behavior.
