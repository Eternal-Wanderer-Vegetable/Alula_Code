## Scope

Implement workbench.editor.tabActionCloseVisibility-equivalent behavior for ordinary, closeable, unpinned tabs:

1. Default to visible; parse absent or invalid session data as true.
2. Add an accessible checked toggle under View > Appearance > Editor Tabs. It applies immediately to every editor group and persists in the session journal, not the layout JSON.
3. When enabled, show the close action on the active tab and on the tab under pointer hover or keyboard focus; idle clean tabs do not show a close glyph. Retain the existing dirty marker and action placement for left/right modes.
4. When disabled, hide and disable the close action even for active, hovered, or focused ordinary tabs. Preserve dirty text/marker, document/model identity, middle-click and keyboard close paths, edit/save behavior, and tab geometry with the default reserved action space.
5. Closing a dirty document continues to use the existing close/confirmation path.
