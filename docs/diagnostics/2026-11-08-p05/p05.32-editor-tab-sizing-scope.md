## Fixed reference

- Code-OSS 1.145.0 `editor.ts` defines `workbench.editor.tabSizing` values `fit`, `shrink`, and `fixed`, with `fit` as the default. Fixed width defaults are 50 px minimum and 160 px maximum. The option is ignored when tabs are hidden. Source: [editor.ts at 1.145.0](https://github.com/microsoft/vscode/blob/1.145.0/src/vs/workbench/browser/parts/editor/editor.ts#L1188-L1211) and its validators at [editor.ts](https://github.com/microsoft/vscode/blob/1.145.0/src/vs/workbench/browser/parts/editor/editor.ts#L1394-L1405).
- The pinned tab control applies the fixed min/max CSS variables when `fixed` is selected, updates sizing when these options change, and holds current tab widths while the pointer remains over the strip so the close target does not move during rapid close. Source: [multiEditorTabsControl.ts, sizing](https://github.com/microsoft/vscode/blob/1.145.0/src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts#L2738-L2801) and [close-width preservation](https://github.com/microsoft/vscode/blob/1.145.0/src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts#L3323-L3338).
- Microsoft documents `fit` as preserving the full label and allowing a scrollbar when space is insufficient; `shrink` reduces tabs to a minimum to reduce scrollbar use. Source: [VS Code 1.19 release notes](https://code.visualstudio.com/updates/v1_19).

## Scope

Implement the Code-OSS tab sizing behavior for ordinary, unpinned editor tabs:

1. Add a session-persistent `workbench.editor.tabSizing` equivalent with `fit` (default), `shrink`, and `fixed`, selectable through an accessible View > Appearance submenu and applied immediately to all editor groups.
2. `fit` retains content-sized labels and horizontal scrolling when the combined tabs exceed available width.
3. `shrink` reduces tab widths as space tightens, down to a bounded minimum; at the minimum it retains a usable overflow/scroll path. The minimum is an internal implementation constant in this slice because the pinned public setting has no shrink-minimum option.
4. `fixed` clamps each tab between the pinned defaults of 50 px and 160 px. While the pointer stays over a fixed-width strip, closing one tab keeps remaining tab widths stable until pointer exit.
5. Resizing the group recalculates widths without replacing document or Rust editor state. Existing `showTabs` and `wrapTabs` modes continue to work; tab sizing is inert when tabs are hidden.

The Settings editor, user/workspace setting precedence and editable custom min/max values belong to P07's configuration slice. Pinned-tab sizing/separate row, close-button styles, icons, and path disambiguation remain outside this child.
