# P05.36 / feat-088 / LAY-08g — editor tab duplicate-name path disambiguation

## Fixed baseline and source behavior

- Baseline is Code-OSS commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`. The default `workbench.editor.labelFormat` is `default`. Its description says that when tabs are enabled and two files in one editor group share a name, distinguishing path sections are added: [workbench.contribution.ts, labelFormat defaults](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/workbench.contribution.ts#L2416-L2434).
- The pinned source also defines `short`, `medium`, and `long` formats; this slice implements only the default collision behavior. Official multi-root docs likewise describe adding the folder name to tab headers when file names collide: [VS Code multi-root editor labels](https://github.com/microsoft/vscode-docs/blob/main/docs/editing/workspaces/multi-root-workspaces.md).

## Registered scope

Implement the default label disambiguation for ordinary file-backed tabs in each editor group:

- Keep a unique filename unchanged. For same-name files in a group, append only the shortest distinguishing path suffix needed to make each visible label unique; if one path segment is insufficient, extend both colliding labels until unique.
- Compute labels from each `OpenDoc.name` and `OpenDoc.path`. Normalize path separators for display and handle root-level, nested, and untitled/no-path documents without fabricating a path. Apply the same derived label to the tab text, measured width, tooltip, and accessible name.
- Disambiguation is group-local. Other editor groups do not add path segments to each other's tabs. In `multiple` and `single` tab modes, the active label is derived against that group's open documents; `none` continues to render no tab.
- Keep document identity, ordering, dirty/disk markers, close controls, drag hit targets, active group, selection, scroll, Rust state, and session/layout persistence unchanged. A change to document paths or membership recomputes labels and width in the next layout.

## Out of scope

- `workbench.editor.labelFormat` choices `short`/`medium`/`long`, custom editor-label patterns, untitled content-derived labels, or Settings UI and configuration precedence (P07).
- File icon theme assets and the `showIcons` toggle (separate LAY-08 slice); pinned/sticky tabs, preview reuse, tab actions beyond already completed LAY-08e/f, Open Editors tree labels, breadcrumbs, Explorer labels, and arbitrary virtual-resource authorities.
- Changes to file opening, path canonicalization, save/revert, workspace-root discovery, Rust, FFI, ABI, or persisted document/session schemas.
