# P05.80 / feat-132 / LAY-16d — SCM resource-list navigation

## Scope and fixed reference

Pinned Code-OSS `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`: `src/vs/workbench/browser/actions/listCommands.ts` (bare navigation, Enter `selectElement(false)`, Space `list.toggleExpand`/leaf `selectElement(true)`), `src/vs/platform/list/browser/listService.ts`, `src/vs/workbench/contrib/scm/browser/scmViewPane.ts`.

`GitChangesList` encapsulates the existing Git resource rows. Bare arrows/Home/End move keyboard focus and reveal it without replacing selection; empty-focus ArrowUp starts at the first row. Enter selects/opens the focused resource and transfers focus to the existing diff panel; Space selects/opens while preserving list focus, never staging. Hover has separate visual state and never changes the keyboard target. Explicit stage/unstage buttons retain mouse and keyboard activation, with activation repeats suppressed. Unsupported modifiers are not treated as bare navigation. Focused semantics and selected styling are distinct.

One owned FocusNode and ScrollController are disposed on unmount. Lazy rows use fixed 48px extents and 24px section headers; focus/selection use path/group identities rather than a retained row-node map. Repository identity keys reset list state across workspace changes. Git diff opens use request generations and Git/workspace identity checks to drop late replies/errors. Async opens do not reclaim focus after the user deliberately focuses another control. The diff panel is made visible when a resource is opened; an untracked file is not mislabelled as cached.

## Boundaries

This is basic list hosting/navigation, not full SCM business parity. Mixed index/worktree entries keep the existing single staged-group row and existing mixed diff-side behavior; split resource groups, multiselect/range, collapse/type navigation/find, full context menus and business actions remain open (LAY-16/P09). The current diff destination remains the pre-existing bottom panel, not a new SCM editor implementation. No unused generic table was added. Native theme/font/DPI pixel/reference comparisons remain unverified. Parent P05 and LAY-16 remain open.
