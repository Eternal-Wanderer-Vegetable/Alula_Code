## Implementation

Added a separate pure-Rust module, crates/editor-merge/src/combination.rs, exported from the crate root. It computes a complete candidate from two inputs against one common base and does not change MergeProjection, conflict resolution, the FFI/ABI, Dart state, or Workbench commands.

The planner uses Unicode scalar offsets and a bounded Myers diff. It preserves valid UTF-8 text verbatim, including BOM and line endings. Edits are ordered by base position, with equal-position changes ordered Input 1 then Input 2. Same-position insertions and boundary insertions can combine; overlapping replacements/deletions and insertions inside a replacement return None. If either input is unchanged from base, there is no smart-combination candidate.

Default limits are 2 MiB total UTF-8 input, 1,000,000 diff-trace cells across both comparisons, and 2,000,000 frontier/equality operations. Exceeding a limit returns CombinationError; no partial candidate is returned.
