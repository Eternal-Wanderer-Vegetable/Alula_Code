## Implementation

- Added `showBulkEditMultiDiffPreview` and `BulkEditMultiDiffPreview` in `app/lib/editor/bulk_edit_multidiff_preview.dart`. The route accepts only the frozen `BulkEditMultiDiffProjection`; it does not create document controllers, edit buffers, workspace handles, or a duplicate row cache.
- The resource navigator preserves projection order and displays a stable path label, selected text-edit count, URI, document ID, and base version. Pointer and Arrow Up/Down navigation select the main diff. The first resource is selected and focused initially.
- The paired side-by-side view uses lazy `ListView.builder` rows with source line numbers, row-kind background styling, inline UTF-16 word ranges, and horizontal text scrolling. Resource and row semantics expose selection, edit count, kind, and line numbers. Layout switches to a compact navigator above the diff below 760 logical pixels.
- Escape and the close button remove the transient route. Tests snapshot URI, document ID, version, before/after text, and selected edits and confirm close leaves the projection unchanged.

The upstream Code-OSS `BulkEditPane` still has no production producer or Workbench route in Alula. This child supplies a reusable read-only route API; it does not claim end-to-end Code Action/Bulk Edit wiring, edit-level selection, Apply/Discard, or application/rollback. The fixed-source scope remains in `p04.125-bulk-edit-multidiff-surface-scope.md`.
