## Upstream contract

`mergeEditor.acceptMerge` is the F1 action “Complete Merge”, available only in Merge Editor, with Ctrl+Enter / Cmd+Enter. When conflicts remain it asks “Do you want to complete the merge of {basename(resultUri)}?”, explains that conflicts remain, and offers “Complete with Conflicts”. Cancel leaves the merge editor active. Confirmation (or zero remaining conflicts) calls `inputModel.accept()` and closes the active merge editor. The pinned input model documents accept as marking the merge done; its implementation saves the result text file.

Sources: [commands.ts, AcceptMerge](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/mergeEditor/browser/commands/commands.ts#L621-L663), [mergeEditorInputModel.ts, accept](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/mergeEditor/browser/mergeEditorInputModel.ts#L418-L421).
