# P04.120 / EDT-19j — Merge Editor smart-combination FFI contract scope

Date: 2026-11-05
Status: registered; implementation not started
Branch: `codex/vscode-parity-p00`

## Goal

Expose the bounded Rust smart-combination planner from P04.119 through a stateless C JSON ABI and typed Dart bridge. This gives the later Workbench Accept All Combination command a safe way to ask whether one conflict's base/input1/input2 text has a complete non-overlapping candidate.

The pinned Code-OSS 1.145.0 reference defines the action and candidate semantics in [`commands.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/mergeEditor/browser/commands/commands.ts#L585-L618) and [`modifiedBaseRange.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/mergeEditor/browser/model/modifiedBaseRange.ts#L24-L170). P04.119 supplies the pure planner in `crates/editor-merge/src/combination.rs`; this slice only transports that result across the existing Rust/Dart boundary.

## Contract and boundaries

- Add `alula_merge_combination_candidate_json` as a stateless C export accepting one JSON request with `base`, `input1`, and `input2` strings. It must not retain a document, session, projection, or candidate between calls.
- Add a typed Dart `AlulaMergeApi.combinationCandidate` method. Return a candidate string when eligible and `null` when the planner returns no candidate. A malformed/error response remains an `AlulaMergeException`; it must not be treated as `null`.
- Use an explicit response envelope with `ok: true` and nullable `candidateText`, or an `ok: false` error envelope. A failed limit/parse/serialization path must never include a partial candidate.
- Synchronize the ABI handshake from v39 to v40 on Rust and Dart. Continue returning native JSON through the established `alula_string_free` ownership path.
- Reuse P04.119 planner limits: 2 MiB combined UTF-8 input, 1,000,000 trace cells, and 2,000,000 work operations. The C JSON request remains capped at 16 MiB and the serialized response at 32 MiB; any cap failure is a whole-request error.
- Do not modify `MergeProjection` or its wire shape, merge resolution, Rust `OpenDoc`, session lifetime, undo/save behavior, Workbench UI/commands, F1 registration, or telemetry. Accept All Combination UI is a later registered slice. Numeric 500 MiB optimization remains deferred.

## Definition of Done

- Rust FFI tests call the real exported function and verify: non-overlapping edits return the exact combined UTF-8 text; overlapping edits and either unchanged side return `candidateText: null`; malformed JSON, unknown fields, decoded-input byte overflow, planner errors, and response overflow return a complete error envelope with no partial candidate.
- Real shared-library Dart tests verify typed candidate/null/error behavior, emoji and UTF-16 surrogate pairs, BOM, CRLF/CR/LF and final-newline preservation, invalid response rejection, native string release, and ABI version 40.
- `cargo fmt --all -- --check`, `bash scripts/build_core.sh`, `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, Flutter analyze/tests, and `bash init.sh` pass. Update `feature_list.json` evidence and `progress.md` before marking done.
- The subsequent Workbench action consumes the typed API and is explicitly out of scope for this slice.
