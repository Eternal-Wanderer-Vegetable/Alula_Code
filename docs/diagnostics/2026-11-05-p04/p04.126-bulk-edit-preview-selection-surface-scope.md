## Purpose

P04.123 supplies the bounded selection state, P04.124 supplies selected-edit projection, and P04.125 supplies a read-only Multi Diff surface. This child adds the missing interactive review surface that joins those pieces: callers provide one text-only `WorkspaceEdit`, its versioned source snapshots, and an apply callback; users can select resource/edit rows, inspect the current selected projection in Multi Diff, apply the filtered edit through the callback, or discard it.

The pinned upstream behavior is the Code-OSS `BulkEditPane`: resource/edit checkboxes, aggregate selection controls, Multi Diff preview, and Apply/Discard completion. References: [BulkEditPane tree/actions](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEditPane.ts#L145-L170), [selection changes and preview](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEditPane.ts#L322-L363), and [resource Multi Diff inputs](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEditPane.ts#L365-L410).

## Scope and contract

- Add a reusable Flutter preview route over the existing bounded `BulkEditPreviewSession`, `BulkEditMultiDiffProjection`, and P04.125 route. Keep its input frozen and text-only; never mutate source `WorkspaceEdit` or snapshots.
- Render resources and individual text edits in source order. Resource checkbox state is checked/indeterminate/unchecked from the session; expose per-edit toggles, resource select/clear/invert, and global select/clear. Show selected counts and stable URI/version metadata.
- Preview opens a fresh validated projection of the currently selected edits. An empty selection cannot open Multi Diff or apply.
- Before calling Apply, plan the filtered edit against the frozen source snapshots. Await the required apply callback; close only when it reports success. A stale/invalid selection or callback failure remains visible and does not report success. Discard/Escape closes without invoking the callback.
- Keep dialog/resource/edit lists bounded by the model's hard limits; use lazy UI rows and do not retain a second full-text/diff cache. Provide keyboard operation, semantics, responsive layout, and deterministic focus/close behavior.
- This child does not add a production Code Action/Bulk Edit producer or Workbench command/menu. It does not modify `WorkbenchPage.applyWorkspaceEdit`, transaction/undo/save logic, Rust/FFI/ABI, or add file create/delete/rename edits. The callback is the explicit integration seam for the existing transaction owner; future producer wiring is separate.
