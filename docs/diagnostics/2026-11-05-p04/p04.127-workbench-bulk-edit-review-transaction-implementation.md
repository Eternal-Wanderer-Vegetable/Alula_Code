## Implementation

- Added Workbench reviewWorkspaceEdit in app/lib/workbench/workbench_page.dart. It flushes pending input composition, freezes the currently open documents as versioned snapshots, and opens the existing Bulk Edit review surface.
- Apply forwards only the selected immutable WorkspaceEdit to the existing Rust-backed atomic multi-document transaction. Missing edit versions are filled from the frozen review snapshot so a document changed while the review is open fails stale validation instead of reinterpreting old ranges against new text.
- Added three Workbench integration tests covering selected-only multi-document apply, authoritative Rust text, dirty tabs, per-document undo/redo and save readback; stale failure with no partial application; and Discard/Escape preserving document and disk state.
- No Rust, FFI, ABI, transaction semantics, or memory target changed. A production Code Action/Bulk Edit provider is not claimed here; the provider mapping belongs to LNG-08 in P08.
