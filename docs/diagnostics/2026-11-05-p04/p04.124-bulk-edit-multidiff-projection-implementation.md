# P04.124 / EDT-20b — Bulk Edit Multi Diff projection model implementation

## Scope delivered

Implemented the bounded, pure Dart `BulkEditMultiDiffProjection` in `app/lib/editor/bulk_edit_multidiff_projection.dart`, with focused tests in `app/test/bulk_edit_multidiff_projection_test.dart`. The model projects a selected text-only `WorkspaceEdit` against immutable, versioned snapshots into ordered before/after texts and per-resource immutable diff results. It preserves URI, document ID, base version, resource order, and `transactionId`; rejects the entire projection for invalid, missing, duplicate, read-only, stale, overlapping, or no-op input and for any exceeded budget or approximate diff. Caller-supplied limits can lower but not raise the hard ceilings. Conservative size preflight runs before projected texts are built.

The model enforces 128 resources; 2,000,000 aggregate before/after UTF-16 code units; 32,768 aggregate source lines; 16,384 diff rows; 4,000,000 line-diff work and 2,000,000 line-diff trace cells; 262,144 inline-word input code units, 2,000,000 inline-word work, and 1,000,000 inline-word trace cells. No widget, Workbench route, document mutation, file operation, Apply/Discard, rollback, dirty/undo/save lifecycle, Rust/FFI/ABI, or numeric memory optimization was added. Scope and pre-edit review remain in [the registration report](p04.124-bulk-edit-multidiff-projection-scope.md); Code-OSS is pinned to `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`.
