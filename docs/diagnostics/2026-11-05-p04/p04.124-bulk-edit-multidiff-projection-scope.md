## Reference behavior and current gap

At the pinned source, `BulkEditPane` opens the transient Multi Diff editor when a file or text-edit tree element is opened. It supplies ordered original/preview resource pairs, and reveals the opened resource and selected text-edit range. Existing resources use the current file as original and a temporary preview resource as modified; new resources use an empty original; delete operations use a preview original and no modified resource. The pane's Apply and Discard controls are separate from this open route. See [`bulkEditPane.ts` tree open route and Multi Diff input construction](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEditPane.ts#L148-L165), [`_openElementInMultiDiffEditor`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEditPane.ts#L322-L363), and [`_computeResourceDiffEditorInputs`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEditPane.ts#L365-L410).

Alula has a bounded per-resource `DiffViewModel` and `WorkspaceEditPlanner`, but no immutable multi-resource preview projection. P04.123 adds only selection state and a filtered text `WorkspaceEdit`; it does not compute before/after snapshots or create diffs.

## Scope and contract

Add a pure Dart `BulkEditMultiDiffProjection` in a new editor module. Given a selected text-only `WorkspaceEdit` and immutable, versioned `WorkspaceDocumentSnapshot` inputs, use the existing planner to build complete before/after text for every resource, then build an immutable `DiffViewModelResult` for each resource. Preserve selected resource order, URI, document id, base version, and transaction id. A projection is a frozen value; it does not listen for later selection or document changes.

Fail the entire projection when a selected edit is empty, a resource is absent/duplicated/read-only/stale, a text range is invalid/overlapping, or any diff exceeds a bound. Hard aggregate limits: 128 resources; 2,000,000 combined UTF-16 code units across all before/after text; 16,384 diff rows; 4,000,000 line-diff work units; 262,144 aggregate inline-word input code units; and 2,000,000 aggregate inline-word work units. If any resource diff is approximate, return no partial projection. Keep the existing P04.123 limits on the upstream selection input.

Tests must cover two or more resources, selected-resource filtering and order, `version`/`transactionId` preservation, UTF-16 emoji and CRLF ranges, identical text/no-op rejection, missing/duplicate/read-only/stale snapshots, overlapping/invalid edits, every aggregate budget boundary, per-resource approximation causing whole-projection rejection, and immutability/source text preservation.

This slice is projection data only. It does not add a widget, Workbench route, diff navigation/reveal UI, file create/delete/rename, disk reads, edits to an open document, Apply/Discard controls, rollback, dirty/undo/save lifecycle, Rust/FFI/ABI, or numeric memory optimization. Those surface and application gates remain separate EDT-20 children. Do not claim Multi Diff UI or P04 completion from this model.
