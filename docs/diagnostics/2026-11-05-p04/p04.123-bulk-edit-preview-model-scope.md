## Scope and contract

Add a GUI-free Dart `BulkEditPreviewSession` over an immutable snapshot of the existing `WorkspaceEdit` text-document shape.

- Group and address changes by input document index/URI and edit index. Duplicate edit text/ranges remain separate independently selectable items.
- Initialize every text edit as selected. Alula's current `WorkspaceTextEdit` carries no `needsConfirmation` field, so selection cannot infer a Code-OSS confirmation category.
- Expose item state, per-document tri-state summary, document-level selection, per-edit selection, select all, clear all, and a checked edit count.
- Produce an immutable selected `WorkspaceEdit`; preserve document order, edit order, URI, optional version, and transaction ID. An empty selection fails visibly instead of yielding an empty operation.
- Freeze the source lists and text-edit values on construction. A selection revision increments only when a selection changes; no timer, stream, cache, or global registry is introduced.
- Fail the entire preview before retaining state if input exceeds 2,048 documents, 32,768 text edits, or 8 MiB combined UTF-8 bytes across document URIs and replacement text. Never silently truncate.

This slice does not compute visual hunks, render a view, open Multi Diff, apply the selected edits, perform rollback, mutate open documents, or change workspace transaction/undo/dirty/save behavior. File operations and notebook edits are unsupported by the existing `WorkspaceEdit` type and remain out of scope. Subsequent EDT-20 slices must connect this model to Multi Diff and then to the existing atomic transaction path with failure/undo/dirty verification.
