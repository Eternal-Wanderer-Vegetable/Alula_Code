## Implementation

- Added `mergeEditor.acceptMerge` / “Complete Merge” as an F1 and Command Palette action available only while a Merge Editor session is active.
- Added platform contextual defaults: Ctrl+Enter on Windows/Linux and Cmd+Enter on macOS. The existing `editor.action.insertLineAfter` binding remains the fallback outside Merge Editor. Context collisions are resolved in binding order; keybindings.json removal and rebinding still operate on the requested command. Context alternatives per chord are capped at 64.
- When conflicts remain, the action asks for confirmation naming the result file. Cancel exits before saving or closing. Pending IME composition is committed before save; if it exposes unresolved conflicts without an earlier confirmation, confirmation is requested.
- Accepted results save through the existing Save / Save As path, retaining atomic write and external disk-conflict handling. The action closes only if the Rust document version remains unchanged during save, the document is clean, and disk state is current. Save failure, cancellation, stale result, or exception keeps the Merge Editor open.
- `MergeResultSession.finishAccept` owns the confirmation gate, version check, savepoint update, last-saved result capture, and disposal after the result-document close callback.
