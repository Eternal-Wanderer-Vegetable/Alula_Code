## Implementation

- Added `showBulkEditPreview` in `app/lib/editor/bulk_edit_preview_surface.dart`. It consumes the existing immutable text-edit selection model and versioned source snapshots, then requires an apply callback. Snapshot records are copied on entry; duplicate and missing resource snapshots are rejected.
- The dialog presents source-ordered resources and lazy per-resource edit rows. It exposes tri-state resource selection, edit checkboxes, resource inversion, global select/clear, selected counts, URI/version semantics, and a responsive compact layout.
- `Preview` constructs a fresh bounded `BulkEditMultiDiffProjection` from the selected edit set and opens the existing read-only P04.125 surface. It does not retain a second diff cache.
- `Apply` plans the immutable selected `WorkspaceEdit` against the frozen snapshots before invoking the callback. It closes only on `true`; stale/planning failures, callback `false`, and callback exceptions remain visible in the dialog. Empty selection disables Preview and Apply. Discard, close, and Escape never call the apply callback. Barrier/back dismissal is disabled while a callback is pending.
- No existing Workbench, Rust, FFI, transaction, undo, save, or ABI code changed. No Code Action/Bulk Edit producer is wired yet; the required callback is the integration seam for a later Workbench child.
