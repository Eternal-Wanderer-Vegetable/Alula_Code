# P04.123 / EDT-20a — Bulk Edit preview selection model implementation

## Scope delivered

Implemented the bounded, pure Dart `BulkEditPreviewSession` in `app/lib/editor/bulk_edit_preview.dart`, with focused tests in `app/test/bulk_edit_preview_test.dart`. The model freezes text-only `WorkspaceEdit` input, groups edits by resource, starts with every edit selected, supports per-edit and resource/global selection operations, advances its revision only when selection changes, and creates a deeply immutable filtered projection while preserving document/edit order, duplicate edits, URI, document version, and `transactionId`.

The complete input is rejected when it exceeds 2,048 documents, 32,768 text edits, or 8 MiB of combined UTF-8 `transactionId`, URI, and replacement text. Malformed UTF-16, duplicate resource inputs, empty input, and invalid edit indices fail closed. No UI, Workbench route, actual edit/apply or rollback, Rust/FFI/ABI, dirty/undo lifecycle, or memory-target work was added. Scope and pre-edit analysis remain in [the registration report](p04.123-bulk-edit-preview-model-scope.md); Code-OSS is pinned to `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`.
