## 实现

- `CommandHistory`（`app/lib/workbench/command_history.dart`）：最近使用在前、
  `record` 去重前移、上限 50、超长/空 id 忽略；`order(ids)` 输出「历史优先 → 其余
  保持原顺序」；`toJson`/`fromJson` 读取时过滤非字符串、空、超长与重复项。
- `CommandHistoryStore`（`command_history_store.dart`）：用 `SessionStore` 的原子
  journal 持久化，`format=alula-command-history` + `version=1` 校验，主/`.bak`/`.tmp`
  任一超过 64 KiB 视为损坏回退空历史；读取失败不影响启动。
- `QuickInput.show` 新增 `onCommandExecuted(commandId)`：只在候选项带 `commandId`
  且已 pop 后触发（真正执行前），供命令面板写历史；单步/多步/多选语义不变。
- 命令面板：空查询时按 `_commandHistory.order(...)` 排序（历史优先，其余注册顺序），
  输入查询后仍由 fuzzy 相关度排序（历史同分时作为稳定次级顺序）；只有经面板接受的
  命令记录，菜单/键位执行不记录（与上游一致）；`AlulaApp`/`WorkbenchPage` 增加
  `commandHistoryStore` 注入点，默认落在 `<session.json>.command-history`。
- item 按钮：只有当前选中/悬停行渲染（hover 会选中该行）；每个按钮持有显式
  `FocusNode`，输入框内按 `Tab` 直接把焦点交给活动行的第一个按钮（无按钮时交回默认
  遍历），`Enter`/`Space` 触发按钮动作；隐藏行的按钮不在树里，无法误点；按钮保留
  `tooltip` 作为可访问名称。
- 登记差异：上游命令面板用「最近使用」分节标题 + 排序，本实现只用排序、不加分组
  标题；按钮 hover 渐显动画与图标主题化不在本切片。
