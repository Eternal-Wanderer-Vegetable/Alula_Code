## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- 命令面板历史：上游 `CommandsHistory` 记录经命令面板接受的命令 id，按最近使用
  （MRU）排序参与面板结果；查询为空时最近使用命令排在前面，输入查询后由相关度
  决定；历史有上限（上游 50 条）并跨重启持久化（storage）。
- item 按钮：`QuickPickItem.buttons` 只在条目被 hover 或成为活动项时显示；按钮是
  可聚焦控件（Tab 可进入、Enter/Space 触发），并带可访问名称。

## 登记范围

- `CommandHistory`（`app/lib/workbench/command_history.dart`）：有序命令 id 列表
  （最近在前）、`record(id)` 去重前移、上限 `maxCommandHistoryEntries = 50`、
  `toJson`/`fromJson` 读取时过滤非字符串/空/超长项；提供 `orderById` 供面板构造
  历史优先顺序。
- `CommandHistoryStore`（`app/lib/workbench/command_history_store.dart`）：基于
  `SessionStore` 原子 journal 的单文件持久化（默认路径
  `<session.json>.command-history`），格式/版本校验、超限丢弃、读失败回退空历史。
- 接线：`WorkbenchPage` 初始化加载历史；`_showCommandPalette` 按「历史顺序（仍受
  visible 过滤）→ 其余命令注册顺序」构造条目；命令经面板接受时记录（`QuickInput.show`
  新增可选 `onCommandExecuted(commandId)` 回调，在真正执行前触发）；历史变化后下一次
  打开面板生效。`AlulaApp`/`WorkbenchPage` 增加 `commandHistoryStore` 测试注入点。
- item 按钮：仅当该行是当前选中/悬停行时渲染；按钮保留可访问 tooltip（按钮名称），
  并可通过 Tab 从输入框进入、Enter 触发；离开行后按钮隐藏。
- 顺带登记：上游命令面板的「最近使用」分节标题不在本切片（Alula 用排序而不用
  分组标题），差异写入报告。
