# P05.58 / feat-110 / LAY-18b — 进度通知（loading/percentage/cancel）与 banner

## 拆分说明

docs/11 LAY-18（通知与进度）验收面：「toast/center/banner/DND/来源过滤/actions/取消/
loading/error/可访问提示一致」。P05.57 交付通知基础设施、toast、中心与 DND；本切片补齐
**进度通知（不确定/确定进度、取消）与 banner 呈现**；产品侧接线（保存失败、LSP/工作区
错误、真实长任务进度）为 P05.59 / LAY-18c。

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- 上游 `INotificationService.notify({progress})`：带进度的通知在 toast/中心显示加载态；
  `IProgressOptions.total` 存在时为确定进度（worked/total），否则为不确定进度；
  `cancellable`/取消回调提供取消按钮；进度通知不会自动关闭，直到 reporter 结束或用户
  关闭。
- 上游 banner：通知以视图内嵌横幅形式呈现（同一 severity/actions/source 语义），
  可关闭、可带动作；与 toast/中心共享同一通知记录。

## 登记范围

- `NotificationProgress`（`notifications.dart`）：`total`/`worked`/`infinite`/
  `onCancel`，`fraction`（确定进度 0..1，否则 null）、`report()` 更新并通知、
  `cancellable` 与 `cancel()`；`WorkbenchNotification.progress` 关联。
- `NotificationCenter.notify(..., progress: ..., banner: true)`：banner 通知进入 banner
  集合（上限 3）而不产生 toast；进度通知保留在 toast/中心并显示进度条与取消按钮；
  `dismiss`/`clearAll` 同时清理 banner；`banners` 派生。
- UI：toast 与中心条目在有 `progress` 时渲染进度条（确定：`LinearProgressIndicator` +
  `百分比` 文本；不确定：indeterminate 进度条），可取消时显示取消按钮
  （`notification-toast-cancel-<id>` / `notification-cancel-<id>`）。
- Banner 层（`WorkbenchNotificationBanners`）：工作台标题栏下方、编辑器网格上方的内嵌
  横幅（key `notification-banner-<id>`、关闭 `notification-banner-close-<id>`、动作
  `notification-banner-action-<id>-<n>`、进度条与取消同上），zen 模式隐藏、空时零高度。
- 可访问：banner 使用 live region 与可读名称；进度条带 semantics 值。
- 命令：不新增（复用 P05.57 的通知命令）；banner/进度可由任意调用方通过
  `NotificationCenter.notify` 创建。

## 实现

- `NotificationProgress`（`notifications.dart`）：`total`/`worked`/`infinite` 可变，
  `fraction` 在确定模式下钳制 0..1（不确定返回 null）、`percent`、`cancellable` 由
  `onCancel` 决定、`report({worked,total,infinite})` 仅在变化时 `notifyListeners`、
  `cancel()` 调用回调。
- `WorkbenchNotification` 增加 `progress` 与 `banner`；`NotificationCenter.notify` 增加
  `progress:`/`banner:`：banner 通知进入 `_banners`（上限 3，旧→新）且**不产生 toast**，
  普通通知照旧；列表上限裁剪同时清理 banner/toast/未读；`dismiss` 与 `clearAll` 清理
  banner；`banners` 派生为通知对象列表。
- UI（`notification_widgets.dart`）：`_NotificationProgressLine` 用
  `ListenableBuilder` 直接监听 `NotificationProgress`，渲染 `LinearProgressIndicator`
  （`notification-progress-<id>`）+ 百分比（`notification-progress-percent-<id>`）+
  可取消时的「取消」按钮；toast 取消 key `notification-toast-cancel-<id>`、中心
  `notification-cancel-<id>`、banner `notification-banner-cancel-<id>`。
- `WorkbenchNotificationBanners` 横幅层：工作台标题栏下、编辑器网格上的内嵌条
  （`notification-banner-<id>`、severity 左色条、动作 `notification-banner-action-<id>-<n>`、
  关闭 `notification-banner-close-<id>`、进度行、live region）；空时零高度；zen 模式由
  工作台不渲染该层。
- 差异登记：banner 沿用上游 view banner 的 severity/actions/source 语义，但 Alula 目前
  没有真实产品来源（工作区信任横幅等留 LAY-18c / P14）；进度通知不自动关闭（依赖
  reporter 结束或用户关闭），自动关闭计时为 P07 设置项。
