# P05.57 / feat-109 / LAY-18a — 通知中心与 toast 基础设施（DND、来源过滤、可访问提示）

## 拆分说明

docs/11 LAY-18（通知与进度）验收面：「toast/center/banner/DND/来源过滤/actions/取消/
loading/error/可访问提示一致」。本切片交付通知模型、toast 层、通知中心（状态栏入口、
未读计数、逐条关闭、全部清除、Do Not Disturb、来源过滤）与可访问语义；**进度通知
（loading/percentage/cancel）与 banner 留给 P05.58 / LAY-18b**，产品侧接线（保存失败、
LSP 错误等）留给 P05.59 / LAY-18c。

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- 上游通知：`INotificationService.notify({severity, message, actions, source, progress})`，
  severity 为 info/warning/error；toast 在右下角堆叠，带来源与动作按钮、可关闭；
  通知中心从状态栏铃铛打开，列出全部通知、支持逐条清除与全部清除；Do Not Disturb
  抑制 toast 但通知仍进入中心；按来源（extension）过滤。
- 可访问：toast 使用 live region 朗读，动作按钮有可访问名称。

  逐条条目（key `notification-item-<id>`）、逐条关闭、全部清除
  （key `notification-clear-all`）、Do Not Disturb 开关（key `notification-dnd-toggle`）、

## 实现

- `NotificationCenter`（`notifications.dart`）：新通知插入列表头、加入未读与 toast
  集合；toast 上限 3（丢最旧）、列表上限 100（丢最旧并清理未读/toast）；
  `dismissToast` 只移出 toast、`dismiss` 同时移出列表与未读、`clearAll` 全清；
  `markRead`/`markAllRead`；`setDoNotDisturb` 开启时清空现有 toast 且之后不再产生
  toast（列表与未读照常）；`sources` 去重排序 + `filtered(source)`。
- `WorkbenchNotification`（severity/message/source/createdAt/actions）与
  `WorkbenchNotificationAction`（label/key/run）。
- UI（`notification_widgets.dart`）：`WorkbenchNotificationToasts` 右下角堆叠
  （`notification-toast-<id>`、severity 图标、来源、动作按钮
  `notification-toast-action-<id>-<n>`、关闭 `notification-toast-close-<id>`、
  `Semantics(liveRegion: true)`）；`WorkbenchNotificationCenter` 面板
  （`notification-center`、未读数 `notification-center-unread`、DND 开关
  `notification-dnd-toggle`、全部清除 `notification-clear-all`、关闭
  `notification-center-close`、当来源多于一个时出现来源下拉
  `notification-source-filter`、空态 `notification-empty`、逐条条目
  `notification-item-<id>` 与 `notification-action-<id>-<n>`、逐条清除
  `notification-dismiss-<id>`）。
- 状态栏：`AlulaStatusBar` 增加通知铃铛入口（`status-notifications`）与未读 badge
  （`status-notifications-badge`），图标随面板展开/DND 变化；其余控件与 key 不变。
- 工作台：`WorkbenchPage` 持有 `NotificationCenter`（可注入），监听变化重建；
  body 由 Column 包进 `Stack(fit: expand)`，通知层在非 zen 模式叠加（面板展开时隐藏
  toast 避免重叠）；打开中心即 `markAllRead`，关闭时清空来源过滤；zen 模式隐藏通知层。
- 命令：`workbench.action.showNotifications`（查看→通知，F1 打开/关闭中心）、
  `workbench.action.clearNotifications`、`workbench.action.toggleNotificationsDoNotDisturb`。
- 差异登记：通知不跨重启/窗口持久化（上游按窗口内存态重建；Alula 单窗口内存态），
  通知超时自动关闭、banner、进度通知与产品侧接线为 P05.58/P05.59，DND 持久化归 P07。
