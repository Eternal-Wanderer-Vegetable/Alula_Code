## 现状与范围

当前 `TitleMenuItem` 只能表示一个命令，`_MenuButton` 使用扁平 `PopupMenuButton` 列表；生产菜单由 `workbench_page.dart:16656` 装配 File/Edit/View/Help 四组。View 的外观切换命令目前是平铺项，无法按 VS Code 菜单树放入 Appearance 子菜单。

本切片为标题栏菜单增加显式 command/submenu/separator 节点，递归呈现并继续遵守 `CommandService` 的 visible/enabled 状态、命令参数与快捷键显示；把现有 View 外观切换项放入 `View > Appearance`，保证至少一条真实生产子菜单路径。覆盖鼠标展开、键盘方向/返回/取消、禁用/隐藏项过滤、分隔符清理和命令执行，不增加未注册的占位命令。

## 明确排除

- 不实现 mnemonic/access-key 标签、Alt 单键菜单聚焦或 `window.enableMenuBarMnemonics`；另开 P05 子项。
- 不接 macOS 原生 application menu；native menu/menubar 单独验收。
- 不扩展 VS Code 默认菜单命令全集，不实现全部菜单配置、视图状态或菜单可见性设置。
- 不改窗口模式、标题栏窗口按钮、Rust、FFI/ABI、键位注册表或 500 MiB 目标。
