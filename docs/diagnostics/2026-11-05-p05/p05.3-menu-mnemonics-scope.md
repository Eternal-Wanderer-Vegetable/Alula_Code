## 目标

在 P05.2 的递归标题栏菜单上补齐默认桌面键盘访问：菜单标签可标记 mnemonic；Windows/Linux 上裸 Alt 聚焦菜单栏、Alt 释放后显示提示，按标记键打开顶层菜单并在当前菜单中调用或展开匹配项；Escape/关闭菜单后焦点回到原工作区。macOS 不启用 Alt 菜单访问键。默认 mnemonic 与 Alt 聚焦均开启，且提供 widget 层可注入的开关，配置系统的用户设置接入属于 P07。

标签采用固定参考中 `&&X` 标记习惯，并提供 `&&` 字面量转义；显示文本不包含标记，Alt 行为使用被标记字符。无标记的标签不响应访问键。重复 mnemonic 采用当前层级中最后一个可见且启用的匹配项；disabled/hidden 命令不可被调用，separator 不参与访问键匹配。菜单层级、command 参数和显隐/启用条件延续 P05.2 的模型。

## 范围

- 在 Workbench 默认菜单标签加入 `&&` mnemonic 标记；`AlulaTitleBar` 实现顶层/递归菜单访问、leaf command 执行、最后匹配项优先、disabled/hidden/separator 过滤、Escape 焦点恢复。
- Windows/Linux 的裸 Alt 聚焦与 Alt+key 打开菜单分开受 `customMenuBarAltFocus`、`enableMenuBarMnemonics` 控制；macOS 禁用 Alt 路径。鼠标或 Alt+Shift 拖选不会被误判为裸 Alt。
- 用无窗口插件通道的 Flutter widget tests 覆盖标签解析/转义、Windows/Linux/macOS 目标、两个设置开关的独立行为、嵌套 submenu/command、禁用/隐藏项、Escape/焦点返回、Alt+鼠标与矩形拖选回归。
- 为避免 Flutter `MenuAcceleratorLabel` 的快捷键注册干扰 Alt+Shift 矩形拖选，使用其 marker parser 解析标签并由 RichText 绘制提示下划线；访问键路由由标题栏自己的键盘处理器执行。
- 不改 Rust、FFI、ABI、命令注册语义、窗口控制、菜单全集、macOS 原生菜单或系统设置 UI；不启动本机 GUI/Narrator，不做数值内存优化。
