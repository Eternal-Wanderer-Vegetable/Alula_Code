## 固定参考语义

对照固定 Code-OSS commit [`4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/browser/linesOperations.ts#L752-L885) 的 `DeleteAllLeftAction` / `DeleteAllRightAction`：

- `deleteAllLeft`：普通光标删除本行起点到光标；光标已在行首时删除前一行内容尾至当前行起点；非空选区扩展到选区起始行行首。
- `deleteAllRight`：普通光标删除光标到本行内容尾；光标已在行尾时删除到下一行起点；非空选区保持原范围。
- 固定源码在 Windows/Linux 没有默认快捷键；macOS 为 `Cmd+Backspace`、`Ctrl+K` 和 `Cmd+Delete`。两个命令在 Alula 均可从命令面板执行。

## 实现

- `editor-buffer` 的 Rope 查询一次解析最多 10,000 个绝对 UTF-16 selection 范围，不将全文复制到 Dart；保留 BOM，按 UTF-16 scalar 边界校验，并按 CRLF 的两个 code unit 删除完整行分隔符。
- `editor-core` 新增批量 FFI `alula_doc_delete_line_ranges`；Rust 与 Dart ABI 握手同步升为 v25。反向范围、无效代理对位置、方向值和超限输入都有显式错误。
- 工作台保护活动 IME composition；按同一 Rust 文档版本查询范围，合并重叠范围，逆序应用删除，并在逆序撤销数据不超过 2,000,000 UTF-16 单元时记录撤销操作。编辑后同步同文档视图、selection、dirty 状态、查找与保存。
- macOS 键位只在 macOS 默认表注册；Windows/Linux 保持无默认键位，用户仍可用命令面板或自定义绑定调用。
