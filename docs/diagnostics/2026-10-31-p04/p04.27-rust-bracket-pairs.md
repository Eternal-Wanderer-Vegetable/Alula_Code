# P04.27 / EDT-06c — Rust bracket pairing

Date: 2026-10-31. Status: implemented and verified.

## Reference and scope

Reference: pinned Code-OSS commit [`4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/extensions/rust/language-configuration.json), Rust `autoClosingPairs` and `surroundingPairs`.

This slice supports Rust `()`, `[]`, and `{}`. A caret opener inserts the matching closer and remains between the pair; an opener wraps the selected text; typing a closer skips a matching closer only when this editor previously inserted it. The default `autoCloseBefore` boundary is honored. Other language files and IME composition keep their existing input path. Quote and angle-bracket pairs, automatic paired deletion, token-aware exceptions, and bracket parsing remain out of scope.

The editor uses existing Rust-authoritative UTF-16 TextOps and does not change the FFI ABI. Auto-closed closer markers are shared by split views, capped at 10,000 per document, remapped through edits, invalidated when a bracket is deleted or the document version cannot be reconciled, and released with the final view. This prevents a literal closer from the original file from being mistaken for an editor-inserted closer.
