# P04.9 — PageUp/PageDown 分页光标移动

## 范围与参考

完成 EDT-01f：编辑器焦点下 PageUp/PageDown 将光标移动到相邻可视页的最近文本位置，Shift 变体保留 anchor 扩展选择。固定 Code-OSS 1.145.0-dev 基线；VS Code Windows、Linux、macOS 默认键位均为 PageUp/PageDown 与 Shift+PageUp/PageDown，见 [Windows](https://github.com/microsoft/vscode-docs/blob/main/build/keybindings/doc.keybindings.win.json)、[Linux](https://github.com/microsoft/vscode-docs/blob/main/build/keybindings/doc.keybindings.linux.json)、[macOS](https://github.com/microsoft/vscode-docs/blob/main/build/keybindings/doc.keybindings.osx.json) 默认键位表。

## 实现

- 工作台注册 `editor.cursorPageUp`、`cursorPageDown` 及两个选择变体，并为 PageUp/PageDown 与 Shift 变体绑定回调。
- 回调 flush 当前输入后，从当前编辑器 FocusNode 的 `EditableText` Action 调用 Flutter `ExtendSelectionVerticallyToAdjacentPageIntent`。Flutter 按实际 render viewport 高度移动，保留目标水平位置并将 caret 滚入视口。
- Flutter Windows/Linux 已将 plain PageUp/PageDown 映射到光标分页；macOS 默认将 plain PageUp/PageDown 映射为纯滚动。本实现显式调用同一个 text-selection Action，统一 VS Code 的光标分页行为。Shift 选择也走同一 Action。
- 输入窗选择回执复用现有 `_onInputDelta` 重居中路径；跨越 16K 输入窗时改读新的 Rust 有界快照。未改 Rust、FFI、`RustTextInputFieldState`、共享 selection/scroll helpers 或 key-chord parser。
