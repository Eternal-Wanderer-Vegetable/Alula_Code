# P04.24 / EDT-05d — 覆写模式粘贴

日期：2026-10-31

状态：实现与仓库自动化验证完成；P15 原生平台验收仍单独 pending。

## 固定参考语义

对照固定 Code-OSS commit [`4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`](https://github.com/microsoft/vscode/tree/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e)：

- `editor.overtypeOnPaste` 默认值为 `true`；仅在 Overwrite 模式下的显式粘贴快捷键走覆盖路径。普通平台 TextInput 更新、IME composition 仍按原有编辑路径处理。
- `PasteOperation` 在配置启用且光标处于 Overwrite 模式时使用 `ReplaceOvertypeCommand`。替换从 selection 起点开始，非空 selection 除原选区外再按粘贴文本 UTF-16 长度减一扩展；扩展不越过 selection 终点所在逻辑行的内容尾。
- 多光标粘贴按既有规则分发：行数与光标数相等时逐行分配，否则每个光标重复完整剪贴板文本。

参考源码：[`editorOptions.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/config/editorOptions.ts)、[`cursorTypeEditOperations.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/cursor/cursorTypeEditOperations.ts)、[`replaceCommand.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/commands/replaceCommand.ts)。

## 实现

- `editor-buffer` 的 Rust Rope 查询接收最多 10,000 个绝对 UTF-16 选区及对应插入宽度，返回版本化覆盖范围；代理对中间位置拒绝，目标跨代理对时向前吸附，CRLF/LF 行分隔符不被覆盖。ABI 从 v25 升至 v26，Rust FFI 与 Dart 握手、JSON 模型同步更新。
- 工作台默认启用 `overtypeOnPaste`；设置存储与 UI 由 P07 接线。显式 Ctrl/Cmd+V 在覆写模式且无 IME composition 时读取剪贴板，校验文档版本和 selection 快照，再查询 Rust 范围。重复或重叠且内容相同的范围合并，内容冲突则取消；逆序提交并保留受 2,000,000 UTF-16 单元预算约束的撤销数据。
- 编辑结果同步同文档视图、caret/多光标、dirty、undo/redo、查找状态与保存。macOS 的 Cmd+Z / Cmd+Y 进入 Rust 文本撤销/重做路径。
- 不改变未带 Ctrl/Cmd+V 的 TextInput/IME 更新处理；已有 P04.21 测试继续验证在覆写模式下程序化多字符更新仍按插入处理。
