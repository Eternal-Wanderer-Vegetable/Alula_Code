## 对照与范围

固定 Code-OSS commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 的
[`toggleOvertype.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/codeEditor/browser/toggleOvertype.ts)
将覆写状态作为工作台级输入模式：Windows/Linux 使用 `Insert`，macOS 使用
`Cmd+Alt+O`；编辑器状态栏在覆写模式显示 `OVR`，点击后回到插入模式。
编辑器字符输入由固定版本的
[`cursorTypeEditOperations.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/cursor/cursorTypeEditOperations.ts)
和 [`replaceCommand.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/commands/replaceCommand.ts)
区分普通打字、IME composition 和 paste。此切片完成工作台命令、状态指示和单次物理按键对应的普通打字覆写。

- 新增 `editor.action.toggleOvertypeInsertMode` 命令与平台默认键位；覆写状态对工作台所有编辑视图生效。
- `OVR` 只在有活动编辑器且覆写模式开启时显示；点击即恢复插入模式。
- 单次可打印按键只有在随后的 TextInput 插入文本与该键字符一致时才覆写；在主光标和次级光标处替换后一个完整 Unicode 字素，遇 CR/LF 或 EOF 停止，不拆代理对/组合字素。
- 非空选区仍按选区替换；没有匹配物理按键的 paste、程序化输入和多字符输入保持插入语义。活动 IME preedit 不会被格式化器改写。挂起字符标记限单条、2 秒失效，并在选择变化、composition、跨窗替换、其他按键和编辑器指针按下时清除。
- 未新增 `editor.overtypeOnPaste` 设置；默认 paste 保持插入。IME commit 的覆写、paste 专用设置、词删除和行边界删除留在 EDT-05 后续原子切片。
