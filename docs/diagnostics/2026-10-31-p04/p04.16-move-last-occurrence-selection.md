# P04.16 / EDT-03a：移动最后一个匹配选区

日期：2026-10-31
状态：done

## 行为

- 增加 `editor.action.moveSelectionToNextFindMatch` 命令。Windows/Linux 使用 `Ctrl+K Ctrl+D`，macOS 使用 `Cmd+K Cmd+D`；前缀等待 5 秒，超时后清除。
- 命令移动当前多选集合中的最后一个 occurrence selection 到下一个未被其他选区覆盖的匹配，并保留主选区。只有一个选区时，移动该选区。
- 新 selection 经过现有 `_setDocSelections` 入口，因此加入每文档 selection history；`Ctrl+U` 与 `Ctrl+Shift+U` 可撤销/重做。单键 Ctrl/Command+D 继续添加下一个匹配。
- 查找复用分页 Rust `readRange` occurrence scanner；Flutter 不读取整篇文档，不改 Rust、FFI ABI 或文档文本。
- 键位默认表现在把 occurrence-add 按键设为 Windows/Linux `Ctrl+D`、macOS `Cmd+D`，删除了错误的 `Ctrl+Shift+D` 默认项。自定义单键 keybindings 仍由现有 `KeybindingSet` 支持；多键默认 chord 由工作台焦点节点处理。

VS Code 官方默认键位表将 `Ctrl+K Ctrl+D` 映射到 “Move Last Selection To Next Find Match”：[Default Keyboard Shortcuts](https://code.visualstudio.com/docs/reference/default-keybindings)。仓库固定参考快照也登记命令 ID：`docs/diagnostics/2026-10-27-p00/runtime-registry.json` 与 `atomic-contributions.json`。
