# P04.5 / EDT-01b — word cursor movement

Date: 2026-10-31
Scope: word movement and Shift selection in the Flutter workbench; subword movement remains P04.6.

## Changes

- `KeybindingSet.load` now resolves platform defaults. Word movement remains with Flutter's editor text shortcuts: Ctrl+Left/Right on Windows and Linux, Option+Left/Right on macOS.
- History navigation no longer captures a word-navigation chord: Windows uses Alt+Left/Right, Linux uses Ctrl+Alt+- and Ctrl+Shift+-, and macOS uses Ctrl+- and Ctrl+Shift+- (physical Control, matching the pinned VS Code `WinCtrl` binding).
- The workbench no longer intercepts macOS Option+Shift+Arrow as column selection. This leaves Flutter's native word/paragraph selection shortcuts available; macOS column-selection arrow bindings are omitted from defaults.
- New fixtures cover both movement directions and Shift extension on Windows/Linux/macOS target platforms, CRLF file loading into the Rust LF text model, a second-line word boundary, and a long document after the bounded input window recenters. Every fixture confirms the Rust document text and version do not change.
