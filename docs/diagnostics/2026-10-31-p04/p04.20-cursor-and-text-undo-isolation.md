## 验收

- `Ctrl+U` / `Ctrl+Shift+U` 在 occurrence 多选状态间撤销与重做；每次操作后 Rust 权威全文和文档版本保持不变。
- 对文本进行编辑后执行光标撤销，文本及 Rust 文档版本保持不变；随后 `Ctrl+Z` / `Ctrl+Shift+Z` 仍可独立撤销和重做这次文本编辑。
- 两个文档分别拥有 occurrence 光标历史。对 B 执行光标撤销/重做后，A 的选择历史仍可恢复；A、B 文本编辑交错后，先撤销 B 不改变 A，切回 A 只撤销 A，再分别重做。
- 两份文件在测试结束时仍保留原始磁盘内容，证明这些未保存编辑只作用于各自 Rust 文档。
