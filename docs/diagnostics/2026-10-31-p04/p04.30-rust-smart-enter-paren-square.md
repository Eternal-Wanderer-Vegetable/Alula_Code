# P04.30 — Rust auto-paired parenthesis and bracket smart Enter

Date: 2026-10-31. Status: implemented and validated.

## Behavior

In a Rust `.rs` document, Enter now expands an empty `()` or `[]` only when its closer is still tracked as inserted by Alula's auto-close handling. The pair becomes an inner line indented four spaces and a closing line at the original indentation; the caret lands after the inner indentation. Source-authored pairs, non-Rust documents, selections, and active IME composition continue through the existing Enter path. Undo and redo use the existing document history.

The implementation reuses the shared marker and Rust-authoritative UTF-16 TextOps. It checks the neighboring pair before expansion, adds no Rust/FFI ABI, and keeps existing bounds, version checks, dirty state, split-view synchronization, and save behavior.

This slice completes the empty tracked `()` / `[]` cases only. Token-aware handling for source-authored pairs, comment continuation, quote rules, and configurable indentation remain open.

- [Pinned Rust language configuration](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/extensions/rust/language-configuration.json) includes `()`, `[]`, and `{}` as bracket pairs.
