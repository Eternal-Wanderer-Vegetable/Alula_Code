# P04.19 / EDT-03d：跨有界输入窗矩形拖选与边缘自动滚动

Date: 2026-10-31. Status: implementation slice complete; P04 / `feat-026` remains in progress. Native desktop platform acceptance remains part of P15.

## Implementation

- Rust `TextBuffer.column_selections_utf16` resolves a rectangle from document-wide line numbers and UTF-16 columns, returning absolute UTF-16 ranges without materializing the whole document. The active row is first. Supplementary scalars snap outward so the range never splits an emoji surrogate pair; CRLF terminators are excluded from line content and a BOM remains text. Allocation is capped at 10,000 rows.
- ABI was bumped from v22 to v23. The new `alula_doc_column_selections` FFI and Dart `AlulaDoc.columnSelectionsUtf16` wrapper return the bounded batch with a document version. The caller rejects a stale version. Invalid line and row-limit errors keep the existing JSON error contract.
- Mouse rectangle selection now stores the anchor as an absolute document line/UTF-16 column. Drag updates resolve all rows through one Rust call, preserve the active row as the primary selection, and feed the existing absolute multi-selection edit/save path. Near the 2,048-unit input-window margin, the active selection recenters the bounded window while remote rows remain in `additionalSelections`.
- The existing 16 ms edge-scroll timer now advances rectangular selection across input-window boundaries, with a maximum speed of 3,600 px/s. Pointer up/cancel, focus loss, disposal, and window updates retain the drag lifecycle cleanup. The bounded input window and 10,000-row selection ceiling remain in force.
