## 行为与实现

- `Ctrl+Alt+ArrowUp` / `Ctrl+Alt+ArrowDown` 仍执行 VS Code 多光标命令，但行号和绝对 UTF-16 行首现在来自 Rust `lineBoundary` / `lineOffset`，不再把 Flutter 的 16,384 单元输入窗口误当成全文。
- 目标列以 UTF-16 单元计算，并限制在目标行正文内。目标附近只读最多 64 Ki UTF-16 单元；Flutter 使用既有 grapheme helper 将列吸附到安全边界，Rust 再验证最终绝对偏移。
- 目标光标在当前窗口之外时，工作台围绕目标打开新窗口并保留原有光标。后续普通输入仍将窗口外光标编辑合并到同一 Rust 文档变更和保存路径。
- 没有修改 Rust/FFI ABI；没有全文读取、无界缓存或常驻轮询。
