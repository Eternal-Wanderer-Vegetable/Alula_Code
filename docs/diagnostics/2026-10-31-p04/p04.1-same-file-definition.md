# P04.1 — Same-file Rust Go to Definition

Status: implementation slice complete. The P04 feature remains in progress.

## Scope

- F12 and the Command Palette route through the shared `editor.gotoDef` command.
- The current-file Rust Tree-sitter symbol list supplies definitions; this slice does not call a language server or change the FFI ABI.
- Definition navigation selects the identifier token itself, not the start of its declaration line.
- Rust identifiers use Unicode XID start/continue characters, and all caret/definition offsets remain UTF-16 code units.
- An empty caret position and an identifier without a same-file definition return separate status messages.
