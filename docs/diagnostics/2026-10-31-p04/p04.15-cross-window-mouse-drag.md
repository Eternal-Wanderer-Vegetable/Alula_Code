# P04.15 / EDT-02f — cross-window mouse drag selection

## Result

Implemented bounded cross-window mouse drag selection and viewport-edge auto-scroll in the Flutter workbench. A mouse drag keeps its original Rust document UTF-16 anchor; after the local input window edge is reached, the workbench stores the absolute selection and recenters the bounded input window around the moving extent. The existing range painter and absolute-range Copy/Cut/Delete paths continue to operate on the full selection.

While the pointer is outside the text viewport, a 16 ms timer scrolls the attached vertical and horizontal viewports at a capped 3,600 px/s. Recentered windows align the moving caret with the dragged edge so scrolling can continue across successive windows. The timer stops on pointer-up, pointer-cancel, focus loss, widget disposal, re-entry into the viewport, and a reached scroll/document boundary. Pending local selection state is flushed before replacing an input window.

The selection-only path does not change Rust document text/version or disk bytes. No Rust or FFI ABI changes were needed.
