# P04.3 / EDT-16c — cross-file definition and navigation history

Date: 2026-10-31. Status: implementation slice complete; P04 feature remains in progress.

## Behavior delivered

- Rust `editor-lsp` parses `textDocument/definition` results in both `Location` and `LocationLink`
  forms and keeps the protocol's zero-based UTF-16 line/column coordinates.
- ABI v20 adds Rust-backed document position conversion and bounded asynchronous definition
  start/poll/cancel calls. Requests are limited to 16 in flight and carry the source document
  version. Close, LSP stop/detach, URI change, workspace shutdown, and Critical resource pressure
  cancel pending requests.
- The workbench uses LSP definition results first and retains Rust symbol navigation as the
  same-file fallback. Cross-file targets open in the source editor group; an already-open document
  becomes a shared view. A result is ignored if the source document or active view changed while
  the request was pending.
- Back/forward history and last-edit history each hold at most 128 locations. Named paths can be
  reopened after their final tab closes. Untitled documents are removed from history when their
  final view closes. Position restoration goes through Rust, so line ends, CRLF, BOM and surrogate
  pair boundaries follow the same UTF-16 mapping contract as editing.
