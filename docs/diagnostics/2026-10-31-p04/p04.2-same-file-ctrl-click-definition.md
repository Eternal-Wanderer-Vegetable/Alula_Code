# P04.2 — Same-file Ctrl/Command+Click Definition Navigation

Status: implementation slice complete. P04 remains in progress.

## Scope and implementation

- Ctrl+Click and Command+Click use the existing `editor.gotoDef` path for same-file Rust definitions.
- The pointer listener records `RenderEditable`'s hit-tested local UTF-16 offset plus the current bounded-window origin, then applies the navigation after `EditableText` completes pointer-up selection.
- Drags beyond `kTouchSlop`, canceled pointers, and disposed workbench state do not navigate. Alt+Click remains on the existing multi-cursor path.
- The implementation changes no Rust code or FFI ABI. Cross-file providers and navigation history remain in P04.3.
