日期：2026-10-31
状态：完成

## 范围

按固定 Code-OSS commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 实现默认缩进行为：Tab 在当前可见列插入到下一个四列制表位；单行局部选择用 Tab 文本替换；整行或多行选择按行缩进；Shift+Tab 反缩进；`editor.action.indentLines` / `editor.action.outdentLines` 注册到命令服务，并绑定 Windows/Linux `Ctrl+]`、`Ctrl+[` 和 macOS `Cmd+]`、`Cmd+[`。

参考的 Code-OSS 源码：[`cursorTypeEditOperations.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/cursor/cursorTypeEditOperations.ts)、[`shiftCommand.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/commands/shiftCommand.ts)、[`linesOperations.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/browser/linesOperations.ts)。

## 实现与边界

新增 `app/lib/editor/indentation.dart`：按 Unicode grapheme 计算可见列，并复用固定版 Code-OSS 的全角与 emoji 宽度规则；默认参数为 `tabSize=4`、`insertSpaces=true`。工作台从 Rust `lineBoundary`、`lineOffset`、`readRange` 读取受影响行，按版本校验后通过既有 `TextOp` 提交，不读取全文、不改 FFI ABI。多光标编辑范围冲突时整次取消；IME composition 时保留当前输入；受影响行最多 10,000 行，读取范围及撤销载荷最多 2,000,000 UTF-16 单元。选择映射、撤销/重做、dirty、同文档第二视图刷新和保存流程继续使用现有文档事务路径。

定向测试 15 项通过：三平台 Tab/行命令、Unicode grapheme 与列宽、多光标、双视图同步、undo/redo、BOM、Emoji UTF-16、真实 Rust 示例 `fn main() { println!("linux-save-ok"); }` 的保存回读。`flutter analyze` 无问题；`cargo fmt --all -- --check` 通过；完整 `RUST_TEST_THREADS=1 FLUTTER_BIN=/home/vegetable/develop/flutter/bin/flutter bash init.sh` 通过 Rust workspace、Clippy、build_core 和 Flutter 393 项。

自动缩进继承、智能回车、括号/引号闭合/跳过/删除，以及 `tabSize`、`insertSpaces` 设置接入留后续 EDT-06 切片/P07。本报告中的三平台用例是 Flutter TargetPlatform 自动化，不能替代 P15 原生键盘/IME/读屏/DPI 验收。
