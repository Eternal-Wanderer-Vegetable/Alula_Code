[`wordOperations.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/wordOperations/browser/wordOperations.ts)
与 [`cursorWordOperations.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/cursor/cursorWordOperations.ts)
实现 `deleteWordLeft` / `deleteWordRight`：

- Windows/Linux 使用 `Ctrl+Backspace` 和 `Ctrl+Delete`；macOS 使用 `Alt+Backspace` 和 `Alt+Delete`。
- 左删尊重非空选区；连续两个以上空格/制表符只删除该空白串，普通左删删除光标前词段及紧邻的单个空格。文件开头不变。
- 右删尊重非空选区；先删除光标后的空格/制表符，否则删到下一词段结尾。行尾跨行时删除行分隔符及下一行词首前的缩进；文件末尾不变。
- Rust 使用 Rope 只扫描相关行，并在绝对 UTF-16 坐标中一次返回最多 10,000 个光标的范围。FFI JSON 输入有字节上限；ABI 从 v23 升至 v24，Dart/Rust 两端同步并握手校验。
- 工作台会合并重叠/相接范围，以倒序提交删除，保留并映射多光标；跨窗选区沿用既有删除路径。IME composition 活跃时保留编辑态，不提交删除。
- 删除前先检查逆操作总字符数不超过现有 2,000,000 字撤销预算，再分块读取 Rust 权威删除文本；超预算时拒绝操作，不先分配撤销载荷。文本操作支持常规撤销/重做、dirty、双视图同步和保存回读。
