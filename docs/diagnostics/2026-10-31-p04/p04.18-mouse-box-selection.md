日期：2026-10-31
状态：done（当前 Rust 输入窗内的鼠标矩形选择）

## 范围

固定版 VS Code 的列选默认手势为 Windows/Linux `Shift+Alt` 拖动、macOS `Shift+Option` 拖动；官方行为说明见[编辑基础：Column (box) selection](https://code.visualstudio.com/docs/editing/codebasics#_column-box-selection)。本片让鼠标矩形选区进入已有多选编辑、Rust 同步与保存路径。

## 实现

- `RustTextInputField` 识别鼠标主键与 `Shift+Alt/Option`，越过 touch-slop 后按屏幕横坐标逐逻辑行命中 `RenderEditable`，正确处理 emoji 等可视宽度不同的字符；活动行作为主选区。
- 同一手势不再触发普通 `Alt+Click` 添加光标。取消、抬起、失焦和控件销毁时清理拖动状态。
- Workbench 将有界输入窗内的本地行选区转为文档绝对 UTF-16 selection，再复用已有多光标编辑、撤销历史、Rust 提交和原子保存路径。最多接受既有 `editor.multiCursorLimit`（10,000）个行选区。
- 无 Rust crate、FFI 或 ABI 改动。
