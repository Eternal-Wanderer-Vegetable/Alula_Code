# P04.8 — 文件首尾移动与选择

## 范围

完成 EDT-01 文件开头/末尾移动及 Shift 选择变体。参考固定 Code-OSS 1.145.0-dev commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`；Windows/Linux 使用 Ctrl+Home/End，macOS 使用 Command+Up/Down。命令分别对应 `cursorTop`、`cursorBottom` 及其选择变体（[VS Code 默认键位表](https://code.visualstudio.com/docs/reference/default-keybindings)）。

## 实现

- 工作台增加 `editor.cursorTop` / `editor.cursorBottom` 与 Shift 选择命令。
- 命令 flush 当前输入后读取 Rust 文档同步确认的 `totalUtf16Length`，将绝对 selection 移到 0 或文档末尾；跨越 16K 有界输入窗时通过现有 selection 路径重居中。
- Shift 选择保持原 anchor 和方向；非 Shift 移动折叠成 caret。操作不会修改文本、文档版本或 dirty 状态；没有新增 FFI ABI。
