# P04.14 / EDT-02e — 跨窗选区输入与 IME 替换

日期：2026-10-31

状态：实现完成；原生平台 IME/辅助功能验收仍由 P15 负责。

## 实现

- 跨窗绝对 selection 存在时，普通 TextField 输入先按有界 Flutter 值计算差异，再把插入文本作为对 Rust 完整 selection 的单次替换；文档操作进入既有 undo、dirty、保存和 sibling view 同步路径。替换后在原 `RustTextInputWindow` 对象上刷新快照，保证当前 formatter 事务立即返回新窗口值。
- IME composing 仍作为 Flutter overlay 保留，不提前写 Rust。候选提交将最终文本作为整段 selection 的替换；预编辑取消恢复 Rust 已提交文本并保留跨窗 selection，之后仍可重新输入。
- Workbench 输入窗硬上限仍为 16,384 UTF-16 单元；初始化范围预留 256 单元给 composition，并保留 1 单元处理代理对边界。三击跨窗整行后将有界 caret 放在选中行内部，避免旧局部坐标覆盖新窗口 selection，也为 IME 预编辑留出两侧空间。窗口默认最大容量没有扩大；超过预留量仍由原有超限恢复路径处理。
- 不改 Rust crate、FFI ABI 或 GUI 边界。
