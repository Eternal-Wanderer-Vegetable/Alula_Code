## Behavior

- In Rust files, plain Backspace removes both characters when every selection is a caret between a matching `()`, `[]`, or `{}` pair that Alula automatically inserted.
- Literal source pairs are not treated as auto-closed pairs. A non-empty selection, a caret outside a tracked pair, IME composition, cross-window selection, or non-Rust file follows the existing input path.
- Multi-cursor pair deletion is one version-checked Rust text operation batch. Undo/redo, dirty state, sibling views, and save/readback use the existing document pipeline.
- Pair reads use Rust-authoritative UTF-16 document ranges. The implementation retains the existing 10,000-selection and undo payload limits. No Rust or FFI ABI change.
