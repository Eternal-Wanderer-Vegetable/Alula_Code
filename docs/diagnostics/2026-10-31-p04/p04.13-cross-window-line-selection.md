# P04.13 / EDT-02d — 跨有界输入窗的超长行三击选择

日期：2026-10-31

状态：实现完成；原生操作系统输入与辅助功能验收仍由 P15 负责。

## 实现

- 三击命中位置在 Flutter 手势处理前换算为 Rust 文档绝对 UTF-16 偏移；若原生 selection 先触发输入窗重居中，延后回调仍按这个绝对位置查询 `lineBoundary`。
- 整行超出 16K 输入窗时，OpenDoc 保存完整的绝对 selection。Flutter `TextEditingValue` 只保留窗内 caret；已有 range painter 将完整选择裁剪到当前输入窗绘制。窗口外 selection 端点不再夹到错误的本地偏移。
- Copy 使用固定上限的 Rust `readRange` 分块读取整段文本。Cut、Delete 与 Paste 在 Rust 文档绝对范围上应用操作，并通过现有文档 undo/dirty/save 路径；selection 或 copy 不修改 Rust 文本与磁盘。
- 用户移动 selection、编辑文本、Escape 或在编辑器点击时清理跨窗 selection。没有新增 Rust ABI 或 GUI 依赖。
