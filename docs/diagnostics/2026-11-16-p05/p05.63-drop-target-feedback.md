# P05.63 / feat-115 / LAY-20a：编辑器拖放 hover overlay

## 固定来源与决策

- VS Code 基线：Code-OSS 1.145.0，commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- [editorDropTarget.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorDropTarget.ts)：拖动期间持续按指针在组正文中的位置更新 overlay；整区目标覆盖全部正文，拆分目标覆盖对应半区，中心区覆盖全区；显示/隐藏不改变既有 drop 操作。
- [editordroptarget.css](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/media/editordroptarget.css)：overlay 不接收 pointer，覆盖在编辑器组上；拆分位置短暂过渡，拖动结束即清理。
- Alula 的 P05.43/P05.44/P05.45 已实现跨组 move/copy、组区域落点与正文边缘拆分；这些报告将拖动复制反馈及组/拆分 hover overlay 留给 LAY-20。

## 范围

- 组区域目标：整区高亮；拖动到正文时正文目标提供更具体的中心/拆分预览。
- 正文中心区：全正文 overlay；四个拆分方向：对应半区 overlay 与方向标识，命中区与现有 `_bodyDropZone` 判定一致。
- 组区域、正文和标签目标均可显示有效复制提示：仅平台复制修饰键被按下，且来源为可复制的命名文档时显示。
- overlay 只呈现已有 drop 意图，不更改 DragTarget payload、移动/复制选择、拆分布局或 session 持久化。

## 排除

- 跨应用文件/文本拖入、拖出新窗口、拖放焦点与快捷键路由、Explorer 文件拖入、多选拖动、overflow 边缘装饰。
- P05.43–P05.45 已完成的拖放语义不在本项重做。
