## 目标与边界

给辅助编辑器窗口增加可访问的 Compact 模式开关。开启后缩窄辅助标题区、隐藏文档名并移除编辑器周围多余边距，以增加正文可用空间；always-on-top 与移回/关闭控制在紧凑状态仍可访问。关闭 Compact 恢复普通标题和编辑器边距。

开关只保存在当前辅助窗口的 Flutter widget state，创建新辅助窗时默认为关闭。不得改变 Rust 文档全文、selection、undo/redo、dirty/savepoint、磁盘内容、session journal、窗口移交 payload 或 P05.67 的 window/group focus channel。不得添加常驻轮询、timer、窗口 listener 或跨窗口消息。

Alula 当前辅助窗是单文档编辑面，无标签栏、面包屑、状态栏、多个 editor group 或 auxiliary-window layout state 服务。因此本 slice 只实现可见 compact 状态和标题/编辑器密度变化，不模拟不存在的 VS Code 子系统，也不在编辑同一文档时自动退出 compact。

明确排除：Always-on-top（P05.66）、组/焦点同步（P05.67）、移回主窗、跨窗口拖拽、文档/组操作、compact 跨重启持久化、Command Palette 与 VS Code 的 compact command IDs、全局布局设置及通用命令基础设施。compact 命令 ID 与跨重启状态作为差异登记，后续由命令/设置 slice 决定是否覆盖。
