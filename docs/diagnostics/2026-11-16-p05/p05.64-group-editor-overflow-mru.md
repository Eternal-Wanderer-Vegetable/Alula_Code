# P05.64 / feat-116 / LAY-10g：编辑器组标签溢出与 MRU 选择

## 固定来源与决策

- VS Code 基线：Code-OSS 1.145.0，commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- [`editorCommands.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorCommands.ts)：`workbench.action.showEditorsInGroup` 先激活目标组，再打开活动组编辑器 Quick Access。
- [`editorQuickAccess.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorQuickAccess.ts)：活动组编辑器按 `EditorsOrder.MOST_RECENTLY_ACTIVE` 排序；条目显示 dirty 状态，接受后在对应组打开/激活该 editor。
- Alula 已有 `EditorGroup.recentDocIds`、`_noteActiveDocument` 和 `_mostRecentDocument`；`_buildTabStrip` 现有水平滚动及 active-tab reveal，但还没有组内溢出列表。

## 范围

- 每个拥有多个打开文档的编辑器组，在其标签/标题操作区提供可访问的“显示编辑器”入口；入口按组工作，不要求该组此前已聚焦。
- 列表先按该组 `recentDocIds` 从新到旧呈现仍打开的文档；去重、忽略已关闭 ID，并将无 MRU 记录的现存标签按稳定标签顺序补齐。
- 条目沿用组内路径消歧后的标签，呈现 dirty 与 sticky 状态，并标记当前活动文档。
- 选择条目后提交当前编辑器输入组合、激活目标组/文档、更新既有 MRU 与命令上下文、将焦点交给目标组、滚动到可见标签并写入既有 session journal。列表关闭或取消不得改变文档内容、关闭状态或 undo/selection/view state。
- 即使当前 tabs 设置为 single/none，也可从此入口切换该组中其他已打开文档；单/无标签显示配置不改变。

## 排除

- 全局或跨组编辑器 Quick Access、fuzzy query、命令注册/快捷键与 `Ctrl+Tab` 循环。
- 标签拖出窗口、关闭菜单、跨组 move/copy、overflow edge 装饰和 drag/drop focus routing。
- 文档打开/关闭语义、Rust/FFI/ABI、文本协议、session schema 或编辑状态模型改动。
