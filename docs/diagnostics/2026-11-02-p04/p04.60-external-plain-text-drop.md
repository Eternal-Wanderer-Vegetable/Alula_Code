# P04.60 / EDT-11b：外部纯文本拖入

日期：2026-11-02
状态：实现完成；本地门禁以及 Linux/Windows hosted 原生探针通过。macOS 原生拖放仍按用户要求列为待验证。

## 范围

- 在桌面编辑器中接收单项 `text/plain` 外部拖放；不处理 HTML、URI、文件、图片、多项拖放或 Paste As。
- 将编辑器布局命中的局部位置转换成 Rust 文档绝对 UTF-16 offset，并带上文档 id/version。
- 插入上限为 65,536 UTF-16 code units；拒绝空文本、过长文本、非法 surrogate、目标文档变化、IME composition、未提交输入和只读/冲突磁盘状态。
- 将 CRLF/CR 统一为缓冲区 LF；插入通过一个 Rust `TextOp` 提交，生成单步 undo，更新光标、分屏视图、dirty、Find、语法和保存路径。

## 实现

- `EditorNativeTextDragDrop` 在有外部文本接收回调时只向 native drop region 声明 `Formats.plainText`。本应用的版本化 localData 仍走原有同文档 move/copy 路径；带 Alula localData 类型但无法解析的项不会退化为外部复制。
- native `DataReader` 读取采用异步回调并设 10 秒超时；超时取消读取，不把数据保留在常驻缓存中。
- `RustTextInputField` 用现有 `RenderEditable` hit test 生成 UTF-16 drop target；workbench 再次核验文档版本/生命周期，以 Rust 权威 buffer 插入，并使用现有 `_recordDocumentOperations` 记录 undo。共享 undo helper 未修改。
- 无 ABI 变更；Rust 核心不新增 GUI 依赖。
