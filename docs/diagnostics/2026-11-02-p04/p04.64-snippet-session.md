# P04.64 / EDT-12a：基础片段占位符会话

日期：2026-11-02

## 范围

实现一个基础 TextMate 风格片段垂直切片：模板展开、编号占位符镜像、Tab/Shift+Tab 导航、最终光标、Esc 取消，以及沿用 Rust 文档输入和撤销路径。没有 Rust 或 ABI 变更。

支持 `$1`、`${1}`、`${1:default}`、`$0`，并处理 `\$`、`\}`、`\\`。同编号占位符共享首个非空默认值；未写 `$0` 时，在模板末尾生成隐式最终停止点。模板、展开结果、tabstop 编号和占位符数量均有上限。未知变量表达式保留为普通文本；choice、transform 和嵌套 placeholder 明确拒绝，不会产生部分编辑。

命令 `editor.action.insertSnippet` 可从命令面板打开模板输入，也接受字符串或 `snippet`/`template` 参数。当前只允许输入窗内的单选区插入；IME 组合、跨窗/列选及已有多光标会被拒绝。插入与后续镜像编辑走同一个 Rust 文档输入协议，插入单独形成撤销帧。Session 使用绝对 UTF-16 坐标和 Rust 文档版本；用户把光标移出活动 tabstop、版本失配或镜像编辑计划不完整时会取消，避免继续使用过期位置。

Rust 输入 diff 可能将多个镜像编辑合并成覆盖其间文本的粗粒度替换。为正确追踪占位符，session 根据 Flutter 原始主选区编辑生成每个镜像位置的编辑计划，并只在 Rust delta 确认后更新其绝对范围。测试也覆盖了输入后未等下一帧就按 Tab 的提交顺序。
