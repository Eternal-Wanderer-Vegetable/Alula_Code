## 范围

片段解析器现在接受 `$TM_SELECTED_TEXT`、`${TM_SELECTED_TEXT}` 与 `${TM_SELECTED_TEXT:default}`，工作台在 flush 当前输入后读取有效的输入窗内单选区，并将选中文本作为纯文本变量值传给解析器。值以普通文本展开，不创建额外 tabstop；空选区解析成空字符串，因此已解析的空值也不会被 default 替换。解析器可以通过 variables map 注入值，未知变量表达式继续保留为原文。变量 transform 明确拒绝，避免它内部的 `$1` 被误解析成占位符后产生部分编辑。

变量文本和周边模板统一受现有 expanded UTF-16 限额约束。输入窗越界、跨窗/列选、多选区、IME composition 与版本失配仍按既有片段插入边界拒绝；替换后的文本沿用 Rust authoritative input、undo 和 save/read-back 路径。没有 Rust 或 ABI 变更。VS Code 片段参考将 `TM_SELECTED_TEXT` 定义为当前选中文本或空字符串：[官方 snippet syntax](https://github.com/microsoft/vscode/blob/main/src/vs/editor/contrib/snippet/browser/snippet.md)。
