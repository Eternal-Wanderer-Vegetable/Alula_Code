## 已实现内容

- `EditorClipboard` 新增有界 `text/plain`、`text/html`、`text/uri-list` snapshot，同时保留既有 metadata；Linux、Windows、macOS 格式映射外，补读 `Formats.fileUri` / `Formats.uri`，按 100 项和 UTF-16 长度上限拒绝超限值。
- 新建 `paste_as.dart` provider/config 模型：kind 对齐 `text.plain`、`uri.path.absolute`、`uri.path.relative`、`html`；空 preference 默认顺序为 plain、absolute URI/path、relative path、HTML；存在 URI-list 时抑制 plain fallback，URI 多项以空格拼接，relative provider 只输出工作区内 file URI。
- 工作台已注册 `editor.action.pasteAs`（Ctrl/Cmd+Shift+V）、`editor.action.pasteAsText`、`editor.changePasteType`、`editor.hidePasteWidget`。普通粘贴保持 plain-text 优先级；`editor.pasteAs.enabled=false` 时普通 plain-text paste 仍工作。粘贴后以非模态“Change Paste Type” widget 选择替代 provider，Escape 隐藏；provider kind 与内部 id 都可用于命令参数。
- Paste As 前后复核活动文档、Rust 版本、selection 集与 `primaryFocus`；多选区按绝对 UTF-16 范围在一次 `applyWith` 中提交，history 单帧记录；替代 provider 先 undo 原粘贴再应用新值，确保一次 undo/redo。保存读回、dirty、双视图与文本输入窗口更新沿用既有 Rust 文档路径，不改 ABI。
- Paste As 设置由 `PasteAsConfiguration.fromSettings` 解析 `editor.pasteAs.enabled`、`editor.pasteAs.preferences` 与 `editor.pasteAs.showPasteSelector`（`afterPaste`/`never`，默认 `afterPaste`）。当前由 `AlulaApp` 注入；Settings UI / 持久化接线仍属于 P07 设置面，不在本 slice 假称完成。

## 本切片行为

- 在有界 clipboard snapshot 中读取 `text/plain`、`text/html`、`text/uri-list`，兼容纯文本 fallback 与既有 `vscode-editor-data` metadata；保留 HTML/URI 数据原始格式，不把 HTML 当普通文本自动插入。
- 普通 Ctrl/Cmd+V 继续默认插入 plain text。增加 `editor.action.pasteAs`、`editor.action.pasteAsText`、`editor.changePasteType` 和 Escape 隐藏选项；Paste As 支持按 `kind` 或有序 `preferences` 指定 provider，默认设置 `editor.pasteAs.preferences` 选择可用 edit，`editor.pasteAs.enabled` 与 `showPasteSelector` 控制普通粘贴后的选项。
- 提供通用 `Insert Plain Text`、显式 `Insert HTML`、`Insert Path/URI` 和 `Insert Relative Path` 四类操作。相对路径仅对 workspace 内 URI 生成；本切片不复制、移动或写入资源文件。
- provider 计算须可取消，并在编辑器文档、版本、焦点或选区变化后拒绝提交过期结果。多光标/多选区编辑在单次 Rust 事务中提交；切换 provider 不留下多次粘贴，Undo 一次回到粘贴前全文，Redo 一次恢复当前选定结果。
- 正确更新 caret/selection、dirty/savepoint、Find、同文档多视图和显式保存回读；不改 FFI ABI。
