## 当前代码缺口

- P04.58 的 `EditorClipboard` 写出 plain text、HTML 和 Code-OSS metadata；读取只保留 plain text 与 metadata，未形成多 MIME clipboard snapshot。
- 普通 Ctrl/Cmd+V 已有文本插入事务，但没有 provider/session 模型、`editor.action.pasteAs` 选择器或粘贴后的替代 provider widget。
- 当前工作台不提供通用 URI list 的绝对路径与 workspace-relative path 备选项。

## 本切片行为

- 在有界 clipboard snapshot 中读取 `text/plain`、`text/html`、`text/uri-list`，兼容纯文本 fallback 与既有 `vscode-editor-data` metadata；保留 HTML/URI 数据原始格式，不把 HTML 当普通文本自动插入。
- 普通 Ctrl/Cmd+V 继续默认插入 plain text。增加 `editor.action.pasteAs`、`editor.action.pasteAsText`、`editor.changePasteType` 和 Escape 隐藏选项；Paste As 支持按 `kind` 或有序 `preferences` 指定 provider，默认设置 `editor.pasteAs.preferences` 选择可用 edit，`editor.pasteAs.enabled` 与 `showPasteSelector` 控制普通粘贴后的选项。
- 提供通用 `Insert Plain Text`、显式 `Insert HTML`、`Insert Path/URI` 和 `Insert Relative Path` 四类操作。相对路径仅对 workspace 内 URI 生成；本切片不复制、移动或写入资源文件。
- provider 计算须可取消，并在编辑器文档、版本、焦点或选区变化后拒绝提交过期结果。多光标/多选区编辑在单次 Rust 事务中提交；切换 provider 不留下多次粘贴，Undo 一次回到粘贴前全文，Redo 一次恢复当前选定结果。
- 正确更新 caret/selection、dirty/savepoint、Find、同文档多视图和显式保存回读；不改 FFI ABI。

## 验收门

- widget/bridge 测试覆盖 plain-only、HTML-only、plain+HTML、URI-only 和多格式 clipboard；HTML 仅经显式 Paste As 使用；URI 同时覆盖 file 与普通 URI、workspace 内与外路径。
- 验证多选区、选择器取消、编辑状态变化后 provider resolve 被取消、粘贴后切换 provider、单步 Undo/Redo、dirty/savepoint、双视图同步和 BOM+CRLF 保存回读。
- 非法、缺失、超限 MIME 安全退回现有纯文本路径或无操作，不得截断后继续写入。新增 HTML/URI 缓冲与 URI 项数量必须设明确上限并有边界测试。
- Linux 与 Windows 优先做真实系统剪贴板集成验收；macOS build/fixture 可在 CI 验证，原生输入路由与 P15 保持独立待验。
- 全量 `bash init.sh`、`cargo fmt --all -- --check`、`flutter analyze --no-pub` 通过；PR CI 与 Platform Availability 归档证据。
