# P04.61 / EDT-11c：跨文档文本拖放复制

日期：2026-11-02

状态：实现与本地门禁完成；待 Linux/Windows hosted CI 复核。跨文档 move 与 macOS 原生拖放仍待后续验收。

## 行为

- 从 Alula 编辑器选中文本拖到另一份已打开文档时，只有显式 Copy（Linux/Windows 为 Ctrl，macOS 为 Option）会被接受；默认 Move 仍被拒绝，避免目标插入与源删除分开提交。
- 放下时按源 Rust 文档 id/version 重新读取完整选区并与 drag payload 对照；源/目标文档或版本不符、范围失效、UTF-16 内容无效、目标偏移越界，以及任一相关视图存在 IME composition、pending 输入或输入窗版本滞后时均安全拒绝。
- 使用现有 Rust 文档 FFI 对目标文档执行单次 UTF-16 `TextOp.insert`；撤销只移除目标副本，源文本保持不变。插入后更新目标 caret、同文档分屏视图、dirty、Find 与编辑器焦点。
- 没有 Rust、FFI ABI 或平台 GUI 核心改动；没有改变文件拖放或外部 provider 行为。
