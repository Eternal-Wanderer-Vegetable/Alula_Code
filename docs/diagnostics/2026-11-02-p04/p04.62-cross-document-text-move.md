# P04.62 / EDT-11d：跨文档文本移动与联动撤销

## 实现

- 跨文档 DropRequest builder 现在保留默认 Move 和显式 Copy；相同文档现有 Move 规则保持不变。工作台重读源 Rust 范围并校验源/目标文档、版本、UTF-16 范围及 payload；目标/源文档只在打开且可写、无冲突、无未提交输入或 IME 时接受移动。
- 源选区删除和目标插入复用 P02.7 `apply_workspace_edit` 单次 Rust workspace transaction；未修改 FFI ABI 或 Rust GUI 依赖。事务失败时 Rust 原子入口回滚，状态不会写入任何历史帧。
- 两个文档的操作历史写入同一 linked transaction id。Ctrl+Z / Ctrl+Y 从任一参与文档调用时，先确认两侧历史帧均在正确栈顶，再经同一 workspace transaction 同步应用；配对帧失配时拒绝且不改动文档。文档关闭、redo 分叉、局部或共享历史预算淘汰会成对移除历史帧。内部 Move 被拒绝时也会阻止 drag-completed 的外部源删除回退。
- 保持 P04.61 跨文档 Copy 与 P04.59 同文档 Move 的处理路径。
