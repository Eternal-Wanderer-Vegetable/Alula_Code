# P05.53 / feat-105 / LAY-16a — Explorer 树 type navigation（键入字符跳转）

## 拆分说明

docs/11 LAY-16（列表树表格控件）验收面较宽。Alula Explorer 树已具备：多选（Ctrl 切换）、
Shift 范围选、右键菜单、悬停高亮、键盘激活。本切片补齐 **type navigation（键入字符
跳转到匹配的可见项）**；筛选（filter）为 LAY-16b 独立切片；列 resize 不适用
（Explorer 为单列树，表格控件属后续列表/表格通用组件）。

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- 上游：WorkbenchList/type navigation——树获得键盘焦点后，键入字母序列在 500ms 空闲内
  累积缓冲，跳转到首个名称以缓冲开头的可见项并选中；修饰键组合（Ctrl/Cmd/Alt+字母）
  不参与 type navigation；超时后缓冲清空。

## 当前 Alula 行为与缺口

- Explorer 树无 type navigation：键入字符直达焦点所在编辑器。
- `_visibleExplorerFiles()` 提供扁平化可见文件列表；`_selectExplorerFile(node)` 提供
  选中态（多选高亮色呈现）。

## 登记范围

- 文件树 ListView 包裹 `Focus(key: explorer-tree-focus, focusNode: _treeFocusNode,
  onKeyEvent: _onTreeTypeAheadKeyEvent)`：树获得焦点后，字母 KeyDown/KeyRepeat 追加到
  500ms 空闲缓冲；匹配 `_visibleExplorerFiles()` 首个名称前缀命中项并
  `_selectExplorerFile` 选中（高亮呈现）；无匹配保留缓冲；修饰键组合忽略交还系统。
- 缓冲 Timer 在 workbench dispose 时取消（避免测试 pending-timer 不变量失败）。

## 排除（LAY-16b）

树筛选（filter UI）、列 resize（单列树不适用，表格控件另行）、数字/符号字符匹配、
非 Explorer 树控件（Open Editors 列表、搜索结果树）。

## N.2 验收

- focused widget tests：键入首字母选中匹配项；缓冲累积（'ma' 仍匹配 main.rs）；
  500ms 空闲后缓冲重置（'z' 匹配 zebra.md）；修饰键组合忽略；非匹配字符不移动选择。
- 完整本地 DoD 与 hosted PR CI / 三平台 Platform Availability。
