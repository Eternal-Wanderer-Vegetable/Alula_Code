# P05.51 / feat-103 / LAY-14 — Zen 模式（居中编辑器 + shell 隐藏）

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- 上游：`workbench.action.toggleZenMode`（View 菜单 / 命令面板）；Zen 模式隐藏标题栏、
  活动栏、侧栏（主/次）、面板与状态栏，编辑器居中限宽（zenMode.centerLayout）；
  Esc 退出；zen 状态跨窗口恢复（zenMode.restore）。

## 当前 Alula 行为与缺口

- 无 Zen 模式实现：标题栏/活动栏/侧栏/面板/状态栏恒渲染。

## 登记范围（含与上游的差异）

- `workbench.action.toggleZenMode` 命令 + View > 外观菜单项（checked 联动 `_zenMode`）。
- 进入 Zen：`setRegionCollapsed` 折叠 activity/sidebar/secondarySidebar/panel（进入前
  折叠态保存，退出恢复）；标题栏与状态栏经 build 条件 `if (!_zenMode)` 隐藏。
- 编辑器居中限宽：zen 下 WorkbenchGrid 包裹 Center+ConstrainedBox(maxWidth 1100)，
  仅渲染编辑器组（`_buildZenGrid` 通配 builders）。
- Esc 退出：Scaffold 级 CallbackShortcuts 在 `_zenMode` 时绑定 Escape → toggle
  （优先于编辑器局部 Esc 绑定）。
- 会话 journal 字段 `zenMode` 持久化；恢复时标题栏/居中直接进入 zen。

## 与上游的差异（如实登记）

- 上游 zen 全屏（window zoom/fullscreen）与本实现的「隐藏 shell + 居中限宽」不同；
  window zoom 属 P15 原生设备验收范畴。
- 上游 zenMode.hideActivityBar 等细粒度设置为 P07 settings 范畴，本切片固定全隐藏。
- compact 模式（zenMode.compact）未实现。
