# P05.55 / feat-107 / LAY-17b — QuickInput 分组分隔符、多选与描述/校验消息

## 拆分说明

docs/11 LAY-17（QuickInput 和多步 picker）验收面：「分组/多选/描述/detail/buttons/back/
校验/历史/取消及焦点恢复一致」。P05.54 已交付 buttons/back/取消及焦点恢复；本切片补齐
**分组（分隔符）、多选、`description` 独立列、`validationMessage`**；输入历史回填与
item 按钮 hover/键盘可达留 LAY-17c。

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- `QuickPickItemKind.Separator`：分隔行不可选、不接收方向键/Enter，点击无效；存在
  过滤查询时被隐藏（不参与匹配，分组标题随过滤消失）。
- `canSelectMany`：行首勾选；`Space` 切换当前项 `picked`；`Enter` 接受并回传
  `selectedItems`；`picked` 初始态在过滤变化后保留；多选下 item buttons 仍可用；
  未按 Space 时 Enter 返回已勾选集合（空集合也算接受）。
- `QuickPickItem.description`：与 label 同行、右侧暗色（命令面板的快捷键列、快速
  打开的路径列都属于它）；`detail` 是第二行说明。
- `validationMessage`：输入框下方的一条提示，不清空输入、不阻断方向键/取消。

## 登记范围

- `QuickItemKind { defaultItem, separator }` 与 `QuickItem.kind`；separator 行渲染为
  分组标题（key `qi-separator-<label>`），不进入可选列表：方向键跳过、Enter 不触发、
  点击无效；非空查询时从过滤结果移除。
- `QuickInput.show(..., canSelectMany: true, onAccept: (List<QuickItem> picked) {...})`：
  行首勾选标记（key `qi-check-<label>`）、`Space` 切换、`Enter` 接受并回传已选条目
  （按过滤后视觉顺序）；`QuickItem.picked` 提供初始态并在过滤后保留；单步 `onRun`
  语义在 `canSelectMany == false` 时完全不变。
- `QuickItem.description` 与 `detail` 分工：`description` 同行右侧暗色列，`detail`
  改到第二行（`detail` 第二行渲染以 label 下方小字号呈现）。
- `validationMessage` 参数：非空时在过滤行下方渲染（key `quick-input-validation`）。
- 接线：命令面板快捷键列与快速打开的路径列改走 `description`；条目 `detail` 留给
  第二行说明（现有调用点逐个迁移）；「移动视图」第一步按当前侧栏分组渲染分隔符
  （主侧栏/次侧栏），条目顺序按组内 `activityBarViewOrder`。
- 多选与 `validationMessage` 本切片以 widget fixture 验收；当前没有与上游对应的
  Alula 多选命令，产品接入留 LAY-17c 的 provider 路由（不伪造调用点）。
