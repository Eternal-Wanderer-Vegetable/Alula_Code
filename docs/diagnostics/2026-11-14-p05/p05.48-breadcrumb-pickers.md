# P05.48 / feat-100 / LAY-11b — 面包屑 picker（路径与符号）

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- 段点击路由：[`breadcrumbsControl.ts` _onSelectEvent](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/breadcrumbsControl.ts#L608-L653)——先激活所属组；FileItem（文件夹段）→ `BreadcrumbsFilePicker`（列出该目录子项），OutlineItem（文件段）→ `BreadcrumbsOutlinePicker`（列出文档符号）；选中项经 `_revealInEditor` 在编辑器中打开/定位。
- Picker 键盘：上下/Enter/Esc 由 picker 列表承载。

## 当前 Alula 行为与缺口

- 面包屑段点击仅 `_revealInExplorer`（侧栏唤起 + 文件树展开）；无 picker。
- 符号数据已有：`_refreshOutline`/`_outlineSymbols`（LSP symbols，kind/name/startUtf16/line）+ `_jumpToSymbol(startUtf16)`；文件树数据在 `_treeRoots`（TreeNode），文件打开走 `_openTreeFile`，目录展开走 `_toggleDir`。

## 登记范围

- 面包屑文件夹段点击 → 目录 picker（Material showMenu）：列出该目录的子文件夹与文件（来自 `_treeRoots` 对应 TreeNode）；选文件 → `_openTreeFile` 打开；选文件夹 → 在文件树中展开（保留原 reveal 行为）并关闭 picker。
- 面包屑文件段（末段）点击 → 符号 picker：列出该组活动文档的 LSP 符号（非焦点组按 doc.id 现场调用 `core.lsp.symbols`）；无符号时显示「未发现符号」空态项；选中 → 激活该文档并按 startUtf16 跳转（选区设置，镜像 `_jumpToSymbol`）。
- Picker 打开时激活面包屑所属组（对齐上游 activateGroup）。
- 键盘：showMenu 自带方向/Enter/Esc。
- 无 Rust/FFI 改动。

## 排除

- quickAccess 模式（上游 `_cfUseQuickPick` 分支，Alula 无该偏好）；面包屑显示开关/顺序设置（P07）；outline 跟随光标（CMD-07）。
