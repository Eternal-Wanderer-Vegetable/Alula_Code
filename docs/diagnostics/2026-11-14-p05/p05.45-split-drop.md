# P05.45 / feat-097 / LAY-10e — 拆分落点建组

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- 落点区域判定：[`editorDropTarget.ts` positionOverlay](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorDropTarget.ts#L386-L470)——编辑器拖动的边缘带为宽度/高度的 10%；中心区内不拆分；边缘区按默认水平偏好：x < 宽/3 → LEFT、x > 2·宽/3 → RIGHT、y < 高/2 → UP、否则 DOWN。
- 开关：[`editorDropTarget.ts` L184-188](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorDropTarget.ts#L184-L188)——part 选项 `splitOnDragAndDrop` 默认开启；`isToggleSplitOperation`（Windows/Linux Alt、macOS Shift）在拖动期间将其反转（关闭拆分区域，全部按中心合并处理）。
- 建组与落点：[`editorDropTarget.ts` handleDrop](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorDropTarget.ts#L252-L345)——有 splitDirection 时 `addGroup(groupView, direction)` 建相邻新组并作为目标；无 split 且 `sourceGroup === targetGroup` 直接返回（同组拆分落点允许建组）；复制修饰键 + 拆分 → 复制进新组；落点后目标组获得焦点。
- 移动/复制进新组沿用 [`editorGroupView.ts` doMoveOrCopyEditorAcrossGroups](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorGroupView.ts#L1471-L1508)（pinned: true、复制不携带 sticky、源组编辑器不关闭 keepCopy）。

## 当前 Alula 行为与缺口

- P05.44 之后组级 `DragTarget<int>` 已包裹组面板（`editor-drop-area-<region>`），落点一律按中心区追加；不存在拆分区域，边缘落点不会建新组。
- 拆分布局已有既有机制：`_layout.splitRegion(region, fresh, axis, insertBefore)` + `_ensureGroupsFromLayout()`（方向移动命令 `_moveFocusedEditorToGroup` 在无相邻组时即用此路径建组）。
- P05.44 的 `_handleGroupAreaDrop` 已解析源组并路由 move/copy；本切片在此之上加入区域判定与建组。

## 登记范围

- 在组级落点处理中加入区域判定（编辑器拖动：边缘带 10%；x < 宽/3 → 左、x > 2·宽/3 → 右、y < 高/2 → 上、否则下；中心带 → 追加）。
- 拆分开关：Windows/Linux Alt、macOS Shift 在拖动期间禁用拆分区域（整组按中心追加处理），对齐上游 toggle 语义。
- 边缘落点：以目标组为基准按方向 `splitRegion` 建相邻新组（左/上 insertBefore，右/下追加），`_ensureGroupsFromLayout` 同步组映射后把被拖文档移入新组（index 0）并激活新组与文档；同组边缘落点同样允许建组。
- 复制修饰键 + 边缘落点 → 复制进新组（未命名文档仍回退移动）。
- 持久化走既有 `_scheduleStateSave` 路径；拆分布局经既有 `layoutStore` 保存路径随会话恢复。
