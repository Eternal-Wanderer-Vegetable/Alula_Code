# P05.46 / feat-098 / LAY-10f — 关闭组的 MRU 组激活与方向邻居 MRU 决胜

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- 关闭空组激活：[`editorPart.ts` doRemoveEmptyGroup](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorPart.ts#L853-L861)——被移除组是活动组时，激活 `mostRecentlyActiveGroups[1]`（剩余组中最近活动的组），而非网格首组。
- 方向邻居 MRU 决胜：[`editorPart.ts` doFindGroupByDirection](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/editorPart.ts#L374-L382)——几何邻居按 `mostRecentActiveGroups` 顺序排序取第一个。
- 文档/11 LAY-10 验收项 "overflow/MRU" 的 MRU 即此组激活顺序语义；overflow 的滚动/显现行为 Alula 已有（可滚动标签条 + 活动标签自动显现，P05.31/P05.42 登记），溢出边缘装饰归 LAY-20 overlay 行。

## 当前 Alula 行为与缺口

- `_closeDocNow` 移除空组后 `_focusedRegion = _groups.keys.first`（插入序首组）；`_moveDocAcrossGroups`/`_closeDoc` 的组摘除同样落到首组。上游语义是最近活动组。
- 组的激活顺序已有跟踪：`_noteActiveDocument` 维护 `group.lastActivationOrder = ++_editorActivationClock`。
- `_adjacentEditorRegion` 的方向邻居决胜链（alongGap → acrossGap → acrossCenter）没有 MRU 决胜：多个等距方向邻居（如右侧上下两组）时按几何中心取，而非最近活动。

## 登记范围

- 新增 `_mostRecentlyActiveRegion({String? excluding})`：按 `lastActivationOrder` 取剩余组中最近活动的组。
- `_closeDocNow` 摘除空组且被摘组是焦点组时，焦点落到 `_mostRecentlyActiveRegion(excluding: owner.region)`（对齐 doRemoveEmptyGroup）；组摘除后无剩余组时回退现状。
- `_adjacentEditorRegion` 在 alongGap/acrossGap/acrossCenter 全部相等时以 `lastActivationOrder` 较高者优先（对齐 doFindGroupByDirection 的 MRU 排序）。
- 既有方向移动命令、关闭路由、P05.44/45 落点语义保持不变。

## 排除

- 溢出边缘装饰视觉（LAY-20）、`preferSplitVertically` 等偏好、编辑器数量上限设置（P07 settings 范畴）。
