# P05.52 / feat-104 / LAY-15 — 跨编辑器锁定滚动（Toggle/Hold + 状态栏）

## 固定基线与上游行为

- 基线：Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。
- docs/11 LAY-15 验收："Toggle/Hold locked scrolling及状态栏、不同文档长度/组/窗口
  正确"。上游 Code-OSS 无内建跨编辑器锁定滚动（属扩展能力），本切片按 docs/11
  验收要求实现 Alula 特性。

## 登记范围

- `workbench.action.toggleLockedScrolling` 命令 + 状态栏锁定图标（lock/lock_open，
  key `status-bar-locked-scrolling`，点击切换）。
- Toggle 开启时：任一编辑器纵向滚动 → 其他组活动文档按滚动比例同步
  （offset/maxScrollExtent 比例，适配不同文档长度）；防反馈环（_scrollSyncInProgress）。
- Hold 模式：toggle 关闭时按住 Alt 滚动临时同步一次（HardwareKeyboard.isAltPressed）。
- 同步监听常挂（编辑器 build 时幂等补挂），回调内判断开关。
- 会话 journal 字段 `lockedScrolling` 持久化。
