## 登记范围

对某文件文档标签从非空源组拖到另一非空组标签上、drop 时按住平台复制修饰键：

- Windows/Linux 读 Ctrl、macOS 读 Alt（与 `editor_native_text_drag_drop.dart` 同一惯用法），在 `onAcceptWithDetails` 时刻读取。
- 仅文件文档（`path != null`，对应上游 Singleton/Untitled 能力位）可复制；未命名文档按上游回退为移动。
- 复制生成 `OpenDoc.viewOf(moving)` 同文档新视图插入目标组：位置按指针在目标标签中点前/后决定并 clamp 到普通分区；复制视图不是 sticky（即使源标签 sticky）、也不是 preview（即使源标签为干净预览）；源组文档/顺序/sticky/preview/活动态完全不变。
- 目标组已显示同一文档时仅激活既有视图（不插入新标签、不改变源组）。
- 激活复制的视图并把焦点/`_focusedRegion` 移到目标组（对齐上游 `targetGroup.focus()`）；源组活动态不动。
- 同组 drop 维持既有行为（复制修饰键被忽略，等价于同组重排）。
- 复制的视图经既有 `_scheduleStateSave`/`_normalizeStickyOrder`/`_syncCommandContext` 持久化与上下文同步；`OpenDoc.viewOf` 携带源视图选区/折叠，Rust 文本、脏标、savepoint、撤销历史经共享文档天然随行。
- 会话恢复沿用既有同 id 多视图路径，验证恢复后两组各持一个同 id 视图。
