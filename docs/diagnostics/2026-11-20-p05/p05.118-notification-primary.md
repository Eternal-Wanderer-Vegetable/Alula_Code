# P05.118 / feat-170 · LAY-18 通知主操作执行与收起

依赖 P05.117 / feat-169。[通知展开折叠与持留](p05.117-notification-disclosure.md)

## 实现

- toast 和中心主按钮通过同一通知模型入口执行操作。核对条目身份和所属操作后，立即移除默认关闭的条目并执行回调。再次触发已移除的条目时跳过回调。
- 明确设置 `keepOpen` 时保留条目。会话 journal 的重试只调度下一次写入，所以会话保存警告继续可见，失败期间仍合并提示。
- 主、次操作共享错误呈现。异步失败生成同一来源的新错误，通知中心已销毁时结束错误回调。只读文件通知的“另存为”仍进入原有对话框，选择该按钮后原通知收起。

固定版主按钮的动作运行器在启动操作后关闭原条目，选择可显式声明保持。[固定版主按钮](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsViewer.ts#L524-L581)
