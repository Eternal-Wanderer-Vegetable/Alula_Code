# P05.130 / feat-182 · LAY-17 QuickInput 多选批量控制与确认

依赖 P05.55、P05.72、P05.129。[前置分组导航](p05.129-quick-input-groups.md)

- 多选面板提供匹配项复选框、总选中数和确认按钮。部分匹配项被勾选时显示未勾选。点击选中当前所有可选匹配项，再次点击清除这些选择。过滤排除的已选项继续计入总数。分隔标题和禁用项不参与批量操作。
- 鼠标点击批量复选框后，输入框继续接受输入。确认按钮和 Enter 共享一次性接受路径。静态条目按原始顺序回传。异步 provider 条目在过滤改变后仍能回传已经勾选的对象。
- 空结果时复选框保持未勾选，点击无效果。固定版在零命中时短暂显示为已勾选，其选中数与已选数据不变。这里按实际选择状态显示。
