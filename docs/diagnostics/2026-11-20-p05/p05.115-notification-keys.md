# P05.115 / feat-167 · LAY-18 通知显隐命令与焦点恢复

依赖 P05.114 / feat-166。[通知中心和 toast 生命周期](p05.114-notification-lifecycle.md)

## 实现

- 注册 `notifications.showList`、`notifications.hideList`、`notifications.toggleList` 和 `notifications.hideToasts`。铃铛通过切换命令打开或收起中心。显示命令重复执行时保持中心打开。
- Windows/Linux 使用 Ctrl+K Ctrl+Shift+N，macOS 使用 Cmd+K Cmd+Shift+N。编辑器内外共用组合键解析和用户自定义键位。编辑器外的组合键入口只接受本项的显示通知命令。
- Escape 根据中心和 toast 可见状态关闭当前表面。焦点位于通知表面时，关闭或清除最后一条后恢复活动编辑器。编辑器查找与中心同时打开时，Escape 先关闭中心并保留查找；只有 toast 时先关闭查找。
- 既有通知切换键位可继续使用。[固定版显隐命令](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCommands.ts#L114-L143) · [固定版 toast Escape](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCommands.ts#L233-L250) · [固定版中心焦点恢复](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCenter.ts#L375-L399)
