# P05.102 / feat-154 · 单条通知清除快捷键

固定 Code-OSS 提交 `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 对 `notification.clear` 使用 `notificationFocus` 条件，Windows/Linux 为 Delete，macOS 为 Cmd+Backspace。命令清除当前焦点对应的通知，活动进度受到保护。[快捷键与处理器](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCommands.ts#L145-L163)

Alula 通过现有工作台命令注册和默认键位表接入，支持用户通过 keybindings.json 重绑。打开有通知的中心时聚焦首条，toast 可通过 Tab 获焦。行按通知 ID 保持焦点，插入新条目时原焦点仍指向同一条。面板已打开后收到新通知时保留当前焦点。执行前重新核对焦点所属条目、当前 model identity、活动进度和对应界面可见性。键盘在 toast 清除整条通知，toast 关闭按钮沿用原有的仅收起 toast 行为。焦点监听由工作台注册和释放，列表沿用现有容量上限。
