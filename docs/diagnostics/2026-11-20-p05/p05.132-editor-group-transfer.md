# P05.132 / feat-184 · LAY-07 整组方向移动与复制

依赖 P05.28、P05.29、P05.43、P05.131。

- 注册 `workbench.action.moveActiveEditorGroup{Left,Right,Up,Down}` 和 `workbench.action.duplicateActiveEditorGroup{Left,Right,Up,Down}`。移动默认使用 Windows/Linux 的 `Ctrl+K` 后方向键，macOS 使用 `Cmd+K` 后方向键。没有同向邻组时依次检查固定版的正交方向，只有一个组时移动无操作。
- 移动在一次布局变更中移动已有叶子，保留组身份、标签、活动文档和 Rust 编辑视图。复制组保持标签顺序、活动项、预览与固定信息。复制后共享权威文档，各组维护独立输入窗口、焦点节点和滚动控制器。
- 实机发现复制组获得焦点时，Flutter 的光标揭示会覆盖原滚动偏移。组移动、复制在焦点通知后的布局帧恢复活动视图偏移。移动时按新视口范围限制偏移。已有单标签或单活动文档的打开仍使用其原滚动入口。
