Alula 在键位、通知中心行关闭按钮和批量清除成功后，向当前 Flutter 视图发送原生辅助播报，并调用系统 alert 提示音。播报为「通知已清除」或「已清除 N 条通知」。每次有效批量操作提示一次，N 取实际移除数。活动进度、空清除、收起 toast、中键和到期不触发提示。系统提示音由平台决定，独立的提示配置仍随 P14 跟踪。原生接口不可用时，清除结果仍生效。

Windows 和 macOS 使用 Flutter 的平台语义状态。Flutter Linux 默认开启语义树，因此 Linux runner 每次有有效清除时额外读取会话 D-Bus 的 `org.a11y.Status.ScreenReaderEnabled`。读取异步，属性查询超时为 500 ms，不自动启动服务。读取失败或状态关闭时保持静默。[Flutter Linux 引擎](https://github.com/flutter/flutter/blob/737ba8f885dc774b53b442759999a312c9461e4e/engine/src/flutter/shell/platform/linux/fl_engine.cc#L925-L933)
