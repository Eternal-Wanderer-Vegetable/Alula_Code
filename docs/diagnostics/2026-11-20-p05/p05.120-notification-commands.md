# P05.120 / feat-172 · LAY-18 清除全部和全局勿扰固定命令

依赖 P05.119 / feat-171。[通知铃铛状态、后台进度与可见标记](p05.119-notification-bell.md)

## 实现

- 命令面板和通知中心工具栏接通 `notifications.clearAll`、`notifications.toggleDoNotDisturbMode`。统一沿用清除、原生清除反馈、活动进度保留、全局勿扰和状态保存逻辑。
- 两个旧 ID 作为查找别名继续执行相同命令。命令面板每项显示一行。没有规范 ID 的自定义键位时，面板沿用旧 ID 的快捷键提示。
- 载入命令历史时把旧 ID 映射到规范 ID，按原顺序去重。下次命令面板执行时保存规范 ID，兼容已有 journal。

固定版本将两个 ID 注册到命令面板。清除时先关闭中心，再逐条清除无活动进度的通知。[固定命令](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCommands.ts#L296-L356) · [固定清除规则](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCenter.ts#L455-L468)
