## 实现

| 优先级 | Toast 准入 |
| --- | --- |
| 常规 | 信息和警告受全局及来源勿扰规则限制，错误照常弹出。 |
| 静默 | 保留在通知中心，包含显式标记为静默的错误。 |
| 紧急 | 新通知绕过全局及来源勿扰。设置来源勿扰时保留现有紧急 toast。开启全局勿扰会先收起当前全部 toast。 |
| 可选 | 在常规规则之上，获焦可编辑控件的左上角位于当前通知角落时抑制 toast。依据工作台窗口的一半宽和高区分左下、右下、右上。 |

四种优先级的通知均保留在中心。可选通知的焦点判定只在接收该通知时执行。工作台挂载时安装判定，销毁时移除。[固定版优先级规则](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/common/notifications.ts#L510-L521) · [固定版可选 toast 与角落计算](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsToasts.ts#L194-L249)
