## 组合键与范围

- 默认组合键为 Windows/Linux `Ctrl+Shift+A` 和 macOS `Cmd+Shift+A`，仅在屏幕阅读器模式开启且有获焦通知或 toast 时执行该命令。焦点或通知在查询期间改变时丢弃原请求。
- 默认组合键检查前先保留可用的用户绑定。屏幕阅读器关闭时，Linux 编辑器的块注释可继续执行。自定义通知主操作键和命令面板沿用 P05.123 的规则。
- Windows 和 Linux 使用现有 `alula/accessibility` 通道按需读取状态，macOS 读取 Flutter 的 `accessibleNavigation`。Windows 查询当前会话的 Narrator 进程及 SPI 屏幕阅读器标记，查询入口直接返回状态。
