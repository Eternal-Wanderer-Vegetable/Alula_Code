# P05.127 / feat-179 · LAY-17 QuickInput 分页与首尾导航

依赖 P05.54、P05.55、P05.72 和 P05.84。

## 行为

- 在选择器列表内处理 `PageDown`、`PageUp` 和 `Ctrl+Home`、`Ctrl+End`。先定位当前视口中完全可见的外侧条目，抵达该侧后再翻页。首尾组合键跳过分隔标题。普通输入框保留文本键位。
- 每次应用导航都使用实际渲染高度，支持 description 和 detail 混排。输入框保持焦点，连续分页后再接受或勾选当前条目。过滤及新结果会使旧的分页请求失效。
- 使用原有惰性列表与滚动控制器。首尾跳转等待当前列表修正估算的最大滚动范围。现有预览及接受回调继续由 QuickInput 调用。
