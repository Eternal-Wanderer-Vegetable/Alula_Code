# P05.119 / feat-171 · LAY-18 通知铃铛状态、后台进度与可见标记

依赖 P05.118 / feat-170。[通知主操作执行与收起](p05.118-notification-primary.md)

## 实现

- 状态栏铃铛用圆点提示未读和后台进度。中心及 toast 都关闭时计入活动进度，任务完成后当帧更新提示。条目与未读仍由通知中心持有。
- 中心打开时显示顶部三角标记和关闭提示。全局勿扰保留开启时的圆点规则并切换静音图标和提示。顶右位置的标题栏入口使用固定提示。
- 状态栏保留稳定的通知按钮语义名。活动进度监听仅挂在需要显示状态的状态栏入口，受既有 100 条通知上限约束。中心或弹窗出现、相关条目移除、状态栏入口卸载时，解除相应监听。

固定版使用未读和后台活动进度决定铃铛圆点，中心打开时显示三角标记。顶右位置的标题栏项固定为切换命令。[固定版状态栏逻辑](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsStatus.ts#L69-L183) · [固定版标题栏项](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCommands.ts#L359-L374)
