# P05.131 / feat-183 · LAY-07 编辑器组尺寸重置与最大化恢复

依赖 P05.28、P05.29、P05.89。

- `workbench.action.evenEditorWidths` 按嵌套分割轴重置编辑器组比例。连续同轴子组依据列或行的数量分配权重，分割条仍占其原有尺寸。停靠区域不参与分配。重置写回会话布局。
- `workbench.action.toggleMaximizeEditorGroup` 从命令面板或 Windows/Linux 的 `Ctrl+K Ctrl+M`、macOS 的 `Cmd+K Cmd+M` 触发。组标题的还原按钮和重复命令使组回到原大小。最大化占用当前编辑器区，保留外部区域。隐藏组保持挂载且不参与输入焦点，最大化前后的保存布局一致。重置命令会先退出最大化，切换活动组时也会退出最大化。
- 同一布局的两个拖拽轴、活动输入视图和非活动视图由实测夹具记录。方向移动整组、整组复制、Expand 和 Lock 继续按 docs/03 推进。
