# P05.128 / feat-180 · LAY-17 QuickInput 默认视口与行密度

## 行为

- 列表宽度按窗口宽度的 62% 调整，上限 600 逻辑像素。视口按窗口高度约 40% 取整为 44 逻辑像素的行组，再保留下一行的提示空间。
- 普通行和 detail 行在默认文字大小下分别为 22 和 44 逻辑像素。行尾按钮显示时保持相同行高，较大的文本缩放可增加行高。多选复选框、分组标题和活动行都参与布局，行尾按钮可用 Tab 和 Enter 操作。
