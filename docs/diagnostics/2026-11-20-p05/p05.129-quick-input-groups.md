# P05.129 / feat-181 · LAY-17 QuickInput 分组键盘跳转

依赖 P05.55 与 P05.128。[默认视口与行密度](p05.128-quick-input-density.md)

## 行为

- Windows/Linux 在选择器中使用 `Alt+Up/Down` 或 `Ctrl+Alt+Up/Down`，macOS 使用 `Cmd+Up/Down` 及其 Option/Control 变体。键位从当前项跳至相邻组首，从组内项向前可回到当前组首，首尾分组可循环。
- 空分组和尾部分隔标题会被跳过。过滤隐藏分隔标题后，从首项向下跳到尾项，再次向下回到首项。输入框保有焦点，现有预览、选择和接受由实际活动项驱动。
- 跳至视口外的组首时先估计滚动位置，再使用当前渲染信息校正。真实指针移动才会选择悬停条目，列表滚动经过静止指针时维持当前的键盘选择。
