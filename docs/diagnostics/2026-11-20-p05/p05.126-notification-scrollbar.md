# P05.126 / feat-178 · LAY-18 通知中心滚动条

依赖 P05.125 / feat-177。P05.121 已校准视口和行密度，滚动条在指针悬停时的外观仍有差异。[通知中心密度](p05.121-notification-density.md)

## 行为

- 通知中心用一个本地滚动控制器和 Flutter 滚动条覆盖层。长列表在指针进入视口或滚动时显示 8 逻辑像素宽的滑块，拖动越出视口期间保持可见。离开或滚动停止后收起，短列表无可见滑块。
- 滑块正常、悬停与按住状态按固定默认深色样本校准。保留 400 逻辑像素视口、列表的惰性构建和滚轮路径。滚动条随中心列表销毁，不增加定时查询及产品常驻状态。
