# P05.122 / feat-174 · LAY-18 通知中心勿扰配置菜单

依赖 P05.121 / feat-173。[通知中心默认密度](p05.121-notification-density.md)

## 实现

- 通知中心工具栏打开配置菜单。全局勿扰选项经现有规范命令执行。按系统区域顺序显示前十个来源，勾选表示接收该来源的所有通知。选择来源时按稳定 ID 更新，并使用打开后读到的当前设置。
- 只有超过十个来源时出现“更多来源…”。它进入现有按来源多选界面。菜单与多选共用排序，原有持久化和通知准入规则继续接管配置。
- 沿用 `intl4x` 的懒加载排序器，每进程一个固定实例，排序集合受既有 100 个来源上限约束。打开菜单或完整选择器时才排序。

固定版工具栏的配置菜单显示全局选项、前十个来源及更多入口。[菜单行为](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCenter.ts#L241-L276) · [完整选择器](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCommands.ts#L311-L345)
