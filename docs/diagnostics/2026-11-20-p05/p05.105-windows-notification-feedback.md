# P05.105 / feat-157 · Windows 清除通知播报去重与静默

P05.104 已交付清除通知反馈。原版 Windows 11 实机对 Delete、单条按钮、全部清除各记录两条相同的 Narrator 语音回顾，并在没有 Narrator 进程时继续播放系统提示音。[原实机记录](p05.104-windows-native-clear.md) · [证据提交的收尾 CI](https://github.com/Eternal-Wanderer-Vegetable/Alula_Code/actions/runs/44666989506)

固定版 Flutter 3.47.8 的 Windows 警报同时发出 MSAA 和 UIA 系统警报。Flutter 收到 Windows 无障碍对象查询时开启语义树，Narrator 退出并不清空这个标志。Microsoft 说明 Narrator 不设置 `SPI_GETSCREENREADER`，本机启用 Narrator 时也读到 false。[Flutter 警报实现](https://github.com/flutter/flutter/blob/737ba8f885dc774b53b442759999a312c9461e4e/engine/src/flutter/third_party/accessibility/ax/platform/ax_platform_node_win.cc#L593-L624) · [Flutter 语义启用](https://github.com/flutter/flutter/blob/737ba8f885dc774b53b442759999a312c9461e4e/engine/src/flutter/shell/platform/windows/flutter_window.cc#L882-L906) · [Windows 屏幕阅读器参数](https://learn.microsoft.com/en-us/windows/win32/winauto/screen-reader-parameter)

有效清除时，Windows runner 核对当前登录会话中系统目录的 `Narrator.exe`，通过由主窗持有的隐藏 Win32 文本控件只发送一个 `EVENT_SYSTEM_ALERT`，并播放一次 `MessageBeep(MB_OK)`。进程快照随查询关闭，主窗仅持有一个无 Tab 停靠的提示控件。没有 Narrator 时，明确注册为活动的其他屏幕阅读器仍可使用既有 Flutter 路径。直接 UIA 通知在本机的尝试没有进入语音回顾；选择单一 Win32 事件前，已独立核对隐藏文本控件的读回。[Microsoft WinEvent API](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-notifywinevent)
