## 实现

- 按稳定来源 ID 绑定配置。现有工作台和文件通知使用各自的 ID，显示名称沿用原有文案。同名来源在选择器中用 ID 区分。来源改名后，原 ID 的勿扰偏好继续生效。
- 命令面板的「按来源切换请勿打扰」使用固定版命令 ID `notifications.toggleDoNotDisturbModeBySource`。选择器默认勾选接收全部通知的来源，确认时应用，Escape 取消。带次级操作且来源已识别的通知也能从「更多操作」直接切换自己的来源。
- 屏蔽选定来源后，撤出现有信息与警告 toast，后续信息和警告进入中心。错误与其他来源按正常规则弹出。解除屏蔽后，已撤出的 toast 不补发。全局勿扰和来源偏好均参与准入。[固定版来源选择](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCommands.ts#L312-L345) · [固定版单条菜单](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsViewer.ts#L252-L285) · [固定版 toast 过滤](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsToasts.ts#L144-L154)
- 来源及其选项保存在会话 journal 的 `notifications.perSourceDoNotDisturbMode`，最多保留 100 项，与通知默认容量一致。仅在来源快照变化时合并写入原有防抖保存。恢复时检查字段类型，同时保留已观测的当前来源名称。正式配置作用域继续由 P07 跟踪。
