# P00.4 WSLg 主应用 cgroup 交互探索（2026-10-29）

## 范围

该记录中的早期单轮探索使用 WSLg、Xvfb、Flutter Linux Release 主应用、独立临时 HOME 与复制的 `rust-mini` fixture。早期启动命令把 `xvfb-run` 放在 `systemd-run --scope` 外，因此 Xvfb 未计入这些旧单轮 cgroup 限额；旧样本不能当作 Xvfb 也受限的测量。后续重复矩阵改为由 scope 启动 `xvfb-run`，将 Xvfb、主应用及子服务全部置于同一 cgroup v2，并设置 `memory.swap.max=0`。应用以 `--lsp-auto` 启动；Rust Analyzer 使用已安装的 WSL stable toolchain。GUI 输入经 Xvfb/xdotool 注入，不操作用户桌面窗口。新矩阵与逐轮结果见 `p00.4-wsl-main-app-cgroup-matrix.md` 和同名 JSON。

为完成 GUI smoke，已从 Ubuntu 官方 apt archive 安装 Xvfb、xdotool、netpbm 与 GTK/Flutter 所需 Linux desktop 依赖；Flutter stable 3.47.8、Rust stable 1.99.1 和 rust-analyzer 组件均可用。

## 结果

| 场景 | 结果 | 关键数据 |
|---|---|---|
| 512 MiB，无 LSP | 通过一次 | marker `ALULACGROUP512RUN4` 与文件 SHA-256 改变；`memory.current` 编辑后 293,056,512 bytes（279.4 MiB）；swap=0；所有 memory.events 计数为 0；应用退出码 0。截图：`p00.4-wsl-linux-cgroup512-save-run4.png`。 |
| 512 MiB，Rust Analyzer | 失败一次 | 首次配置错误的启动未计入。修正隔离 HOME 的 Rustup/Cargo 路径后，scope 观测到真实 `rust-analyzer` 进程；systemd 报告 45.670 秒后因 `oom-kill` 终止 scope。未形成可计入的编辑保存样本。 |
| 1 GiB，Rust Analyzer | 通过一次 | scope 观测到真实 `rust-analyzer`；marker `ALULALSPCGROUP1024RUN1` 与文件 SHA-256 改变；编辑后 `memory.current` 892,416,000 bytes（850.9 MiB），71 个采样的峰值 903,749,632 bytes（861.9 MiB）；swap=0，所有 memory.events 计数为 0；应用退出码 0。 |

成功运行退出日志仍有 `FlutterEngineRemoveView returned kInvalidArguments`。加入标题栏 close-in-progress guard 后，应用进程退出码为 0；该 Flutter 引擎 warning 仍存在，不能将关闭路径描述为无告警。

## 证据与边界

- 512 MiB 无 LSP：`p00.4-wsl-linux-cgroup512-save-run4.txt`、`p00.4-wsl-linux-cgroup512-save-run4.png`
- 512 MiB Rust Analyzer OOM：`p00.4-wsl-linux-rust-lsp-cgroup512-run2.txt`；systemd scope 名为 `alula-p00-linux-lsp512-run2-563990.scope`，systemd 最终状态为 `oom-kill`，运行时长 45.670 秒
- 1 GiB Rust Analyzer 交互：`p00.4-wsl-linux-rust-lsp-cgroup1024-run1.txt`

每个有效场景只有一次运行。结果只能说明这套 WSLg/Xvfb 软件渲染环境中，Rust Analyzer 工作负载在 512 MiB 失败、1 GiB 单轮成功；不能据此认定全产品最低可工作档，也不能替代 docs/04 要求的每档至少三轮、完整 30 分钟编辑/10 分钟空闲、服务进程树采样和 Windows Job Object 对照。真实 DRM/WPE GBM、官方 Microsoft 服务身份/许可、Windows Rust+RA 500 MiB 目标及完整跨平台内存验收仍未解决，P00.4 继续 blocked，P01 不启动。
