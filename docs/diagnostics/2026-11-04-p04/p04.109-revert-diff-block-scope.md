## Pinned Code-OSS contract

The pinned editor registers `diffEditor.revert` as an F1 command without a default keybinding. In a diff editor it exposes `Revert Block` in the hunk toolbar and `Revert Selection` in the selection toolbar, gated on the modified side being writable and using the proper inline/side-by-side icon. Toolbar invocation resolves the diff editor by original and modified URIs and passes the mapping's `innerChanges`; the command uses those ranges to restore original text into the modified model. The command-palette/editor action instead requires an up-to-date diff, modified-side text focus, and reverts the full line mappings intersecting the caret or selected line range. Upstream wraps the resulting edit set in undo stops.

Pinned sources: [`diffEditor.contribution.ts` toolbar registration](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/browser/widget/diffEditor/diffEditor.contribution.ts#L32-L67), [`commands.ts` `RevertHunkOrSelection`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/browser/widget/diffEditor/commands.ts#L171-L197), and [`diffEditorWidget.ts` edit behavior](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/browser/widget/diffEditor/diffEditorWidget.ts#L674-L712).

## Alula baseline and boundary

P04.105–P04.108 now open a side-by-side compare with a frozen original string and a Rust-backed editable modified document. `SnapshotComparePreview` renders aligned, bounded `DiffViewRow`s and the modified editor, but has no per-hunk/selection toolbar or `diffEditor.revert` command. The Rust document is already the source of truth; changes must continue through its versioned edit path, not through a widget-owned replacement string.

This slice adds only single-comparison restore actions: block toolbar restore for a selected diff block, selection toolbar restore for the selected changed mapping, and the `diffEditor.revert` command for blocks intersecting the modified-side caret/selection. The original side and the source snapshot (clipboard or disk) remain immutable. The current `DiffViewModelResult` must be exact and match the modified document revision; a busy/stale/approximate/over-budget comparison, active IME composition, closed document, or mismatched resource identity disables or rejects the complete operation. A successful operation is one version-checked Rust edit transaction, with a single undo grouping boundary, normal sibling-view synchronization, and save/read-back behavior.

Out of scope: applying content to the original side; SCM stage/unstage; merge editor accept/combine/conflict routes; multi-file Multi Diff; changing the diff algorithm/model; FFI, ABI, or save protocol changes.
