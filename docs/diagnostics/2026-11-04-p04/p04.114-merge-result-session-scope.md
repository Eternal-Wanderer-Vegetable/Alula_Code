## Why this slice

P04.111 added the GUI-free three-way projection, P04.112 exposed it through ABI v38, and P04.113 added ABI v39 UTF-16 ranges into the current projected result. The remaining gap is the stateful result working copy: the current merge API is stateless, and no merge session owns a Rust result document, savepoint, unresolved-conflict close decision, or disposal lifecycle.

This slice creates that session/lifecycle layer before adding the visible four-pane Merge Editor. It must reuse the current Rust document authority and save behavior; it must not create a second Dart-owned full-text authority.

## Included

- A bounded merge-session model freezes the base/input1/input2 snapshots for the session and uses the existing ABI v39 `AlulaMergeApi` projection.
- Exactly one Rust `OpenDoc` owns the result text. Result conflict ranges/counts are accepted only when their projected text and document version match Rust's authoritative full text.
- Conflict-choice projection updates are applied to the result document as one checked transaction; stale document/session state rejects the whole update.
- Dirty and savepoint state come from the result document. Successful atomic disk save advances the baseline; failed save leaves dirty/savepoint unchanged. Revert restores the latest successful savepoint.
- Closing is modeled as explicit outcomes: a dirty result offers Save with Conflicts, Don't Save, or Cancel; a clean result with unresolved conflicts requires explicit close confirmation; cancel preserves the session and result.
- Closing/disposal releases the session's temporary snapshots and result-document registration exactly once.

## Excluded

- Git merge discovery, parsing conflict markers from Git output, SCM staging, or branch selection.
- Visible four-pane layout, command/keybinding registration, conflict navigation, combination UI, Multi Diff, and persisted “close with conflicts” preference. A later EDT-19 slice will connect this session to the Merge Editor surface.
- ABI changes, generic `DocRegistry`/`AlulaDoc` contract changes, unbounded full-text Dart caches, and numeric memory optimization.

## Acceptance evidence required

- Freeze all three inputs; per-conflict and accept-all resolutions update the same Rust result document.
- After every projection change, current result ranges slice to their claimed base/input contribution in UTF-16, including emoji surrogate pairs, BOM, CRLF/CR/LF, empty insertions, and final-newline variants; the complete Rust document equals the projected result.
- Two views of the result remain synchronized. Save/read-back, failed-write dirty state, revert, and undo/redo preserve the existing document invariants.
- Dirty close: save-with-conflicts persists and closes only after successful save; don't-save reverts before close; cancel preserves the current text and dirty state. Clean-but-unresolved close requires confirmation. A failed/cancelled decision leaves the session registered and usable.
- Session teardown releases the result document and snapshots; repeat open/close does not leave extra Rust documents or watchers.
- Full local DoD, PR CI, Linux/Windows platform availability and package lanes pass. macOS hosted package evidence is required; native macOS GUI interaction remains a P15 device gate.
