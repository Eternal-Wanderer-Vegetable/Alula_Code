## 已登记的本 slice DoD

- 提供 `workbench.files.action.compareWithClipboard` 命令面板入口及 Ctrl/Cmd+K, C chord；仅在当前活动文本资源可比较时显示/执行。
- 异步读取 clipboard 前获取 Rust 权威全文、活动文档 id/version/resource；读取后再次检查身份与版本。若工作区/活动文档已切换、关闭或被编辑，取消打开并给出可见反馈，避免混合不同时刻的文本。
- 以 clipboard 快照作为 original、活动文件快照作为 modified，打开固定且可关闭的 side-by-side preview；两侧只读，文本选择可用。预览关闭后清除临时模型/provider，不创建文件，不将剪贴板内容写入 session、recent、history 或磁盘。
- 复用 `DiffViewModel` 与已有计算预算；输入/行/row/work 超限时显式显示不可比较原因，禁止局部 diff 或静默截断。Emoji/代理对、CRLF、BOM、空 clipboard、无差异和异步竞态均有测试。
- preview 不更改 Rust text/version、selection、undo/redo、dirty/savepoint 或磁盘内容；不改 Rust、FFI ABI 或协议。
- 此 slice 右侧为只读快照。右侧编辑与 live sync、Explorer 选中文件比较、compare with saved、apply/revert blocks、three-way merge 和 Multi Diff 均不在范围内，后续分别登记。
