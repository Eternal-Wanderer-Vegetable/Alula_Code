# P04.101 / EDT-17i：Git unified diff 首尾空白等价

日期：2026-11-04
状态：实现已推送；本地 DoD、PR CI、Linux/Windows/macOS hosted build/package/startup 验收通过；macOS 原生 DnD 因 hosted pointer route 不可用而 skip。

## 实现

- Git Diff 视图现在用既有 `computeDiffViewModel` 按 hunk 分别对齐原文/修改文，沿用 Code-OSS 默认 `ignoreTrimWhitespace: true`。首尾空格或 tab 等价的行在 inline 中只显示修改后文本、采用中性样式、不产生 word range 或导航目标；side-by-side 保留两侧文本与行号并采用中性样式。行中间的空白变化仍是差异。
- 每个 hunk 独立建模，不跨 hunk 配对。投影保留 metadata、hunk header、EOF marker、源行号、可选择文本和 patch 源顺序；旧/新替换行在 inline 中按原 patch source row 排序，避免 marker 被移到另一侧行之后。
- source row 映射不完整、marker 对齐不一致、解析失败或任何模型预算耗尽时，放弃整个投影并显示原始完整 patch。累计复用/施加 2,000,000 UTF-16 code units、16,384 source rows、16,384 projected rows 上限；每 hunk 的 line/word work 预算由全局预算均分。实现没有修改 Rust、FFI/ABI、用户编辑文本或常驻缓存。
- 实现 commit：`e39a648`（已推送到 `codex/vscode-parity-p00`）。
