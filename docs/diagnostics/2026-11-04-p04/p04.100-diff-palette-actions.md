## Pinned behavior and scope

The fixed Code-OSS 1.145.0 source at commit 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e registers editor.action.accessibleDiffViewer.next and editor.action.accessibleDiffViewer.prev in commands.ts. Their titles are Go to Next Difference and Go to Previous Difference, both use f1: true and the isInDiffEditor precondition, and their keybindings are F7 and Shift+F7. This corrects the earlier state note that used the diffReview.* IDs.

Alula now registers localized versions of those actions in the existing CommandService and QuickInput command palette. They are visible only while the Git Diff panel tab is active and the mounted patch view has at least one parsed change target. Selecting an action forwards exactly one direction to the same state that owns F7, Shift+F7, toolbar buttons, wraparound, centering, and the live status announcement. The patch view reports bounded navigation availability after frame build and on patch updates; TabController changes refresh the panel context. The controller detaches by owner on teardown.

No Rust, ABI, text editing, parser, navigation-target model, or memory budget changed. No local application GUI or Narrator was launched.

Pinned source: [commands.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/browser/widget/diffEditor/commands.ts).
