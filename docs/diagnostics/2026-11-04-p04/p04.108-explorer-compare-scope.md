## Pinned Code-OSS contract

Code-OSS 1.145.0 registers `selectForCompare`, `compareFiles`, and `compareSelected` command IDs. In the single-file Explorer context menu, `Select for Compare` invokes `selectForCompare`, which stores the original resource and sets the selected-for-compare context; after selection, `Compare with Selected` invokes `compareFiles` with the second resource and opens a pinned comparison. `compareSelected` is a separate multi-resource command that uses current multi-selection and is excluded from this slice. `getResourceForCommand` resolves an explicit resource, focused Explorer/Open Editors row, or active editor; this slice only supplies the Explorer row resource. Explorer multi-selection, Open Editors, selected editor tabs, and direct `Compare Selected` remain separate work.

Pinned source: [IDs](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/files/browser/fileConstants.ts#L13-L17), [handlers](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/files/browser/fileCommands.ts#L187-L230), [Explorer menu conditions](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/files/browser/fileActions.contribution.ts#L524-L535), and [resource resolution helpers](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/files/browser/files.ts#L96-L130).

## Alula baseline and boundary

The current Explorer stores `TreeNode` roots in `workbench_page.dart`; `_buildNode` opens a file on one tap and has no selected-resource state or Explorer context menu. `_registerCommands` already registers command-palette commands, and `_showEditableSnapshotCompare` provides the editable Rust-backed modified side from P04.107. Text search found no current `selectForCompare`, `compareSelected`, `compareFiles`, `Select for Compare`, or `Compare with Selected` route in `app/lib` or `app/test`.

P04.108 will add the Explorer single-resource `selectForCompare` → `compareFiles` flow (`Select for Compare` → `Compare with Selected`) only. Selecting an already-open original uses its Rust-authoritative current text; otherwise the Rust workspace decoder reads the file. The original snapshot is frozen when selected. The second Explorer file is opened/resolved as the modified Rust `OpenDoc`; edits continue through the existing FFI path. Workspace root, canonical path, document identity/version, and budgets must be checked before opening the preview. The separate `compareSelected` multi-resource command, Open Editors/selected tabs, apply/revert, three-way/Multi Diff, and ABI changes are excluded.
