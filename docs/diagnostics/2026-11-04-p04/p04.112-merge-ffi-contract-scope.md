# P04.112 / EDT-19b — Versioned FFI contract for merge projections

Date: 2026-11-04. Status: complete for this FFI-contract slice. Product commit `e08bfe9`; depends on completed P04.111 (`0c261b2`). EDT-19 and `feat-026` remain in progress.

## Goal and fixed contract

Expose the bounded `editor-merge::MergeProjection` through the existing Rust C ABI and Dart bridge so the later Merge Editor workbench can use the same Rust-owned projection and resolution rules. This is an additive, synchronous, stateless contract; it does not introduce a global merge-session registry or retain user text between calls.

The Code-OSS reference remains `1.145.0-dev` at `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`. EDT-19 requires base/input1/input2/result, accept/combine, conflict navigation, saving, and unresolved-state behavior (`docs/11-VSCode功能对照矩阵.md`); this slice only exposes the already implemented projection and per-conflict/accept-all choices.

## In scope

- Add `editor-merge` as an `editor-core` dependency and export one JSON C ABI operation, provisionally `alula_merge_project_json`.
- Version the ABI atomically from v37 to v38 in Rust and Dart. Keep the existing startup handshake; test that Dart rejects a mismatched runtime version.
- Request shape: required `base`, `input1`, `input2`; optional `acceptAll` (`input1` or `input2`); optional `resolutions` array of `{conflictId, side}`. Apply accept-all first, then explicit per-conflict choices as overrides.
- Return the complete result text, ordered conflicts with deterministic id, zero-based/end-exclusive base line range, base/input1/input2 candidate text and selected side, plus conflict and unresolved counts. Line numbers are not UTF-16 offsets; no source offset is added by this API.
- Preserve the existing `{ok:true,...}` / `{ok:false,error:{code,detail}}` JSON envelope, panic containment, UTF-8 validation, caller-owned output pointer, and `alula_string_free` lifetime contract. Bound request/response bytes before exposing data; model input, line, work, trace, conflict, and projection limits remain authoritative. Any parse, resolution, serialization, or model-limit error returns no partial projection.
- Add a typed Dart bridge result and a `AlulaCore` entry point. Only add to existing bridge classes: do not alter document mutation, resync, undo, savepoint, dirty, or close semantics.
- Test the real Rust export and Dart-to-Rust shared-library round-trip for ABI v38; cover automatic merge, unresolved and resolved conflicts, accept-all with overrides, unknown IDs, malformed JSON, bounds, string freeing, and BOM/emoji/CRLF/CR/final-newline preservation.

## Out of scope

- Merge Editor UI/routing, commands, menus, keybindings, four-pane rendering, conflict navigation, combine behavior, result `OpenDoc` dirty/save/undo lifecycle, Git conflict discovery, Multi Diff, and P15 physical-device gates.
- Any change to `DocRegistry`, existing `AlulaDoc` document operations, editor synchronization/IME, or the ABI of existing functions beyond the required version handshake.
- Persistent FFI handles or process-wide merge registries. Each call reconstructs the bounded projection from its request.
- Closing EDT-19 or marking `feat-026` complete.
