## 已登记的 DoD

- 注册 `workbench.files.action.compareWithSaved`，进入 File 命令面板，并提供 Ctrl/Cmd+K、D chord；活动文本文件路径有效时可执行。未保存文件或磁盘版本不可读时显示清楚的状态提示。
- 将当前 Rust 权威文档快照作为 modified，将命令执行时从磁盘读取并按原文件编码解码的文本快照作为 original。比较不修改文件，不把已保存快照写入 session/recent/history。
- 在读取磁盘前拒绝超过 6,000,016 bytes 的文件；总输入不超过 2,000,000 UTF-16 code units，并复用 DiffViewModel 行/row/work 预算。超限、二进制/不支持编码、文件丢失或读取失败时整体拒绝，不显示部分 diff。
- 显示可关闭、只读、side-by-side 比较视图。比较过程中复核活动文档对象、id、path/uri 与 Rust version；任何身份变化都取消打开。
- 保持 Rust text/version、selection、dirty/savepoint、undo/redo 和磁盘字节不变。测试覆盖 clean/dirty、同文本、磁盘文本差异、BOM/emoji/CRLF、错误/超限路径与关闭/切换期间状态。
- 不改 Rust、FFI ABI、编辑器保存协议或工作区 watcher。单独注册/提交该切片后再实现；仍留 `EDT-18` 其余操作给后续项。
