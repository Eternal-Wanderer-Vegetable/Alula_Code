## Implemented behavior

The compare editor has per-hunk Revert Block and modified-side Revert Selection actions, plus the diffEditor.revert Command Palette action. The palette can be opened inside compare preview with Ctrl+Shift+P on Windows/Linux and Cmd+Shift+P on macOS. Revert Selection and the command action use the current exact diff to map the modified caret/selection to affected hunks.

Restore ranges are projected as absolute UTF-16 offsets. The frozen original is copied only into the Rust-authoritative modified OpenDoc through the version-checked edit path. The operation is atomic, creates one undo grouping, keeps the original snapshot unchanged, refreshes sibling views, and supports undo, redo, save, and disk read-back. Stale or approximate diff results, budget fallback, active IME composition, document close, and identity/version changes are rejected before mutation. No Rust, FFI, ABI, save protocol, or diff algorithm changes were made.
