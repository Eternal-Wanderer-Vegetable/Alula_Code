## 登记的范围与 DoD

- 按 patch source row 将每个 move 的原/修改侧所有行映射到投影 side-by-side rows；映射缺失、重复、越界、乱序或不连续时返回整体不可用结果，禁止只画一部分。
- 工具栏 toggle 默认关闭；只有 side-by-side presentation 与宽度可用时可启用。开启时画原/修改块 outline 和跨中心 gutter 的连接曲线；inline 和 raw fallback 不画。
- 测试默认关闭、开启后的双侧边界/连线、source mapping、inline/窄布局、raw/model fallback、patch 更新清状态、文本选择与既有差异导航。
- 不实现近似相似度或 unchanged move 检测；不改 patch parser、Rust/ABI 或设置持久化。复用 P04.102 硬界（2,000,000 UTF-16 units / 16,384 patch rows / 4,000,000 candidate text work）。
