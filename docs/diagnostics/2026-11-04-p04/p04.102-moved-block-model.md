# P04.102 / EDT-17j：Git Diff moved-block 配对模型

## 状态

模型实现、定向测试与本地完整 DoD 已完成；PR CI 与三平台包/可用性 workflow 尚待推送后确认。该切片只提供纯 Dart 分析模型，尚未接入 Git Diff 视图，因此当前产品 UI 不显示移动标记，也没有启用 `showMoves` 的配置入口。

## 对齐范围

固定 Code-OSS 1.145.0 将 `diffEditor.experimental.showMoves` 默认设为 `false`。其 `DefaultLinesDiffComputer.computeMovedLines` 会把简单删除块与新增块做相似度匹配，过滤太短的移动并连接相邻结果。本切片在现有 bounded unified patch 上实现保守子集：同一文件、不同 hunk、首尾空白归一后内容完全相同且候选唯一的删除/新增块。每块至少 3 行、归一后至少 15 UTF-16 units，至少两行各不少于 2 units。重复候选、同 hunk、更改过内容的近似块、未作为删除/新增出现的 unchanged moves 均不标记；这些仍是后续模型/UI 切片。

范围给出原文/修改文 1-based、end-exclusive 行号和 0-based patch-row 映射。输入和工作硬上限分别为 2,000,000 UTF-16 units、16,384 patch rows、4,000,000 候选文本 work units；任一预算、解析或映射失败都返回空结果和明确原因，不暴露部分移动块。未改 parser/projection/navigation、工作台 UI、Rust 或 ABI。

固定来源：[diffEditor.ts (`showMoves: false`)](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/config/diffEditor.ts)、[computeMovedLines.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/diff/defaultLinesDiffComputer/computeMovedLines.ts)。
