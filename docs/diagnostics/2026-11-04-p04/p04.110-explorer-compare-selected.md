- [Explorer context-menu condition](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/files/browser/fileActions.contribution.ts#L531-L536)
- [selected-resource order](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/files/browser/files.ts#L113-L124)

This slice adds only the Explorer route. Windows/Linux use Ctrl-click; macOS uses Command-click; Shift-click selects a range among expanded visible file rows. A plain file click keeps opening the file and resets the selection; a folder click keeps expanding/collapsing it. Selection is limited to visible ordinary file rows and is pruned on collapse, refresh, and workspace changes. The context menu exposes `Compare Selected` only for exactly two distinct selected files when the clicked row is one of them. Selection order is retained: first original, second modified.

The action reuses the established Select for Compare and Compare with Selected data path. It freezes the first side from the current Rust document when open (including dirty edits) or workspace-decoded disk text when closed; the second side is opened as the editable Rust-backed document. Existing path/workspace/document identity, version, IME, UTF-16 length, and diff-budget checks remain authoritative. Save, sibling synchronization, and read-back use the existing document/save route. No Command Palette entry, keybinding, Open Editors/editor-title action, three-resource diff, merge/SCM action, or Rust/FFI/ABI change was added.

## CI failure and crash interpretation

The user's concern that repeated CI failures may contribute to crash instability is retained for follow-up. The existing review in `docs/diagnostics/2026-11-03-p04/ci-failures-and-crash-correlation.md` distinguishes actual historical process crashes (Windows `0xC000041D`, macOS startup SIGSEGV) from recent runner/queue cancellations, dropped synthetic input, and failed assertions that exited normally or ran before app launch. Stable CI improves regression signal; a green rerun or a non-crashing assertion failure does not itself fix or explain the historical crashes. This P04.110 change does not modify startup or window-close code.
