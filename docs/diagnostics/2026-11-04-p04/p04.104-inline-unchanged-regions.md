## 登记范围与 DoD

- 只在 inline presentation 和可解析 bounded patch 中提供默认关闭的折叠 toggle；raw fallback、窄宽度 fallback 和 side-by-side 不显示折叠标记。
- 按 patch-source-row 严格映射折叠前后 inline rows，变更来源映射不完整、重复或乱序时整片关闭 folding。hunk 间不得合并；不跨文件或在 changed line 上折叠。
- 使用每个 hunk 内 context run 的有界计算；小于 9 行的上下文不折叠。折叠控件可访问并说明隐藏行数；每次最多展开 20 行，支持完整展开。
- 现有差异导航目标必须重映射到折叠后的可见行；patch 更新清除已展开/折叠状态，不修改文本、行号、selection、dirty/savepoint 或 Rust 文档版本。
- 新增投影和 widget tests 覆盖默认关闭、长度/上下文阈值、hunk/file 隔离、来源映射失败、逐次/全部展开、导航映射、patch 更新、选择文本与 raw fallback。
- 复用现有 2,000,000 UTF-16 和 16,384 patch row 上限；不增加持久化、不改 Rust/ABI，不实现 side-by-side folding 或 P14 数值内存调优。
