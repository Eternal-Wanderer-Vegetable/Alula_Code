# P05.133 / feat-185 · LAY-07 编辑器组锁定与隐式打开路由

- 注册 `workbench.action.lockEditorGroup`、`workbench.action.unlockEditorGroup` 和 `workbench.action.toggleEditorGroupLock`。启用状态随活动组更新，锁定组显示可操作的解锁图标。
- 向锁定组隐式打开已经存在于其中的文档时复用原视图。对新文档，选用最近活动且可用的组。所有候选组均不接收该文档时，在活动组右方建立新组。文件打开和新建未命名文档共用目标选择。
- 会话仅为已锁定的组保存 `locked: true`，旧会话缺省解锁。恢复锁定组时保留已有文档及标记。显式跨组移动和复制的目标仍由用户所选组决定。
