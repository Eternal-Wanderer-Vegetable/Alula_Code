# P05.139 / feat-191 · LAY-10 跨组已选标签批量移动

依赖 P05.42、P05.44、P05.136、P05.138。本项验收覆盖向现有编辑器组的标签前、后和编辑区中央拖放。

- 拖起已选标签时按源标签栏顺序移动该选择。标签落点依据左右半区插入。目标已打开同一文档时复用其视图、移除源重复视图，并按落点重排目标标签。最后一项成为目标活动标签。
- 编辑区中央接纳整个选择。当目标最后一项活动时，移动项追加到该项之后，并由首个移入项保持焦点。已有源组剩余标签时恢复该组最近的标签。移空源组时折叠布局并将焦点移至目标。
- 普通移动项保留原 Rust 文档、输入窗口、滚动控制器和焦点节点。关闭事务或辅助窗口转移锁定了所选文档时，整批移入现有组停止。复制修饰键的批量行为登记为 P05.140。
