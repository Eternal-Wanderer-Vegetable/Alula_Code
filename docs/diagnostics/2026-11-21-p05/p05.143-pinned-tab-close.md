# P05.143 / feat-195 · LAY-09 固定标签关闭保护

依赖 P05.39、P05.41、P05.136、P05.142。

- 固定标签支持键盘和中键、仅键盘、仅中键、允许关闭四种会话配置，缺失或无法识别的值用键盘和中键。通过查看菜单的编辑器标签子菜单或相应命令可更改。
- 键盘受保护时，活动固定标签让出焦点给最近活动的普通标签，普通活动标签的批量关闭保留被选中的固定标签。中键保护检查被直接点击的标签。右键菜单关闭、关闭按钮和显式关闭命令继续走统一的保存确认。
- 关闭当前活动标签后，如果关闭事务已移除该视图，在布局完成后把焦点交给现有回退编辑器。混合关闭的确认取消保留 Alula 的整批取消规则。
