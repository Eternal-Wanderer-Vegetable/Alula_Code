# P05.134 / feat-186 · LAY-07 扩展活动编辑器组与隐藏侧栏

依赖 P05.28、P05.131、P05.132。

- `workbench.action.toggleEditorWidths` 按活动组所在分割路径分配可用宽高。兄弟组保有其最小尺寸和现有视图。再次切换恢复各编辑器分割的均分比例。
- `workbench.action.minimizeOtherEditorsHideSidebar` 同时隐藏主侧栏和次侧栏，并扩展活动组。单组配有可见侧栏时也可执行，隐藏状态按既有布局规则保存。
- 默认编辑器组最小宽度为 220、最小高度为 70 个逻辑像素。旧版生成的 320 宽度迁移到新默认，已有其他正宽度继续使用其原宽度限制。无约束的旧布局在扩展时为兄弟组提供默认最小宽度。极窄组的标题动作区可横向滚动，保留原命令与顺序。
