# P05.141 / feat-193 · LAY-09 固定标签尺寸

依赖 P05.39、P05.40、P05.138。

- 多标签模式下，固定标签支持普通、紧凑、收缩。普通继续按当前标签布局计宽。紧凑为 28 逻辑像素，保留文件图标、完整标签名的工具提示和语义名称，鼠标命中覆盖标签宽度。收缩为 80 逻辑像素，保留可省略的标题和关闭操作。
- 通过查看菜单的编辑器标签子菜单或相应命令切换。会话保存尺寸，缺失或无法识别的值回到普通。独立固定行使用同一尺寸。普通标签继续按自身宽度策略分配剩余空间。
- 本项验收固定宽度、标签内容、命中和双行布局。紧凑／收缩标签在水平溢出时停靠前端的行为登记在 P05.142。
