# P05.135 / feat-187 · LAY-07 同组文本编辑器拆分与合并

依赖 P05.28、P05.132、P05.134。

- 普通文本标签可在原编辑器组拆分。两个输入窗口和滚动控制器共享一个 Rust 权威文档，未保存状态、撤销栈和保存流程共用。标签栏和 Open Editors 各显示一个条目。
- 注册拆分、合并、切换、布局方向及三个焦点命令。组内分隔条可调整大小，双击恢复均分。合并保存当前视图的光标与滚动位置。会话恢复拆分方向、分隔条比例及活动侧。
- Windows/Linux 默认组合键为 `Ctrl+K Ctrl+Shift+Backslash`，macOS 配置使用 `Cmd`。同一键位交给切换命令，根据当前标签执行拆分或合并。各固定命令 ID 仍可分别执行与重绑。Linux 将同一物理键上报为 `|` 时，组合键匹配按反斜杠处理。
