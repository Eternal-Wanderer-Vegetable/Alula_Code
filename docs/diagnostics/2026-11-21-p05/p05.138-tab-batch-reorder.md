# P05.138 / feat-190 · LAY-10 同组多选标签批量排序

依赖 P05.39、P05.42、P05.136。

- 拖动开始时记录组内选择，已选标签按原标签栏的相对次序移动。目标标签的左右半区分别表示插入到前后，移动后拖起的标签活动，并保持其他批量项选中。
- 普通标签进入固定区时成为固定标签，固定标签移出时解除固定。单独固定行的末尾可以接纳整批，移入普通行时按普通标签处理。
- 多选存在时拖动一个未选标签会只移动并激活该标签。普通单选保持原有排序与焦点规则。批量排序复用原文档和视图节点，保存顺序、活动标签及固定区。
