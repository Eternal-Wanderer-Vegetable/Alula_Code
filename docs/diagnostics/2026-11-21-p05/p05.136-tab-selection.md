# P05.136 / feat-188 · LAY-10 同组标签多选与批量关闭

依赖 P05.41、P05.43、P05.135。

- Windows/Linux 的 Ctrl 和 macOS 配置的 Cmd 加单击增减组内标签选择。取消活动标签时切换到仍被选中的最近活动标签，最后一个选中标签保持活动。Shift 采用当前选择锚点及标签顺序，跨越锚点时收起反方向连续范围。普通单击恢复单选。
- 活动标签保留原蓝色顶线，其他选中标签显示底色，并通过标签语义公开选中状态。选择按编辑器组保存于运行态，重启从活动标签开始。
- 关闭键、选中标签的关闭动作、中键与上下文菜单 Close 使用同一组选择。未选中标签的入口只关闭该标签。Windows 优先使用 Ctrl+F4，Ctrl+W 继续可用。键盘关闭遵守固定标签保护。
- 关闭复用共享文档的既有批量事务，整个确认包含需要处理的脏文件，取消保留原标签及选择。固定版逐文件处理确认，Alula 沿用既有单对话框。点击标签或打开菜单时保留编辑器的文本输入焦点，以便继续使用关闭快捷键。
