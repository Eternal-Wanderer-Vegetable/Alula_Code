## Implementation

- Registered `editor.action.transformToSnakecase` as a command-palette action with no default keybinding. - Added `editor_buffer::transform_snake_case_text` using the two Unicode boundary passes from the pinned Code-OSS source: lowercase-to-uppercase boundaries and acronym-to-word boundaries, followed by full Unicode lowercase. The regex cache is bounded to two process-wide compiled patterns.
- Added NUL-safe JSON FFI `alula_text_transform_snake_case` and raised the synchronized Rust/Dart ABI handshake from v29 to v30. The endpoint uses the existing 8 MiB request and 16 MiB response bounds.
- The only unrelated edit is a pair of braces around an existing search-completion `if`, which removes a Flutter analyzer info diagnostic and has no behavioral effect.

## Difference and boundary

Rust `to_lowercase` is locale-independent and its Unicode tables may differ from JavaScript `toLocaleLowerCase` on the host. This remains in the parity difference ledger. The three `TargetPlatform` fixtures are automated Flutter tests; they do not establish native OS, IME, screen-reader, DPI or theme acceptance. The Windows 11 exact-artifact results remain pending under P15; see [`P03.7 hosted artifact run 41221325692`](../2026-11-01-p03/p03.7-windows11-hosted-artifact-41221325692.md).
