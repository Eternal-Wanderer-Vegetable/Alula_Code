## 上游行为

对照固定版本 Emmet 扩展的 [数值实现](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/extensions/emmet/src/incrementDecrement.ts)、[命令清单](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/extensions/emmet/package.json)、[本地化标题](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/extensions/emmet/package.nls.json) 与 [上游测试](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/extensions/emmet/src/test/incrementDecrement.test.ts)：

- 六个命令只注册到命令面板，无默认键位；步长为 ±0.1、±1、±10。
- 每个 selection 从右端点查找同一行 ASCII 数值；`parseFloat + delta` 后按原小数位数（没有小数时默认为 1）调用 JavaScript `toFixed`。
- 输出去掉全零小数部分，保留整数前导零宽度；原文为 `.x` 或 `-.x` 时省略输出整数部分。找不到数值时不编辑。

## Alula 实现

- `editor-buffer` 增加纯 Rust UTF-16 数值计划函数。它按 IEEE-754 binary64 精确复刻 JavaScript `toFixed` 的舍入，包括 ties-away 与 `|value| >= 1e21` 分支，并保留 Emmet 的小数、前导零与 `.x` 格式规则。toFixed 精度大于 100 时返回等价的范围错误。
- ABI 双侧升至 v33。新增 NUL-safe JSON FFI 只处理最多 1,000 UTF-16 单元的逻辑行窗口，不读取整篇文档。工作台用 Rust `positionAt` / `lineBoundary` 取版本一致的窗口，再校验 FFI 计划范围、长度和被删文本是否与 Rust 权威文档相同。
- 长行窗口内找不到数值时保持 no-op；若数值 token 触及被截断的窗口边界，整批拒绝，避免部分替换。窗口本身最多 1,000 UTF-16 单元。
- 工作台一次性生成 UTF-16 `TextOps`，相同范围去重，冲突的重叠范围整批取消，撤销载荷受 2,000,000 字符上限约束；提交后更新 selection、undo/redo、dirty、Find、分屏视图和保存状态。
