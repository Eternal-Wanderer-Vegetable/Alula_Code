## 实现

- 工作台注册两个 command id，使用 Rust `positionAt`、`lineOffset`、`lineBoundary` 取得 UTF-16 行位置及范围。整行内容通过有界文档读取获取，计入现有撤销历史文本上限；超限、版本变化或 Rust 边界异常会取消操作。
- 复制操作通过现有 Rust 文档 `TextOp` 一次提交，降序处理多个插入；同步选择、撤销/重做、dirty、Find 与 split view。没有更改 FFI 或 ABI。
- 为兼容已有 Linux 列选并释放 VS Code copy-line 默认键位：Linux 列选仍用 Alt+Shift+方向键，Windows 列选改为 Ctrl+Alt+Shift+方向键，macOS 不注册列选键位；复制行在 Windows/macOS 用 Alt+Shift，Linux 用 Ctrl+Alt+Shift。`KeybindingSet`、命令提示与编辑器焦点键盘处理保持一致。
- `_setDocSelections` 先于复制后的输入窗重建执行。端点超出旧窗口时，直接先重建并调度 widget 更新，避免把新文档坐标写入旧 TextField controller。
