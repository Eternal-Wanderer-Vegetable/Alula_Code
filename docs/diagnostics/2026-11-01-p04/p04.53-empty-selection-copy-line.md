# P04.53 / EDT-10a：空选区复制当前行

## 固定上游行为

对照固定 Code-OSS `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`：[`clipboard.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/clipboard/browser/clipboard.ts) 注册 `editor.action.clipboardCopyAction`，桌面默认 Ctrl+C / Cmd+C；[`viewModelImpl.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/viewModel/viewModelImpl.ts) 的 `getPlainTextToCopy` 在 `editor.emptySelectionClipboard` 开启时，将空选区扩展为当前逻辑行，并在复制文本后追加行尾。Windows clipboard 强制使用 CRLF，其他平台使用文档模型 EOL。

## 实现范围

- 单光标、折叠选区时，编辑器焦点下的 Ctrl+C / Cmd+C 拷贝当前 Rust 文档逻辑行及一个 EOL；即使当前行是文件末行且原文没有末尾换行，clipboard payload 仍附加 EOL。
- 行文本通过 Rust `lineBoundary` 取得 UTF-16 范围，再经已有有界分块读取；读取期间校验文档版本。Windows 生成 CRLF，Linux/macOS 使用文件 EOL 元数据。
- 复制不改变 Rust 文本、selection、dirty 状态或磁盘字节，不改 ABI。
- 本 slice 不处理空选区剪切、多光标空选区的新增语义、VS Code clipboard metadata、复制语法高亮 HTML 或 Paste As；这些继续按 EDT-10 拆分。
