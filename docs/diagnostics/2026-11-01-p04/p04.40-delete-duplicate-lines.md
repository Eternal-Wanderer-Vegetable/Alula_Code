# P04.40 / EDT-07g：Delete Duplicate Lines

## Scope and pinned reference

- Command: `editor.action.removeDuplicateLines`, displayed as “删除重复行”; command palette only, matching the pinned editor action (no default keybinding).
- Reference: Code-OSS `linesOperations.ts` at commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`, [`DeleteDuplicateLinesAction`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/browser/linesOperations.ts#L298); pinned tests cover selected ranges, the whole document, multiple selections, and single-line selection promotion ([tests](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/test/browser/linesOperations.test.ts#L189)).
- The action preserves the first exact line occurrence and its order. Each selection is deduplicated independently. A single caret or single-line selection promotes to the entire document; other selections include both endpoint lines, including an endpoint at column 1. Empty lines participate in exact equality.

## Implementation

- Added the command to the editor command palette and use Rust `positionAt`, `lineOffset`, and `lineBoundary` for UTF-16 row/range validation and bounded reads. Exact `String` equality preserves case and whitespace distinctions.
- Each range is capped at 100,000 lines and the shared undo payload budget. Version, selection-count, and overlapping-range checks run before a single descending Rust TextOps transaction. The operation feeds the existing undo/redo, dirty, Find, bounded input-window, and split-view synchronization paths; no ABI change.
- For a single-line caret promoted to the whole document, Alula maps the original caret line/column to the corresponding retained line. The pinned action leaves cursor-state computation to Code-OSS `executeEdits`; the pinned tests do not assert a caret inside a line removed as a duplicate, so that exact marker-collapse edge remains unverified against a native Code-OSS client.
