## 实现

- 注册上述 command id 与三平台 Alt+↑/↓ 默认键位；无 ABI 变化。
- 使用 Rust `positionAt`、`lineOffset`、`lineBoundary` 解析 UTF-16 绝对行范围。根据 Code-OSS 的 ordered selection 边界判断首尾 no-op，再排除结束于下一行第 1 列的行。
- 将相邻移动范围合为一个有序块，以固定范围内的内容旋转实现上/下换行；空行也可以移动。提交前按撤销预算上限检查文本范围，版本变化、边界异常和超预算均取消；一次 Rust `TextOp` 事务接入 selection、undo/redo、dirty、Find 与兄弟视图同步。
- 选择端点随所选块或相邻行内容重映射；覆盖反向范围、多光标、空行、行尾、首尾边界和下一行第 1 列结束的选区。

## 已知差异

Code-OSS 的 `MoveLinesCommand` 在 `autoIndent=full` 且语言配置可用时，会根据 `indentRules` / `onEnter` 重新缩进移动行及其块。Alula 当前没有等价的完整语言配置服务；本切片保留行的原有缩进，不推断新的 Rust 缩进。高级语言规则缩进仍是明确待办，不计为本切片已实现能力。
