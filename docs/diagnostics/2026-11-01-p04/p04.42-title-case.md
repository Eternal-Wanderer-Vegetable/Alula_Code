## 固定版本参考

固定 Code-OSS 1.145.0-dev commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 的 `TitleCaseAction` 继承 `AbstractCaseAction`：非空选区转换选中片段，caret 使用配置词查询；执行前后分别 push undo stop。Title Case 先 `toLocaleLowerCase()`，再以 Unicode 字母/数字/撇号边界匹配字母并将匹配内容 `toLocaleUpperCase()`。固定正则为 `(^|[^\p{L}\p{N}']|((^|\P{L})'))\p{L}`，flags 为 `gmu`。

源码：[linesOperations.ts（固定 commit，TitleCaseAction 与 AbstractCaseAction）](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/browser/linesOperations.ts#L1127-L1238)。

## 实现

- 工作台注册 `editor.action.transformToTitlecase`（命令面板，无默认快捷键），复用 P04.41 的 Rust 权威范围规划与事务。Title Case 选区和 caret、范围去重、版本/重叠/undo payload 校验、selection 长度映射、undo/redo、dirty、Find、分屏、保存路径都沿用同一实现。
- `editor-buffer` 新增 bounded `transform_title_case_text`：使用单个 `OnceLock` 缓存的 Unicode `regex::Regex`，先做 Rust full lowercase，再仅把上游正则匹配片段做 full uppercase。regex 缓存固定一个实例，不随请求增长。
- 新增 `alula_text_transform_title_case` JSON FFI 导出；Rust 与 Dart ABI 同步升至 v28。NUL 通过 JSON 转义往返，输入/输出限制沿用 8 MiB/16 MiB。

## 差异和边界

- Rust `str::to_lowercase/to_uppercase` 是 locale-independent；Code-OSS 调用 JS `toLocaleLowerCase/toLocaleUpperCase`，非默认系统 locale（例如 Turkic I）可能输出不同。Rust regex 与运行时的 Unicode 数据版本也可能有差异。
- Upper/lower 的语言专属 `wordPattern` 差异仍见 P04.41；本命令沿用工作台当前配置词查询行为。
- TargetPlatform 是合成平台 fixture，不是原生 Windows/macOS/Linux 键盘、读屏、IME、DPI/主题或发行门证据；这些继续在 P15 验收。
