# P04.54 / EDT-10b：空选区剪切当前行

## 固定上游行为

对照固定 Code-OSS commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`：[`clipboard.ts`](https://raw.githubusercontent.com/microsoft/vscode/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/clipboard/browser/clipboard.ts#L35-L70) 注册 Ctrl/Cmd+X 的 `editor.action.clipboardCutAction`；[`viewModelImpl.ts`](https://raw.githubusercontent.com/microsoft/vscode/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/viewModel/viewModelImpl.ts#L914-L961) 将空选区扩展为当前逻辑行并附加 EOL，Windows 强制 CRLF；[`cursorDeleteOperations.ts`](https://raw.githubusercontent.com/microsoft/vscode/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/cursor/cursorDeleteOperations.ts#L213-L271) 定义空选区剪切范围：中间行一并删除后续行分隔符，末行删除前置分隔符，单行文档只删行内容。

## 实现范围

- 单光标空选区 Ctrl+X/Cmd+X 写入当前 Rust 文档行文本与 Windows CRLF/其他平台文档 EOL，再删除整行。
- 剪贴板写入前按 Rust `lineBoundary` 与有界范围读取行文本；异步写入后重新检查活动文档身份、版本、selection、composition、多选状态与只读状态。状态变化时保留文档，不应用旧快照的删除。
- 复用现有 Rust 权威 `editor.action.deleteLines` 事务，沿用其删除范围、光标映射、撤销预算、dirty、Find、兄弟视图刷新和 undo/redo；不改 Rust ABI。
- 不扩展多光标空选区、跨窗选择或 clipboard metadata / rich text。
