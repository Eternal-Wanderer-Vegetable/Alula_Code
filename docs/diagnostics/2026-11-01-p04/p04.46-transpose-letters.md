## 实现

- `TextBuffer` 从一个 Rust 文档版本对最多 10,000 个 UTF-16 caret 生成转置计划；按 Unicode scalar 和 LF/CRLF/CR 行界移动，范围文本仍由 Rust 权威 buffer 持有。NUL-safe JSON FFI ABI 从 v31 升为 v32，输出上限为 2 MiB。
- Dart bridge 校验版本与计划长度。工作台对非空 selections 保持原样，对折叠光标应用 Rust 计划；编辑范围按冲突检查后，以一个版本门控 TextOps 批次提交。复用现有 undo/redo、dirty、Find、分屏刷新及保存路径。
- 命令在 `Command Palette` 注册为“编辑器: 转置字母”；只在 macOS 提供 Ctrl+T。
- 如果多个 caret 计算出的替换范围重叠，Alula 会取消整批，避免交叠 TextOps 造成部分提交。上游编辑器在该冲突场景的行为尚未用固定版 Code-OSS 自动化验证，保留为明确的 parity 限制。
