# P04.58 / EDT-10f：富文本复制与系统剪贴板 metadata

## 实现与根因

- 为桌面系统剪贴板接入 `text/plain`、`text/html` 与 Code-OSS v1 `vscode-editor-data`，复用有界 metadata sidecar；复制/剪切/空光标复制/多光标复制和粘贴读取均走统一适配。
- Linux GTK 原生剪贴板已发布三个 target。首次回读测试发现 `vscode-editor-data` 的原生值是 UTF-8 `Uint8List`，原解码器只接收 `String`；现在同时支持字符串和有界 UTF-8 字节，限制 metadata 输入为 1 MiB 并拒绝非法 UTF-8。完整的 plain text、HTML 与 metadata 回读由 Xvfb 桌面插件测试验证。
- HTML 仅从当前版本的 Rust Tree-sitter/LSP token 构建，做 HTML escaping 和 token/长度限制；无真实 token provider 的语言不伪造颜色。
