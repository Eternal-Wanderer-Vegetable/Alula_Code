## Implementation

- Registered `editor.action.joinLines` in the workbench and `KeybindingSet`; Windows/Linux use the command palette, and macOS uses Ctrl+J. macOS panel toggle is Cmd+J.
- Rust `positionAt`, `lineOffset`, and `lineBoundary` resolve absolute UTF-16 line ranges. Text is read only within the existing undo-history budget, transformed without mirroring the whole document, then applied in one version-checked Rust TextOps batch. Descending edits preserve disjoint multi-cursor offsets; inverse ops provide undo/redo. Selection, dirty state, bounded input window, Find, and sibling views are synchronized. No ABI change.
- The operation follows existing range/version/budget failure handling. Native keyboard validation remains part of P15.
