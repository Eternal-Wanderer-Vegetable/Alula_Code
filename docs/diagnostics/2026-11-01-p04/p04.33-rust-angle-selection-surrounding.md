# P04.33 — Rust angle bracket selection surrounding

Date: 2026-11-01. Status: implemented and validated.

## Behavior

- The pinned Rust language configuration includes `<` / `>` in `surroundingPairs` only. Typing `<` around a non-empty Rust selection now wraps it; typing `<` at a caret inserts only `<` and creates no auto-close marker. A following `>` remains a normal TextInput character.
- The implementation uses the existing Rust UTF-16 TextOps transaction, selection mapping, undo/redo, dirty tracking, split-view refresh, and save path. No Rust or FFI ABI changed.

## Fixed source

- [Pinned Code-OSS Rust language configuration](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/extensions/rust/language-configuration.json) includes `<` / `>` in `surroundingPairs`; it does not define `<` as an `autoClosingPair`.
