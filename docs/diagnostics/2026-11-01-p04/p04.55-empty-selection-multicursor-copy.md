# P04.55 / EDT-10c — Multi-cursor empty-selection copy

## Result

Implemented multi-cursor `Ctrl+C` / `Cmd+C` copy behavior for empty selections. Each empty caret copies its Rust-authoritative logical line plus the correct clipboard EOL. Non-empty selections copy their Rust-authoritative selected text. The ranges are processed in document order, duplicate empty carets on the same line do not duplicate that line, and copied ranges are joined with the document EOL.

Windows forces CRLF within selected text and for copied lines. Linux and macOS use the document's EOL metadata. The implementation reads absolute UTF-16 ranges from Rust, checks document version and selection snapshots, and works when a secondary caret lies outside the current bounded input window. It does not mutate document text, selections, dirty state, or disk bytes. Multi-selection cut remains on its existing path.
