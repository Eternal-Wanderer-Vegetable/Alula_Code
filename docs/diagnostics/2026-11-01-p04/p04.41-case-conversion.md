## 固定版本参考

## 实现

- 工作台命令面板注册两个固定 command id，无默认快捷键。显式选区转换原范围；caret 按固定默认 separators/小数规则，在 Rust `positionAt` / `lineBoundary` 给出的逻辑行中定位词；空白/空行保持 no-op。
- 所有文本范围来自 Rust 权威文档的版本一致 UTF-16 读取。多光标对相同词范围复用一次转换；编辑范围去重、重叠检查、undo payload 预算与 document version 校验后，以一次降序 TextOps 事务提交。更新 selection、undo/redo、dirty、Find、输入窗口、分屏兄弟视图与保存状态。
- Dart 大小写 API 无法表达 VS Code 默认 JavaScript `toLocale*` 的完整 Unicode case expansion：实测 Dart `'ß'.toUpperCase()` 保留 `ß`。新增 editor-buffer full Unicode case mapper、JSON FFI 与 ABI v27；JSON 编码保留 NUL，输入/输出字节限制分别为 8/16 MiB。selection mapping 覆盖 `straße` → `STRASSE` 的长度变化。

## 差异和边界

- 工作台尚未加载语言贡献里的专属 `wordPattern`，caret 查询当前实现固定版本默认规则。特定语言覆盖词边界后续另列 slice。
- Rust Unicode full case mapping不使用系统 locale；VS Code `toLocaleUpperCase/LowerCase` 对 Turkic `I/i` 等 locale-sensitive 特例可能不同。已覆盖完整 Unicode expansion 示例，但该 locale 差异仍需保留。
- 本 slice 只完成 Uppercase/Lowercase；title/camel/snake/kebab、transpose 与数值替换继续拆成后续 EDT-08 slices。
- TargetPlatform fixture 不是原生 Windows/macOS/Linux 输入、读屏或 DPI/主题验收；这些仍按 docs/03 留给 P15。
