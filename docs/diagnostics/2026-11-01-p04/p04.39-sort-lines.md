## Pinned behavior

- Code-OSS registers `editor.action.sortLinesAscending` and `editor.action.sortLinesDescending` without default keybindings. A single-line selection sorts the whole document; other selections sort their selected line ranges. An endpoint at column 1 excludes that final line.
- The command runs only when every selection contains at least two sortable lines and each range would change. If one range is unsortable or already sorted, the entire command returns without partial edits. Disjoint selections are sorted independently, and descending order reverses the ascending result.
- The pinned implementation compares lines with `Intl.Collator` and tracks each original selection through the replacement. Sources: [SortLinesCommand](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/browser/sortLinesCommand.ts), [line operation registration](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/browser/linesOperations.ts), and [pinned tests](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/test/browser/linesOperations.test.ts#L34).

## Implementation

- Registered both command IDs in the workbench with no default shortcut.
- Rust `positionAt`, `lineOffset`, and `lineBoundary` resolve document-absolute UTF-16 selections and line ranges. Text reads remain bounded by the undo-history budget and a 100,000-line cap. Version checks, overlap checks, and a single Rust TextOps batch protect the operation. Inverse edits provide undo/redo; selection, dirty state, Find, input window, and sibling views are synchronized. No FFI or ABI change.
- Known parity gap: Dart `String.compareTo` sorts by code-unit order, while Code-OSS uses the runtime locale's `Intl.Collator`. ASCII and tested emoji ordering pass, but locale-specific case, accent, and language collation can differ. The command is implemented, but exact collation parity remains open for this feature family.
