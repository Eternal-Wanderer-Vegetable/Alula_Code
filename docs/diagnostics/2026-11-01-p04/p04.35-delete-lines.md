# P04.35 / EDT-07b: Delete Lines

Date: 2026-11-01

## Scope

Implemented the pinned Code-OSS command `editor.action.deleteLines` with Ctrl+Shift+K on Windows/Linux and Cmd+Shift+K on macOS. The command is registered in the command palette and runs only while the editor has focus.

The reference implementation and default chord are in the pinned Code-OSS [`linesOperations.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/linesOperations/browser/linesOperations.ts#L498-L610).

## Behavior

- A caret deletes its current line. For a multiline selection ending at column 1, the endpoint line is excluded. Overlapping and adjacent line selections merge into one deletion.
- Deleting the final line removes the preceding separator and leaves the prior line. Deleting the only empty line is a no-op. The caret returns to the same column, clamped to the surviving line.
- Rust `positionAt`, `lineOffset`, and `lineBoundary` resolve line positions and UTF-16 boundaries. The workbench reads only the bounded deleted ranges, checks document version and the existing undo budget, then submits descending `TextOp`s as one undoable edit.
- The command uses the existing document history, dirty/save state, and sibling-view refresh paths. It does not change the Rust/FFI ABI. Cross-window selections and off-window additional selections are included.
