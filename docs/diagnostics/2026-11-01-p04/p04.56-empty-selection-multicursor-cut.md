# P04.56 / EDT-10d — Multi-cursor empty-selection cut

## Result

Implemented `Ctrl+X` / `Cmd+X` for mixed multi-cursor selections, including empty carets. Non-empty selections copy and remove their selected text. Each empty caret copies its Rust-authoritative logical line with the applicable EOL and removes that whole line. The command snapshots absolute document selections, reads content from the Rust document outside the bounded input window, validates version and selection state around the asynchronous clipboard write, and applies all deletions as one version-checked Rust transaction. Undo, redo, dirty state, sibling views, Find, and save use the existing document paths. No ABI change was needed.

For an empty caret on a middle line, cut removes the line and its following separator; for an empty caret on the final line, it removes the preceding separator with the line. Duplicate/overlapping deletion ranges are merged before applying the transaction. The operation retains the existing deletion and undo payload limits.
