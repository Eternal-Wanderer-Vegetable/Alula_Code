# P05.382 默认编辑器组拆分工具条

主窗在默认多标签模式下，仅活动编辑器组显示拆分按钮。普通点击向右创建编辑器组。按住 Alt 点击向下创建编辑器组。新组继续显示同一文件。单标签和无标签模式继续沿用各自的工具条规则。

## 固定版对照与发布构建

- 固定 Code-OSS 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e 的 Windows 125% DPI 复验先在普通窗口向右拆分，旧组随之只显示 More Actions。右组活动时，Alt 点击在右列下方创建新组，左组高度保持。重复用例在 Zen 全屏复验同一行为，三个编辑器组显示同一文件。
- Alula 改前的回归显示两个组同时保留拆分按钮，并且 Alt 点击仍导致横向拆分。修复后，Windows 与 Linux 发布构建均观察到同一活动组规则、横向再纵向拆分、Alt 释放、正常窗口范围恢复和系统关窗退出码 0。带 BOM、CRLF、中文和 Emoji 的原文件字节保持一致。相关多视图测试也验证同一 Rust 文档与独立视图状态。
- Linux 使用隔离 Xvfb/Xfwm4 的真实键鼠事件，测试配置关闭了 Xfwm4 对 Alt 加鼠标的窗口移动捕获。Windows 在隔离 WinSta0 桌面使用发给所属窗口的原生 Alt 消息，再运行已渲染按钮的回调。Windows 隔离桌面的鼠标消息未到达 Flutter，原生指针端到端在后续实机补验中通过。Flutter widget 测试也覆盖了按钮命中。[固定版、基线和双端发布回执](p05.382-group-split-toolbar/native.json)。

## Windows 原生鼠标补验

在 Windows 125% DPI 上复验产品 0db66fd9896a03c9450c5e455ee648381500eafb 的精确发布构建。普通窗口单击后两组横向排列。Zen 全屏中按住 Alt 单击后右列增加下方组。两次实际指针送入 Flutter 的按下和抬起事件均有记录。Alt 松开后变体恢复，退出 Zen 恢复原生窗口范围。系统关窗以 0 退出，BOM、CRLF、中文与 Emoji 文件字节一致。[原生鼠标回执](p05.382-group-split-toolbar/windows-pointer.json)。
