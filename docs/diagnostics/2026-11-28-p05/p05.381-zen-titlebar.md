# P05.381 Zen 默认标题栏与命令中心

主窗使用默认自定义标题栏时，进入 Zen 后可继续使用标题栏和命令中心。状态栏随 Zen 隐藏。退出 Zen 后恢复原窗口范围和状态栏。正常关窗后，使用同一配置重启可以恢复 Zen 及其标题栏。
