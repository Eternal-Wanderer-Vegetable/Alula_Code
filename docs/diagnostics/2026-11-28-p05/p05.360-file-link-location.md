# P05.360 本地文件链接行列与区间定位

## 依赖和范围

P05.359 / feat-411 提供本地链接悬停打开入口，P05.193 / feat-245 提供 UTF-16 文件区间定位，均已完成。固定 Code - OSS 1.145.0 的提交为 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e。其位置片段支持可选的 L、1 基行和列、可选结束位置。编辑器打开器提取位置后打开文件，模型校正越界与代理对边界。参见 [固定版本 URI 解析](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/platform/opener/common/opener.ts#L126-L159)、[编辑器打开器](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/browser/services/openerService.ts#L74-L97) 和 [模型位置与选区校正](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/model/textModel.ts#L1028-L1159)。

打开前从文件路径去除 URI 片段，保留路径中的编码井号。已解码片段按 UTF-16 模型列处理，未知片段仍打开文件。命令、Ctrl/Cmd 点击、Alt 侧开及悬停提示共用打开路径。过宽区间沿用有界输入窗口和跨窗口选区。Rust ABI 51。CMD-12 其余本地路径或 URL 的识别以及 P14 对外打开与可信域见 [P05 交付顺序](../../plans/p05-completion.md)。
