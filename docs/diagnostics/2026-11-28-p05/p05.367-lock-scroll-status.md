# P05.367 同窗滚动锁定状态栏入口

## 实现

有效锁定时，主工作台状态栏显示可点击的「滚动已锁定」入口。关闭锁定时移除该入口及其间距。提示为「滚动锁定已开启」，辅助功能树包含一个按钮标签。点击沿用现有 Toggle，Hold 按下、反向 Hold 和释放使用同一个有效状态。跨窗口显示和同步继续由 LAY-15 追踪。[固定版本状态入口](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/scrollLocking/browser/scrollLocking.ts#L161-L181)。
