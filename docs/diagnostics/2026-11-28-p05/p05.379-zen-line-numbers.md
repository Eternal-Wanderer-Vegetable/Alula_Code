# P05.379 Zen 普通文本编辑器行号

主窗普通文本编辑器使用现有行号参数遵循 Zen 状态。进入时停止绘制行号，退出后恢复。两个编辑组和在 Zen 中新建的文本编辑器继承当前显示状态。包含 Rust 折叠标记的边栏仍绘制这些标记。

## 固定版与双平台验证

- 固定 Code-OSS 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e 的默认配置在 Windows 125% DPI 下实测。两个编辑组的行号在进入前显示，进入后隐藏，新建未命名文本也隐藏。退出后两组行号恢复，系统关窗退出码为 0。[固定版本默认配置](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/workbench.zenMode.contribution.ts#L61-L64)。[固定版本编辑器更新](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/layout.ts#L1461-L1513)。
- Alula 同一 Windows 基线的进入前、进入后、新建后及退出后都绘制两组行号。发布构建在 Windows 私有桌面和 Linux 独立 Xvfb/Xfwm4 的四阶段均呈现 2、0、0、2 组行号。样本文档有 400 行带 BOM、CRLF、汉字和 Emoji 的正文及末尾空行，新未命名文本为单行。两次系统关窗退出码为 0，样本全部磁盘字节一致。[固定版、基线和两端原生记录](p05.379-zen-line-numbers/native.json)。
- 专项组件验证还检查了 Rust 折叠标记、Rust 文档版本、全文一致和原始磁盘内容。
