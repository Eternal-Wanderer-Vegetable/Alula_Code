# P05.387 工作区独立居中布局

普通窗口的居中由查看菜单的外观子菜单和规范命令 `workbench.action.toggleCenteredLayout` 控制，菜单勾选反映请求状态。设置按工作区存储。主窗单编辑区采用比例留白，横向分组临时展开，最大化、纵向分组和关闭多余组时恢复居中。侧栏和面板继续由工作台网格分配。参与居中的编辑区域沿用原视图和文档。Zen 自动启用的居中在退出时恢复普通模式，原本已经居中时可以在 Zen 内修改工作区偏好。

## 固定版与发布构建

- 固定 Code-OSS 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e 在 Windows 125% DPI 下验证普通窗口、Problems 面板、横纵拆分、Zen 和退出。四次隔离启动确认 A 启用后重启仍居中，B 使用默认展开，回到 A 后继续居中。额外序列验证自动居中与手动居中各自退出 Zen 的状态。
- Windows 私有桌面及 Linux Xvfb/Xfwm4 的发布构建验证相同命令路径、面板、横纵分组、组最大化和视口还原。实测编辑区宽度、居中后宽度与单侧留白依次为 Windows 875.52 / 541.52 / 167、Linux 885.40 / 547.40 / 169 逻辑像素。两端各四次进程启动验证工作区状态、系统关窗和文件字节，源样本包含 BOM、CRLF、中文与 Emoji。[固定版与发布构建回执](p05.387-centered-layout/native.json)。
- 定向测试验证同一编辑器状态、工作区切换、重开与 Zen 内手动切换。侧边留白的调节动作、复杂编辑形态和设置可配置行为继续登记在对应验收范围。
