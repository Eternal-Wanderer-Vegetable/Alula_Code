# P05.361 真实空行后的诊断详情占位

## 实现和范围

P05.351 的空格或 Tab 方案已完成。本项补齐真实空行后紧邻无可用空白的代码、首个可视行无空白以及连续空行。F8 将详情放在诊断空行和下一行之间。显示层用一份 792 字节的内置字体为现有 LF 或 CRLF 增加行下部高度，复用编辑器行基线和行号布局。字体只作用在目标换行，文档文本和 UTF-16 索引继续由 Rust 管理。可见折叠导致常规行基线机制停用时，沿用原有浮层定位。
