# P05.384 编辑器组更多操作中的锁定与最大化

主窗默认多标签组菜单可以锁定或解锁点击组。在多个编辑器组中，菜单可以最大化点击组，并将最大化组还原。动作复用现有布局和激活方法，文件及已有视图保持原身份。

## 固定版和双端发布验证

- 固定 Code-OSS 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e 在 Windows 125% DPI 下从非活动左组触发 Lock Group。左组进入锁定，右组仍活动，菜单改为勾选。从左组执行 Maximize Group 后只显示左组，左组成为活动组。Unmaximize Group 恢复两组原范围及右组文件，左组锁定与活动状态保持，最后再次执行 Lock Group 解锁。
- Windows 与 Linux 发布构建按同一顺序复验。两个组复原前后宽度、位置和高度的最大差异均为 0 逻辑像素。含 BOM、CRLF、中文和 Emoji 的共享文档及右组独有文件在两次系统关窗后字节一致。Windows 通过渲染后的 PopupMenu 路由选择，Linux 以隔离 Xvfb/Xfwm4 的真实指针操作。[固定版与双端原生回执](p05.384-group-menu-state/native.json)。
- 此范围包含两项状态操作与恢复。默认 Zen 居中尺寸和其他配置入口继续单独对照。
