# P05.362 相对文件 URI 源目录解析

## 实现和固定版本规则

支持 `file://./` 和 `file:///./` 相对当前文件目录打开。先识别原始 URI 中的相对标记，再解码文件名并按本机路径解析，覆盖父目录、编码的点、空格和井号。相对重写后的 URI 采用普通打开位置。绝对 URI 继续处理行列片段。目录、非相对 authority、空字节和无文件路径的未命名编辑器由集成回归覆盖。跨阶段的外部资源打开与可信域按 P14 归属。

固定 Code OSS 1.145.0 的提交为 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e。读取同一提交的链接重写规则，并在 Windows 和 Linux 运行其编译后的 URI、链接检测和路径实现。两种书写形式、父目录、编码点和文件名的计算结果已对照。相对重写采用源文件目录，丢弃原 URI 的查询和位置片段。[固定版本链接重写](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/links/browser/links.ts#L221-L253)。
