# P05.383 编辑器组更多操作中的打开与关闭

主窗默认多标签模式的非空编辑器组提供「更多操作」入口。菜单可以列出点击组的已打开编辑器、关闭该组全部普通标签，或仅关闭已保存的普通标签。两种关闭继续使用共享文档、固定标签和脏确认的现有规则。

## 固定版和双端发布验证

- 固定 Code-OSS 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e 在 Windows 125% DPI 下，非活动左组的 Show Opened Editors 通过 edt active 前缀仅列出左组文件。打开列表时左组成为活动组，Escape 恢复原活动右组。从左组菜单执行 Close Saved 移除清空的左组，右组的共享文件和独有文件全部保留。
- Alula 两端发布构建复验了同一场景。Windows 的菜单打开和选择经渲染后的 PopupMenu 路由，Escape 由所属 Flutter 窗口的原生消息触发。Linux 通过隔离 Xvfb/Xfwm4 的鼠标点击和 Escape。两次系统关窗均退出 0，含 BOM、CRLF、中文和 Emoji 的源文件与独有文件字节一致。[固定版及双端发布回执](p05.383-group-more-actions/native.json)。
- 新增 widget 用例覆盖单组列表选择和取消、关闭已保存的共享视图、固定和脏标签保护、取消关闭。窄窗基线回归表明追加按钮会占用可拖动的标签宽度。将 LSP 启动入口移入同一菜单，沿用原按钮位。窄窗拖动排序和中键关闭恢复通过。锁定、最大化和配置相关入口继续单独对照。
