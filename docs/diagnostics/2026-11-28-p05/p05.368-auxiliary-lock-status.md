# P05.368 辅助窗口滚动锁定状态与切换命令

## 实现

主工作台持有会话开关，并把当前有效状态发布给已登记的辅助窗口。辅助窗接收最新版本，普通模式在有效锁定时显示「滚动已锁定」，并通过状态栏点击或命令面板调用同一个切换命令。紧凑模式隐藏状态栏入口。启用时新开的辅助窗获取当前状态，关闭后主窗保留锁定。后续 LAY-15 验收继续覆盖跨窗滚动位移和辅助窗 Hold 键位。[固定版状态项和 Toggle](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/scrollLocking/browser/scrollLocking.ts#L161-L206)。[固定版紧凑模式](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/auxiliaryEditorPart.ts#L237-L248)。

## 原生验收

- Windows 125% 和 Linux Xvfb + Xfwm4 各通过 16 项。使用实际键盘和鼠标检查启动、主窗 Toggle、按住与释放、辅助窗状态栏点击、F1 选择、紧凑模式、关闭以及已启用时新增辅助窗。主窗 Hold 暂时隐藏两边指示，释放时恢复。点击或执行 Toggle 会更新会话开关。
- 两端均使用 ABI 51。两个含 BOM、CRLF 和 Emoji 的文件在开窗、切换与关闭后字节 SHA-256 一致，应用正常退出。[原生状态、源码与构建哈希](p05.368-auxiliary-lock-status/native.json)。
