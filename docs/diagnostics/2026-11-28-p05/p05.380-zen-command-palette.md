# P05.380 默认命令面板位置

主窗使用默认自定义标题栏时，Command Palette 的卡片距 Flutter 视口顶部 6 逻辑像素并水平居中。普通窗口、Zen 和退出后的尺寸变化沿用同一位置规则。通过 QuickInput 的可选顶部间距接入该入口。

## 固定版和两端原生结果

- 固定 Code-OSS 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e 在 Windows 125% DPI 下通过 F1 在三个阶段打开命令面板。绘制卡片的顶部都是 6 逻辑像素，输入均获得焦点，退出后窗口回到原范围。默认命令中心由工作台布局设置 Quick Pick 的顶部偏移。[固定版本容器偏移](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/layout.ts#L253-L275)。
- Alula 同一 Windows 基线实测顶部为 56，三个阶段均偏下 50 逻辑像素。Windows 发布构建和 Linux Xvfb/Xfwm4 发布构建通过 6 像素间距、水平中心、聚焦和窗口复原。快速打开另测为 56 逻辑像素。两次系统关窗退出码为 0，原文档磁盘字节一致。[固定版、基线和原生卡片位置](p05.380-zen-command-palette/native.json)。
