# P05.364 同窗横向锁定滚动位移

## 实现

开启锁定滚动时记录同窗各可见编辑视图的纵向和可用横向起点。任一轴滚动时，从该视图的起点计算两轴位移，再按目标视图起点和滚动范围应用。并排的编辑视图各持有独立位置。拆分、合并或视图离开时重新取起点并释放旧横向监听。解除锁定和工作台销毁时同样移除横向监听。固定版 Hold、状态栏与跨窗范围继续由 LAY-15 追踪。[固定版本滚动实现](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/scrollLocking/browser/scrollLocking.ts#L66-L150)。
