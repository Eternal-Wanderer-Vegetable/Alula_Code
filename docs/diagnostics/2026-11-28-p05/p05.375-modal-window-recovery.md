# P05.375 主窗退出保存模态草稿供恢复

模态编辑期间由工作台记录仍打开的脱离文档。正常关停先提交待处理输入，再把脏模态文档的正文与文件格式放入现有会话组。重启可从已有会话恢复为可编辑文件标签。会话写入失败时保留模态窗口和未保存正文并允许再次关闭。

- 阻塞会话目标后按正常路径关闭。两端主窗均保持可见，模态仍显示并保留精确正文。复位测试目录后重试通过。Windows 只向私有桌面内的测试窗发送关闭消息。Linux 在隔离 Xvfb 和 Xfwm4 用 Alt+F4。[原生回执、参考版对照及构建哈希](p05.375-modal-window-recovery/native.json)。
