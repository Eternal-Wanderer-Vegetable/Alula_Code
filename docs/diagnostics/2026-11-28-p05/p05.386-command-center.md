# P05.386 自绘标题栏命令中心的宽度与文件搜索入口

自绘标题栏将命令中心设置在可用的居中位置。窗口变宽时搜索项按 38% 扩展，内容宽度上限 600 逻辑像素。窄窗控制邻接的菜单和窗口按钮宽度。搜索两侧的可用区域支持拖动窗口。点击、Enter 或 Space 触发 `workbench.action.quickOpen`，通过现有前缀进入命令等搜索模式。

## 固定版和发布构建

- 固定 Code-OSS 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e 的 Windows 125% DPI 对照将 Agent Status 和 AI 入口关闭，以观测普通搜索。经典搜索入口在普通窗口和 Zen 都打开空查询，键入文件名筛选，Escape 后重开为空，键入 `>` 切换命令提供程序。
- Windows 私有桌面使用渲染后的标题栏入口和输入，Escape 由窗口接收。Linux 使用隔离 Xvfb/Xfwm4 的 X11 指针与键盘。两端在窄窗均能打开并取消搜索，普通窗口可查询文件和通过前缀切到命令，Zen 可进入原生全屏、搜索并恢复窗口。三次取消恢复编辑器焦点，关窗退出为 0。BOM、CRLF、中文和 Emoji 的源字节一致。[固定版与双端原生回执](p05.386-command-center/native.json)。
- 普通、窄窗和 Zen 的逻辑视口宽度与搜索项实测宽度依次为 Windows 1204 → 459.52 / 647.2 → 247.94 / 2048 → 602.00、Linux 1217 → 464.46 / 660 → 216.49 / 1920 → 602.00。窄窗尺寸受菜单和窗口按钮所需空间限制。
- Linux 基线由实际指针打开搜索后，Escape 关闭了弹层，焦点停在窗口焦点域。修复在点击时记下工作台焦点，并在打开搜索前完成焦点交接。定向回归确认鼠标、Enter 和 Escape 恢复同一个编辑器焦点节点。
- 这里覆盖命令中心的宽度和基本搜索路径。固定版外层同时容纳前进和后退按钮，并显示独立的初始帮助行。其搜索框相对中心的偏移、帮助行和弹层位置仍是待核对差异。Alula 保留现有标题文字和色彩。
