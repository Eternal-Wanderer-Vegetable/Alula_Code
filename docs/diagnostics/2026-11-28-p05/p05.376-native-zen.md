# P05.376 Zen 原生全屏与窗口生命周期

进入 Zen 时检查原生全屏状态。普通窗口切入全屏，Zen 退出时恢复进入前的范围。已经全屏的窗口继续保留全屏。外部退出由 Zen 引发的全屏后，工作台恢复普通布局入口。Windows 的无边框全屏退出可漏发窗口事件。此时视口变化触发一次原生状态查询并恢复布局。

标题栏在 Zen 中移出可见界面，保留原生窗口关闭监听。系统关窗继续走现有工作台会话保存。重启时等待窗口可见，再恢复已保存的 Zen 状态及原生全屏。
