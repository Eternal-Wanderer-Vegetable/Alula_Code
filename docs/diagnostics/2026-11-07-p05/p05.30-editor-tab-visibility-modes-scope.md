# P05.30 / LAY-08a：编辑器标签显示模式

## 矩阵要求与当前缺口

`docs/11-VSCode功能对照矩阵.md` 的 LAY-08 要求 multiple/single/none、wrap/multirow、标签尺寸、关闭按钮、图标和路径消歧。本切片只处理 `workbench.editor.showTabs` 的 `multiple`、`single`、`none` 三态及运行时切换；LAY-08 剩余表现细节另行登记。

当前 `WorkbenchPage` 总是渲染 `_buildTabStrip`，并为 `EditorGroup.docs` 中每个文档绘制标签；没有 single/none 模式、模式选择命令或该选项的持久化。目标实现默认 `multiple`，通过 View > Appearance 中的三态选项修改；保存为会话设置，在关闭/重启后恢复，不写入编辑器分割布局树。`single` 只显示当前活动文档的标题标签，`none` 隐藏标签内容但保留编辑器组工具区和主体编辑器。

## 固定上游语义

- `DEFAULT_EDITOR_PART_OPTIONS.showTabs` 默认是 `multiple`；校验器只接受 `multiple`、`single`、`none`。
- `EditorTitleControl` 为 `multiple` 创建多标签/多行控件，为 `single` 创建单活动标签控件，为 `none` 创建无标签控件。`showTabs` 改变时销毁旧控件并创建新控件；`NoEditorTabsControl` 的标签高度为 0。
- `EditorGroupView` 在标签选项变化时更新标题容器并重新布局。

## Alula 验收范围

- 定义三态显示选项，默认 `multiple`；仅接受 `multiple`、`single`、`none`，非法或缺失存储值回退 `multiple`。
- 在 View > Appearance 提供三个可访问、互斥且实时反映当前值的选择项。选择后所有编辑器组立即更新，不重建文档或丢失 active tab、焦点、selection、滚动及 Rust 文档状态。
- `multiple` 保留现有标签条及已有点击/关闭/拖动行为；`single` 只显示当前活动文档，切换活动标签仍通过现有打开编辑器路径；`none` 不显示标签项但保留拆分、LSP、补全和一致性操作，编辑区域与面包屑可用。
- 会话保存/恢复三态，切换模式不改编辑器组拓扑与布局 JSON；无文档、单文档/多文档、脏文档与多编辑器组场景切换可用。
- 增加 widget/单元验收，覆盖菜单当前态、三态渲染/动态切换、会话 round-trip、多个 editor group、无文档及已有编辑器状态保持。

不包括：wrap/multirow、pinned/sticky 标签语义、标签 sizing/height、关闭按钮显示规则、图标主题或标签图标开关、路径消歧、标签重排/拖放/overflow、设置编辑器/JSON settings 完整实现；不改 Rust、FFI、ABI 或保存协议。

## 产品实现与本地验收

### 实现

- 新增 `EditorTabMode`，只解析 `multiple`、`single`、`none`；会话值缺失或非法时回退 `multiple`。
- 在 View > Appearance 新增三个互斥命令；菜单同时暴露 checked 语义和可见勾选状态。选择后一次更新所有 editor groups。
