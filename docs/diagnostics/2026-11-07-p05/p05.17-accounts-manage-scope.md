## 本切片范围

- 在纵向 Side 和横向 Top/Bottom Activity Bar 都显示 Accounts 与 Manage 两个全局动作；Accounts 在 Manage 前，Manage 固定且不可隐藏。
- 两个入口可用鼠标、Tab、方向键、Enter/Space 操作，并提供按钮、tooltip、popup/选中状态等语义。
- Accounts 主动作显示真实支持边界：目前没有 authentication provider，显示“尚无可用帐户提供程序”，不伪造登录、帐户或同步状态。Accounts 右键提供 Hide Accounts；Activity Bar 空白区/Manage 右键可勾选显隐 Accounts。
- Accounts 默认显示；显隐写入现有根 layout JSON，旧 JSON 迁移到默认显示，格式错误时回退默认值。
- Manage 主动作打开菜单，并分发到当前已注册的命令（命令面板、侧栏/面板切换、关于）；不能把尚未交付的 Settings、Profiles 或登录能力列成可执行菜单项。
- 保持现有 view 排序、pin、badge、尺寸与 Activity Bar 位置；全局动作不参与 view 拖放排序。

## 暂不覆盖

- Authentication sessions/providers、登录、登出、账户头像与 Settings Sync 属 P13/NET。
- User Data Profiles 的创建、切换、菜单和 Manage 图标/徽章属于 P07；当前 Manage 使用固定 Alula 管理图标，不伪造 profile。
- Settings UI、键位编辑器、主题选择、用户片段等目前未注册的管理器功能不做假入口；后续按 P05/P07 独立切片。
- LAY-03 中 Activity Bar 的其余设备/golden 验收与 P05 其余 LAY/CMD 矩阵项目继续开放。
