Status: scope registered; product implementation not started. This is the first bounded slice for the Panel position portion of LAY-05. It does not close LAY-05 or P05.

- Matrix requirement: `LAY-05 / parity-lay-05` in `docs/11-VSCode功能对照矩阵.md` requires Panel location/alignment/maximize/restore/drag/drop and minimum-size correctness. This slice covers only Top/Bottom placement, command/menu behavior, and persistence.

## Registered scope

- Register the two fixed command IDs and titles above in the View category and Command Palette. The current location is checked in `View > Appearance > Panel Position`; selecting the active position is idempotent.
- Move Alula's existing `panel` leaf to the first or last child of the root vertical split for Top or Bottom. Bottom remains the default. Preserve the leaf object state (`weight`, `collapsed`, `lastWeight`, minimum extent), every other child and its order, root metadata, Activity Bar placement/size/order/pins/badges/Accounts, primary/secondary sidebar positions and assignments, and editor split state.
- Persist the resulting root tree through the existing layout-store path and restore it on remount. Do not add a second storage source or FFI/ABI fields.
- Verify the model in both directions, active-position no-op, default Bottom and legacy JSON behavior, hidden/collapsed Panel moves, serialization round-trip/remount, command palette invocation, menu checkmark, and preservation of unrelated layout state (including Activity Bar Top/Bottom and Side Bar Left/Right).

## Explicit exclusions

- Panel Left/Right placement; Center/Justify/Left/Right alignment; maximize/restore; Panel title context menu; drag/drop or moving/grouping Panel views; sash behavior and minimum-size constraints; floating layout; changes to Activity Bar, sidebars, editor groups, Rust/FFI/ABI, or workspace persistence.
- These exclusions remain open LAY-05 work and must be registered separately. P05 remains in-progress.
