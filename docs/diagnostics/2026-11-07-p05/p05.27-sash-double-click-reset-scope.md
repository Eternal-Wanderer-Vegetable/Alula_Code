## Alula 范围

- 只为当前实际渲染的 WorkbenchGrid sash 增加双击复位。
- 复位该 sash 直接相邻的两个弹性节点，使它们在各自最小尺寸约束内均分当前合计主轴尺寸。
- 不改变其它兄弟节点当前尺寸；固定和折叠节点不参加复位。当前 renderer 只在相邻弹性节点间绘制 sash，因此行为覆盖其全部可见分割线。
- 将新比例写回布局权重，沿用现有 Panel alignment 投影回写、布局通知和 root layout JSON 持久化路径。重挂载及窗口缩放后保留两侧相等比例。
- 为模型和真实 GestureDetector 双击路径添加回归覆盖：横/纵轴、最小尺寸、其它兄弟不动、固定/折叠节点、alignment 投影、layout JSON 往返及 resize 后比例。

不包括 Panel/Side Bar view 拖放、被折叠节点之间的 sash、snap 行为、区域折叠策略重做、跨屏 DPI/缩放验收或 P05.28 之后的其他 LAY-06 项。该切片不关闭 LAY-06 或 P05。
