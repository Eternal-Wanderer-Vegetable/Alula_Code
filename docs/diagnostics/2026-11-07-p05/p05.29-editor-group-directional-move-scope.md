## 矩阵要求与当前缺口

`docs/11-VSCode功能对照矩阵.md` 的 LAY-07 要求编辑器组支持方向布局以及组间编辑器移动/复制。P05.28 / LAY-07a 已交付四向拆分与活动文档复制；当前工作台尚未注册 `workbench.action.moveEditorToAboveGroup/BelowGroup/LeftGroup/RightGroup`。本切片仅交付方向移动当前活动编辑器。

## 固定上游语义

- `editorCommands.ts` 定义四个方向移动命令。标准活动编辑器调用按方向查找目标组；没有目标时，用同一方向新建组；将源编辑器移动到目标组并聚焦目标组。
- VS Code 的 `moveEditors` 迁移选中的 editor input。Alula 本切片将命令范围限制为焦点组的当前活动视图，直接迁移该视图对象，从而保留选择、滚动和 Rust 输入窗口；权威文档/版本/保存状态继续共享。
- 命令无活动文档时不变更布局。若迁移使源组变空，沿用现有空组清理及 split 树折叠行为。

## Alula 验收范围

- 注册上游四个命令 ID，分别按 Left/Right/Up/Down 寻找目标编辑器组。
- 目标组存在时移动活动编辑器视图；目标不存在时创建正确方向的新组后移动。不得复制文档、重建编辑视图或丢失原 view identity、selection、scroll、IME/input-window state。
- 目标组取得焦点并激活移动视图；源组保留其它 tabs 的顺序与活动文档状态。源组变空时执行既有移除逻辑并保持有效的嵌套 layout tree。
- 文档继续指向同一 Rust 权威内容、版本、undo/save 状态。跨组已有同文档视图时不得产生重复 tab 或提前释放共享文档；目标已有该文档时聚焦目标视图并安全移除源视图。
- 覆盖四方向已存在/新建目标、嵌套布局、单 tab 与多 tab 源组、空源组折叠、同文档目标、no-active no-op、新焦点、视图身份/选择/滚动保留和 root layout JSON 往返/重挂。

不包括：复制编辑器到其它组或窗口、非活动/多选编辑器移动、组内 tab 顺序调整、tab/组拖放、同组 split、组均分/最大化/锁定、未实现的方向键绑定；不改 Rust、FFI、ABI 或保存协议。
