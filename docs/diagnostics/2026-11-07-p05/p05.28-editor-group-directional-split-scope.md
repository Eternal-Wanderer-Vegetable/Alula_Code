## 矩阵要求与当前缺口

`docs/11-VSCode功能对照矩阵.md` 的 LAY-07 要求编辑器组支持水平/垂直分割，并在布局树中保留其顺序和嵌套关系。当前 Alula 仅有 `editor.split`：它调用 `_splitFocusedGroup`，固定沿 `Axis.horizontal` 在当前组后创建空组；用户还要再次打开文件，才会得到两个同文档视图。模型 `splitLeaf` 也只把新叶子插在原叶子之后，因此没有 Left/Up 插入路径。

## 固定上游语义

- `src/vs/workbench/browser/parts/editor/editorCommands.ts` 定义 `workbench.action.splitEditorLeft/Right/Up/Down`。`splitEditor` 根据方向创建相邻组，将当前组可拆分的活动编辑器复制到新组，并聚焦新组。
- 默认 `workbench.action.splitEditor` 对应编辑器工具栏拆分动作；Alula 在本切片将其映射为 Right，保持现有默认横向右拆。
- VS Code 的组布局是嵌套树，方向与组顺序均影响可见位置；现有 root layout JSON 已可保存 WbSplit 树。

## Alula 验收范围

- 注册四个方向命令 `workbench.action.splitEditorLeft/Right/Up/Down`；保留 `editor.split` 并映射到 Right。方向决定正确主轴和插入顺序，且新组取得焦点。
- 在新组复制当前活动文档视图；同一 Rust 文档继续共享权威内容/版本/保存状态，但每个视图保持独立光标、选择、滚动和输入窗口状态。无活动文档时不创建空组。
- 支持在已分割的任一组继续分割，已有嵌套树、其它组、组内 tabs 和各组活动视图不丢失。
- root layout JSON 保存/恢复横纵向嵌套与区域顺序；重挂载后组边界、方向、可见位置和对应文档视图保持一致。
- 对命令层、模型和真实 Workbench 集成添加测试；覆盖 Left/Right/Up/Down、新组焦点、同文档独立视图、嵌套布局、既有组不变以及 JSON round-trip。

不包括：同组 split editor、现有 tab 的 move/copy/reorder、组均分/最大化/锁定、组间拖放、浮动窗口或 P05 后续 LAY-07 项；不改 Rust、FFI、ABI 或文档协议。
