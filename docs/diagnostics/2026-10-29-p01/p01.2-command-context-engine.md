# P01.2 命令与上下文引擎

日期：2026-10-29
范围：SRV-06 / `docs/11` `parity-srv-06`
内存优先级：本阶段暂停 500 MiB 数值门；本切片不做占用优化。

## 实现

- `CommandService` 将命令 ID、可选参数、可见条件、启用条件和执行状态集中管理。分发结果区分 `unknown`、`hidden`、`disabled`、`unsupportedArguments` 与 `executed`。
- `ContextKeyService` 提供条件表达式：标识符、`!`、`&&`、`||`、`==`、`!=`、括号；解析错误 fail-closed。context 更新即时通知订阅者。
- 标题菜单、命令面板、全局键位、编辑器工具栏、面板标签和编辑器焦点链中的撤销/重做/查找入口通过命令 ID 分发。命令面板与菜单根据 context 刷新可见/启用状态。
- `keybindings.json` 可选 `args` 与 `when`；键位过滤 context 后将参数传给同一执行服务。现有无参数条目和 `resolve()` API 保持可用。
- workbench 同步 `editorActive`、`editorDirty`、`editorTextFocus`、`editorCanUndo`、`editorCanRedo`、`workspaceOpen`、`lspStarting`、`lspReady`。
