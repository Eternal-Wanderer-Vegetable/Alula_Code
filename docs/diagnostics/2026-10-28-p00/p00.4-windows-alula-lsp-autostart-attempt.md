## Interpretation limit

All 45 samples observed one process, `alula_app.exe`; no rust-analyzer child was observed. Treat this as an autostart attempt only, not a Rust+LSP memory sample. The default profile session file existed and its metadata showed a workspace entry resolving to an existing directory. `_restoreSession` runs before `_initCore` checks `autoFolder`; a restored `_workspaceRoot` makes `openedFolder` false, so the delayed `autoLsp` callback is skipped. This explains the single-process attempt. A fresh temporary `HOME` produced the Rust + rust-analyzer process tree in `p00.4-windows-alula-rust-lsp-summary.md`. The user-profile session timestamp predated the run; no path or document text was included here.
