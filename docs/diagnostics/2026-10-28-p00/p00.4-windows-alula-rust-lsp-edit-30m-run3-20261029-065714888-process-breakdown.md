## Limits

- `cargo.exe` was observed once at edit elapsed 1070 seconds, outside the retained tail. This does not establish its launch duration or peak contribution.
- The 129 PID rows are sparse process snapshots, not per-process one-second timelines. The one-second timeline records only process-tree totals.
- The Windows Release executable came from the shared worktree. Pre-existing uncommitted `app/` changes existed then; this attribution is not a clean-commit build claim.
- This report does not justify disabling rust-analyzer features or changing the 500 MiB target. Any resource/configuration trade-off must preserve editing and save reliability and be explicitly evaluated against the pinned feature scope.
