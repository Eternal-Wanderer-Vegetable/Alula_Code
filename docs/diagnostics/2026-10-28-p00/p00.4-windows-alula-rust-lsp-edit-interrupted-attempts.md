# P00.4 Windows Alula Rust + rust-analyzer scripted editing attempts

## Successful preflight

The isolated Windows Release app opened a copied `rust-mini` fixture under a temporary `HOME`. Six source comments were entered through the Alula window and verified on disk by marker and SHA-256. The edit window was 30.0 seconds; 40 one-second memory samples were recorded. Peak/stable/final Private Bytes were 653.84/645.64/608.53 MiB. All seven observed process IDs had exited at the 30-second close check, and the temporary fixture and home were removed.

This is a short preflight only. It does not count toward the 30-minute acceptance and its stable memory observation is above the 500 MiB target.

## Formal attempts

Three attempts to start run 1 stopped when Windows foreground ownership left Alula. The first two changed to the same File Explorer window (HWND 201794, PID 8696). The third changed to Windows Sandbox (HWND 12781196, `WindowsSandboxRemoteSession.exe`, PID 46760); its structured abort report records 732.329 seconds and 61 saved edits. In every attempt the guard stopped further input and the Alula/mem-probe process trees were terminated.

All three attempts are invalid for acceptance and do not establish a product failure or memory result. Structured evidence is in `p00.4-windows-alula-rust-lsp-edit-interrupted-attempts.json` and `p00.4-windows-alula-rust-lsp-edit-30m-run1-20261028-204339106-abort.json`.

## Script updates

`p00.4-windows-alula-rust-lsp-edit-30m.ps1` now stops its edit timer at the end of the editing window and writes a separate abort JSON record with foreground handles, elapsed time, saved edits, observed process IDs, and an explicit invalid-memory-report flag. The first two interrupted runs happened before that abort-record change, so their details are recorded from session observations. Attempt 3 verifies the abort JSON path and captured the changed HWND, elapsed time, saved edits, and observed process tree.

Each run's report contains 1808 one-second samples, and all observed PIDs were gone at the close+30-second check. The exact reports, activity logs, and stderr are linked in `p00.4-windows-alula-rust-lsp-summary.md`. These completed repetitions do not erase the invalid attempts below.
