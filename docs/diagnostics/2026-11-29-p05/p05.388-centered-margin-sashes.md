# P05.388 居中编辑区边距分隔线

在主工作台的普通居中和 Zen 居中状态，拖动任一边界按方向调整两侧边距。Alt 可在空间允许时调整单侧，松开或按下 Alt 时从当前指针与布局继续。边界限位保留编辑区和可用留白，任一边界双击恢复两侧默认值。拖动完成后将比例保存在布局配置档，同一档内的新工作区启用居中后使用该比例。工作区的居中开关沿用 P05.387 的独立状态。
