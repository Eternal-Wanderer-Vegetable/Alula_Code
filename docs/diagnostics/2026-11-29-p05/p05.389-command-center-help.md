# P05.389 命令中心初始快速访问模式

自绘标题栏经 `workbench.action.quickOpenWithModes` 打开快速访问。初始或仅含空白的查询显示已有的文件、命令、文档符号及更多模式，转到文件默认聚焦，最近文件继续显示在模式后。明确选择转到文件后进入普通文件列表，Ctrl+P 也使用普通入口。键入前缀或选择已有模式进入各自提供程序，清空查询恢复本次标题栏入口的建议。Esc 恢复此前编辑器焦点。
