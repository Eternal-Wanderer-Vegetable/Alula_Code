# P05.392 标题栏导航历史按钮

主工作台的自绘标题栏在命令中心前显示后退和前进，按钮可用状态来自现有导航栈。接受新位置、往返和移除已关闭的未命名文档时，同步历史状态。已有文件的历史位置可以在工作台为空时重开，恢复保存的位置和编辑器焦点。标题栏保留原来的文件搜索、菜单和窗口控制路径，快捷提示使用当前登记键位。
