# P05.259 / feat-311 · 速览预览内容双击打开

固定版 Code OSS 在预览上第二次按下时使用鼠标命中的实际范围。Alula 从可选择文本的段落取得点击位置，扣除行号前缀并加上本行截取前的 UTF-16 列。普通双击在当前组打开目标预览并关闭速览。Ctrl、Meta 或 Alt 双击沿用侧开预览，来源速览保持可操作。
