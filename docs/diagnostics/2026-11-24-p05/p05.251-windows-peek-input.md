# P05.251 / feat-303 · Windows 只读速览字符和快捷键投递

Windows 中文键盘布局 0x0804 的原生追踪复现了 P05.250 的扫描码差异。F4 到达 FLUTTERVIEW，随后 x 的扫描码 0x2d 转成 `VK_PROCESSKEY` 并启动 IME 组合。当前组合长度为 2 字节时，F12 的按下同样转成 `VK_PROCESSKEY`，Flutter 停留在上一个引用。基线追踪仅增加私有原生消息日志，Dart AOT 与 P05.250 Windows 通过构建的哈希相同。[P05.250 验收和原始复现](./p05.250-peek-focus.md)

只读速览的结果树或预览持有焦点时，Windows runner 暂时解除本窗口 Flutter 子窗口的输入法上下文关联。焦点回到可编辑区域或速览关闭时重新关联保存的上下文。速览销毁也会恢复关联。组间切换继续复用同一个上下文生命周期。[Microsoft ImmAssociateContext 文档](https://learn.microsoft.com/en-us/windows/win32/api/imm/nf-imm-immassociatecontext)
