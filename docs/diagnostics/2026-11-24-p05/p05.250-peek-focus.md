# P05.250 / feat-302 · 速览树与只读预览焦点切换

定义与引用速览共享 `togglePeekWidgetFocus`。Windows/Linux 默认 Ctrl+K F2，macOS 默认 Cmd+K F2。结果树与只读预览可来回切换，预览获焦时显示边框。引用定位沿用原来的预览、结果树或主编辑器焦点。关闭归还宿主编辑器焦点。
