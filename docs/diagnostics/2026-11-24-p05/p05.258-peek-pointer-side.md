# P05.258 / feat-310 · 速览结果树鼠标侧开

固定版 Code OSS 对树结果的 Ctrl、Meta 或 Alt 加主键单击采用侧开，并让目标使用预览标签。Alula 在按下时保存修饰键，在有效单击后处理侧开。点击结果树由速览接收，底下的源码编辑器保留原光标和文档。干净侧开预览可由下一次侧开替换，键盘侧开仍可保留目标为常规标签。
