Date: 2026-10-31. Workflow [run 41221325692](https://github.com/Eternal-Wanderer-Vegetable/Alula_Code/actions/runs/41221325692) downloaded the exact x64 Release package `alula-windows-x64-d5319369c5b5d569954e0d816daf325f3bc12a51` from [artifact run 41109679662](https://github.com/Eternal-Wanderer-Vegetable/Alula_Code/actions/runs/41109679662). The UI jobs ran on GitHub's `win11-vs2026-arm64` image: Windows 11 Enterprise build 26200, ARM64 host, x64 emulation. Both light and dark registry settings were exercised at 96 DPI (100% scaling). This is hosted Windows 11 ARM evidence, not native x64 evidence; a separate native Windows 11 x64 replay is recorded in [the exact-artifact report](../2026-10-31-p03/p03.7-exact-windows-artifact-41109679662.md).
