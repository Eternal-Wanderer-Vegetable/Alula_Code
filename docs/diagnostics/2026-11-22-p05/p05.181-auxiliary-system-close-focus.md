# P05.181 / feat-233 · Windows 辅助窗系统关闭后的焦点交接

P05.180 的 Windows 11 125% DPI 轨迹记录到一次 Alt+F4 交接。关闭前辅助窗及编辑器均获焦，主窗接收脏正文和 UTF-16 选区 `[21, 20]`，采样时主窗及编辑器均未获焦。激活标签后可继续输入。采样期间调整过两窗位置，单次记录无法归因于贴靠。固定版的系统关闭先合并待确认的编辑器，再对接收组请求焦点。[P05.180 轨迹](p05.180-auxiliary-close-return/native.json) · [固定版源码](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/auxiliaryEditorPart.ts#L444-L495)

Windows 辅助窗收到系统关闭事件并得到主窗接收确认后，请求原生前台交接。回调只在待关闭辅助窗仍为前台且主窗可见、未最小化时请求激活。原生激活失败仍可完成已确认的文档交接。主窗接收时为返还文档准备编辑器焦点。标签关闭、应用顶栏关闭、拖回关闭与其他平台沿用各自的关闭路径。[Win32 前台激活规则](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)
