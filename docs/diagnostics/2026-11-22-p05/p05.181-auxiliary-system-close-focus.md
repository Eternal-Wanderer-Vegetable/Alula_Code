# P05.181 / feat-233 · Windows 辅助窗系统关闭后的焦点交接

P05.180 的 Windows 11 125% DPI 轨迹记录到一次 Alt+F4 交接。辅助窗关闭前的原生窗口和编辑器均有焦点，主窗接收了未保存正文和 UTF-16 选区 `[21, 20]`，采样时主窗及编辑器均未获焦。激活标签后可以继续输入。采样期间两窗位置有调整，普通和贴靠摆位的可重复性待本轮受控复验。[P05.180 轨迹](p05.180-auxiliary-close-return/native.json)

辅助窗收到系统关闭事件并获得主窗的接收确认后，在本地释放文档的关闭流程中请求 Windows 交接前台。原生处理在同一次回调中读取当前前台 HWND，只有被关闭的辅助窗仍在前台、主窗可见且未最小化时才请求激活。现有的主窗接收逻辑为返还的文档准备编辑器焦点。原生激活失败仍可完成已确认的文档交接。标签关闭、应用顶栏关闭、拖回关闭与其他平台沿用各自的关闭路径。[Win32 前台激活规则](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)
