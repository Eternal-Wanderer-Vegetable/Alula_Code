# P05.184 / feat-236 · 清除最近使用的命令

固定 Code-OSS 1.145.0 将 `workbench.action.clearCommandHistory` 注册到命令面板。在已启用历史的默认配置下，选择后先确认，再清除最近使用的命令。固定版的面板在执行动作前记录当前选择，所以取消确认会保留此前记录，清除动作本身也会留在最近使用列表。[固定版清除动作](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/quickaccess/browser/commandsQuickAccess.ts#L296-L329) · [面板接受顺序](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/platform/quickinput/browser/commandsQuickAccess.ts#L303-L318)

Alula 由主窗命令面板打开确认框，初始焦点在“取消”。确认后使用原子 journal 连写两份空历史，让主记录与备份都可以从空状态恢复。写入失败时重新读取可恢复的历史，并在工作台显示失败状态。

## 验证

- Windows 11 build 26200，125% DPI，及 Linux WSL Xvfb + xfwm4。F1、Enter 打开确认，Escape 取消后两份 journal 均保留三条记录。再次打开并点击“清除”后，两份 journal 均为空，后续面板没有“最近使用”区块。
- Windows 将隔离夹具主记录置为无效后正常重启。备份恢复后面板仍为空历史，两次进程退出均为 0。Linux 同轮读回主记录与备份为空。组件回归另外覆盖无效主记录下的重启恢复和临时文件写入失败。
- 确认和取消均保留 Rust 全文、Flutter 镜像、UTF-16 编辑选区和脏态。关闭面板后可以直接继续输入，原文件 BOM、CRLF、emoji 与字节保持。[交互轨迹与构建哈希](p05.184-clear-palette-history/native.json)
