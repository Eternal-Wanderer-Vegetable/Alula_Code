# P05.183 / feat-235 · 主窗规范命令面板入口

固定 Code-OSS 1.145.0 注册 `workbench.action.showCommands`，Windows/Linux 主键是 Ctrl+Shift+P，macOS 主键是 Cmd+Shift+P，次键是 F1。P05.182 对照时 Alula 主窗 F1 绑定了诊断面板，打开命令面板使用另一个默认组合键。P05.183 将面板收为一个规范命令，标题菜单、欢迎页等已有入口和存储在历史中的旧命令 ID 通过别名解析到同一命令。用户旧键位里的 `view.commandPalette` 或 `view.quickInput` 可以覆盖或移除同一个规范动作。诊断面板仍可从命令面板选择或在用户键位文件中绑定。[固定版动作和键位](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/quickaccess/browser/commandsQuickAccess.ts#L273-L293)

- Windows、Linux、macOS 组件变体检查 F1、平台主键、单一命令面板项、取消恢复、旧入口执行和从面板选中诊断命令。首次全量有 15 个 macOS 变体以固定 Ctrl+Shift+P 打开旧面板入口，修改 11 个编辑器测试夹具改用通用 F1。最终专项 177/177，Flutter 1,762 passed / 2 skipped。
