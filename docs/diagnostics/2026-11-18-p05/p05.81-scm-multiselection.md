本片只扩展现有平面 `GitChangesList` 资源行。焦点、选择集合和鼠标范围锚点分别维护。

- 普通点击选择并打开一项；Windows/Linux Ctrl 点击、macOS Cmd 点击切换选择，保留其他已选项且不打开资源。
- Shift 点击（包括 Ctrl/Cmd+Shift）用锚点到目标的连续范围，替换锚点所在的已选连续段，保留不相邻的已选段。缺少锚点时由原焦点或目标初始化。
- 裸方向键/Home/End 只移动焦点、更新锚点并揭示。Shift+方向键遵循固定版树算法：先移动焦点，目标已选时移除原焦点项，否则加入目标；边界焦点不动时不改选择，不自动补选原焦点。
- Ctrl/Cmd+A 选择当前平面资源集合，不改变焦点和锚点。它不实现上游层级树反复全选扩大的行为。
- Enter/Space 将选择收回为焦点单项，只打开该项；Enter 交焦点，Space 保留列表焦点。键盘改变选择后只剩一项时，以保留焦点的方式预览。鼠标修饰键选择不打开资源。
- 显式暂存/取消暂存按钮始终作用于该行，不因多选变为批量 Git 动作。非本平台修饰键点击不改变选择或打开资源。
