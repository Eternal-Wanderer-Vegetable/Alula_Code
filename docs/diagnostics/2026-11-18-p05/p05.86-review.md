# P05.86 review and independent reference verification

2026-11-18. Review was read-only; suite results are separately recorded in logs.

The workbench review found one P1 in the initial integration: `doc.uri` comes from the existing `_pathToUri` helper, which emits `file:////tmp/...` for POSIX paths and does not escape literal `%/#` filenames or construct UNC authority. The strict new URI sorter correctly rejects those malformed resources, leaving them unsorted. The real Workbench fixture with `z%done#.rs` failed its sorted-row geometry assertion before correction (`p05.86-native-path-red.log`).

The correction is local to the Open Editors projection: use `Uri.file(doc.path!, windows: Platform.isWindows).toString()` for native files, falling back to `doc.uri` for pathless resources. The shared LSP/document URI producer remains an adjacent recorded issue. POSIX/Windows/UNC policy fixtures and the real Workbench test pass after correction. The same reviewer read the correction and reported no remaining substantive findings in this scope. Menu gesture ownership, session preference, layout-leaf order, per-group copies, stable ties and row id/group action targets were checked. Group relocation order is supported by source review, not a new relocated-group UI fixture.

An independent reference reviewer compiled the actual pinned `src/vs/base/common/uri.ts` and `charCode.ts` in memory and used `resources.ts` comparison-key behavior, without reusing the Dart serializer. All 26 literal golden keys and their 676 ordered pairs agreed with Code-OSS `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`; numeric, case, drive-colon, Unicode, UNC and 21 punctuation expectations also agreed. The checked-in Dart test compares relative order against handwritten golden literals; it does not execute the upstream implementation or expose/assert every private serialized key.

Malformed-input boundaries remain deliberate: upstream accepts missing schemes, `%GG`, `%FF` and raw newlines that this helper rejects. Both reject `file:////invalid`. Host/port validation and ill-formed UTF-16 are outside the helper contract. Alphabetical Intl/locale/numeric name ordering and the name order within the resource-less bucket are deferred, not counted as completed.

The focused suite passes 18/18. It logs a non-failing minimap `UnknownDoc id=1` during existing teardown paths; its cause is not established or claimed fixed by this change. Full-gate, graph and exact hosted results are recorded separately.
