## 范围与固定参考

接续 SCM 导航和多选，仅处理现有平面资源列表的右键/键盘菜单、目标焦点、取消及迟到动作隔离。固定参考：Code-OSS `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 的 `listWidget.ts:750–757,1457–1484`、`scmViewPane.ts:473–484,1850–1907`。

菜单调用保留选择集合和范围锚点，右键更新资源焦点，包括右键未选项。ContextMenu/Shift+F10 在 keyup 打开，按逻辑焦点定位并揭示离屏目标，不使用 hover 选择目标。Escape 不执行动作；用户已主动聚焦外部控件时，取消不夺回焦点。

菜单只接已有“打开差异”和明确标注“此文件”的暂存/取消暂存回调。固定版可按选择集合批量分派，完整贡献菜单与 P09 批量 Git 业务仍开放，此片不宣称全 SCM 菜单等价。键盘无资源焦点时安全无操作；上游完整树的根菜单留到后续。

确认动作前校验 path、staged side、状态和原始路径。目标删除、迁移或改变后旧动作拒绝；删除再加回同路径也不能复活旧动作。等价新对象刷新继续有效。可见菜单锁在 popup 关闭时释放，不被慢 Git I/O 占用；旧动作完成不会清除新菜单状态。移除监听后再等待 Git，避免等待任务积累菜单失效回调。单视口 key 用于定位，不新增常驻行节点映射或轮询。

组件销毁由 mounted 拒绝迟到动作；独立 PopupMenuRoute 可能保留到用户取消，未声称实现源组件销毁时自动关闭。当前源码审查与自动化覆盖边界见 `p05.83-acceptance-map.json`。
