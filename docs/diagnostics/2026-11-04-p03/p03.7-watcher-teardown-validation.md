Date: 2026-11-04. Repository: `Eternal-Wanderer-Vegetable/Alula_Code`; branch target `codex/vscode-parity-p00`; implementation commit `753ad8f057f93629d370e1a5ef0166be79a13b0c`.

## Change

`_stopWorkspaceWatcher()` now invokes the current watcher's `stop()` before appending its await to `_watcherTransition`. This starts native cancellation promptly during workbench disposal even if an earlier transition is queued; the existing serialized transition still awaits that exact Future and keeps workspace generation checks. It does not increase cleanup retries.

Added `WorkspaceWatcher` coverage that awaits `stop()` and then deletes its watched workspace directory. Existing `workbench_multi_view_test.dart` teardown remains the product-level integration check, including same-document multi-view and the 50,000-line edit/save scenario.

An exploratory widget test attempted recursive directory deletion immediately after unmount, without waiting for the asynchronous watcher cancellation Future. It hung on Linux and was removed: calling `stop()` initiates native close, but directory removal must wait for close completion. The retained unit test awaits cancellation; product integration uses the existing 100 ms pump and bounded five-second retry.
