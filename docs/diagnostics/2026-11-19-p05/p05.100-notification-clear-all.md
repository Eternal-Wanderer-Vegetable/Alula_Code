# P05.100 / feat-152 · 通知中心全部清除

固定 Code-OSS 提交 `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 的通知中心将有活动进度的条目排除在 Clear All 之外。仅剩活动进度时按钮禁用，进度完成后重新可用。按钮和命令调用同一清除路径，清除前关闭面板。[notificationsCenter.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCenter.ts#L193) [notificationsCommands.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/notifications/notificationsCommands.ts#L302)

Alula 既有命令 `workbench.action.clearNotifications` 与面板按钮共用清除入口。模型保留活动进度条目及其未读、toast 和 banner 成员资格，成批删除普通及已完成条目。按钮在面板挂载期间监听有界列表中的进度变更，进度结束后可即刻清除。现有默认上限为 100 条，监听资源随按钮卸载清理。
