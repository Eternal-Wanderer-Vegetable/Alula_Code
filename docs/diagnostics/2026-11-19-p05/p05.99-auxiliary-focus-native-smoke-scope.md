## Native smoke finding

- The first Linux native smoke launched the main workbench but the actual auxiliary engine failed with `MissingPluginException` for `window_manager.ensureInitialized`. The script was stopped after this direct failure; it produced no passing native-focus evidence.
- Inspection of `desktop_multi_window` 0.3.1 source and its README shows that Linux, Windows, and macOS require a window-created callback to register generated plugins in every child engine. The Alula runners registered plugins only in the main engine, so the auxiliary app had no `window_manager` implementation and could not publish native focus events.
- GitNexus impact for Linux `my_application_activate`, Windows `FlutterWindow::OnCreate`, and macOS `MainFlutterWindow.awakeFromNib` returned UNKNOWN with no caller edges. Manual source review confirmed each main-engine registrant call and the documented child-window callback as the missing boundary. No HIGH/CRITICAL verdict was returned. The implementation adds the plugin callback on all three platforms; this slice's native focus smoke remains Linux/Windows only.
