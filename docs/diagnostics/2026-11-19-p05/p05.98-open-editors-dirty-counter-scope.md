# P05.98 / feat-150: Open Editors dirty counter shortcut

## Scope

Make the existing Open Editors dirty-count badge an accessible action. When the count is nonzero, pointer/touch activation or Enter/Space opens and focuses the first dirty editor using the workbench's visible editor-group order and each group's editor order. Preserve the existing count and its visibility rules. At zero, keep the badge hidden and expose no action.

The action must use the existing owner group/document objects and the current activation route. It must not perform an edit, save, discard, or close. Reuse `_activateOpenEditorsRow` so any pending input composition is committed exactly as it is for ordinary Open Editors row activation before focus changes; validate document invariants after that existing flush. Keep the section collapse action, sorting selector, and badge count semantics unchanged, and do not alter auxiliary-window focus synchronization.
