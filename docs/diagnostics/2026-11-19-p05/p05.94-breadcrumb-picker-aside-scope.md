# P05.94 / feat-146 — Breadcrumb picker side-open scope

## Scope

Implement the pinned Code-OSS Breadcrumb picker action that opens its currently focused file or document-symbol entry in the adjacent editor group. The default shortcut is Ctrl+Enter on Windows/Linux and Cmd+Enter on macOS. A file picker opened from a directory segment and the document-symbol picker both participate.

Normal Enter keeps its current behavior: files open in the owning group, symbols move the owning document caret, and directory entries reveal the next directory level. The side-open action on a directory entry continues the existing directory reveal behavior. Side-opening a symbol creates/reuses the adjacent editor group, opens a view of the same document there, and moves only that view's caret to the selected symbol's UTF-16 start.

The side group receives focus as part of opening. The source group keeps its caret, selection history, text, document version, dirty state, and disk contents. Picker cancellation, workspace/document replacement, or stale group ownership must not create a side group or change editor state. No Rust crate, FFI ABI, document content, or auxiliary-window focus-sync change is in scope.

## Acceptance

- Keyboard side-open works for a focused file and a focused symbol; platform defaults use Ctrl+Enter on Windows/Linux and Cmd+Enter on macOS.
- Ordinary Enter behavior remains intact, including directory-to-directory reveal and symbol caret navigation.
- The side file is opened in a new adjacent group; a side symbol opens the same document view and selects the symbol start using the existing UTF-16 offset.
- Source group caret/selections/history, authoritative text/version/dirty state, and on-disk bytes remain unchanged; the new side group becomes focused.
- Escape, stale workspace/document state, and route/group disposal do not open a side view.
- Full local DoD, exact-SHA PR CI, and Linux/Windows Platform Availability pass. macOS native device validation remains deferred under the repository's no-device policy.
