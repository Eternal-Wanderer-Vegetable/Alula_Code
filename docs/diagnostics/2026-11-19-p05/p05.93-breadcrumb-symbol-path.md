# P05.93 / feat-145 — Breadcrumb 当前符号祖先路径跟随光标

## 范围与验收

- 文件路径段后显示当前 AlulaDoc 版本的 Rust 符号树中光标所在的根到最深祖先链。
- 复用现有版本化符号快照和有界树；每个编辑组只保存短祖先链。过期/无快照时回退到文件路径，不修改 FFI ABI。
- 光标移动跨符号时更新路径；符号路径点击与键盘 reveal 维持所属组和编辑器焦点语义，原有目录/文件 picker 与长路径滚动继续工作。
- 验收嵌套/并列/空隙/无 provider、版本失效、Emoji UTF-16 起点，以及全文/选区/dirty/undo-redo/磁盘不变。

## 实施与验证

- `documentSymbolPathAtLine` 迭代读取有界符号树，返回与 `documentSymbolAtLine` 相同优先级的根到最深祖先链；只将当前行范围相交的节点压入临时祖先帧，保留深树不递归行为。
- Workbench 复用当前文档/版本的大纲快照，光标同步只做缓存树行查找；每个编辑组只缓存 `{id, name, startUtf16}` 轻量祖先记录，不持有完整符号树。快照过期或不可用时 Breadcrumb 立即隐藏符号段，仅显示文件路径；新版本的同一祖先链到达后，即使标签未变也会合并重绘并恢复。
