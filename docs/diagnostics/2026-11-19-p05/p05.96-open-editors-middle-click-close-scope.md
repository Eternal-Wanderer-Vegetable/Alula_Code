# P05.96 / feat-148 — Open Editors middle-click close

## Scope

Add the Code-OSS Open Editors row middle-click action to Alula's grouped Open Editors tree. A mouse middle click on an editor row closes that document through the row's owning `EditorGroup` and the existing dirty-safe close route. It must not first activate the clicked row or switch the focused editor group. Closing an active row follows the existing owner-group MRU behavior.

Single click and Enter continue to activate the row. Right-click continues to offer Copy Path. Existing editor-tab middle-click behavior is unchanged. No Rust, FFI, document text, auxiliary-window, sort mode, or batch-close behavior changes are in scope.

## Acceptance

- Middle-clicking an Open Editors editor row requests a close for that row's current owner group and document.
- A clean document closes without changing the active/focused document in another group; the owner group keeps its existing MRU behavior if the closed row was active.
- Dirty close uses the existing confirmation route. Cancel preserves the row, text, dirty state, disk contents, and session selection; Save/Discard continue through the existing shared-document safety checks.
- Ordinary click/Enter activation, right-click Copy Path, visible close button, and editor-tab middle-click continue to work.
- Focused Workbench tests and full local DoD pass; exact-SHA PR CI and available Linux/Windows Platform Availability pass. macOS device interaction stays unverified under the no-device policy.
