# P04.79 / EDT-12e: Multi-cursor snippet insertion

## Scope

This slice implements Code-OSS 1.145.0 multi-cursor snippet insertion for ordinary, non-overlapping selections that all fit in one bounded Rust-backed input window. Each selection resolves selected text, line number, current line, and current word from its own insertion position. File, workspace, and clipboard variables use one shared snapshot.

All expansions are checked before mutation. The workbench rejects IME composition, column selection, cross-window selections, invalid or overlapping selections, more than 64 selections, stale document/controller state, expansion timeout, more than 4,096 merged placeholder occurrences, more than 64 transforms on a tabstop, input-window overflow, or undo-payload overflow. The accepted edits are applied as one Rust transaction and one undo frame. One session synchronizes tabstops, mirrors, choices, and transforms across cursors. Multiline transforms retain each insertion's own leading indentation. No Rust crate or FFI ABI changed.

The session combines expansions by assigning every occurrence a distinct identity and preserving its source selection's indentation. When an async clipboard read or expansion yields, the active document, version, input window, selection set, editing value, and controller identity are checked again before continuing.
