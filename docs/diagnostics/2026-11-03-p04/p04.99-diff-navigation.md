## 固定行为与实现范围

固定 Code-OSS commit 4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e 在 [commands.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/browser/widget/diffEditor/commands.ts) 将 editor.action.diffReview.next/prev 映射到 F7 / Shift+F7。 [diffEditorWidget.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/browser/widget/diffEditor/diffEditorWidget.ts) 的 goToDiff 在当前末行之后回到首个 diff、当前首行之前回到末个 diff，并居中揭示目标修改行。

本切片为现有 Git unified diff 视图增加对应的上一处/下一处导航。解析后连续的删除/新增行组成单一目标，no-newline marker 不分割该块；上下文、hunk 和文件 metadata 终止改动块。导航目标必须同时适用于 inline 与 side-by-side 投影，滚动后将目标行居中。工具栏提供可访问按钮、当前序号/总数状态，并支持 F7 / Shift+F7。空差异和完整原文 fallback 不提供活动导航。替换 patch 时清空当前索引。
