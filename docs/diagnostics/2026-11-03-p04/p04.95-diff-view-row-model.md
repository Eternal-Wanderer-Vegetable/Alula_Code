# P04.95 / EDT-17c — bounded diff view row model

Date: 2026-11-03
Status: local implementation/DoD and hosted Linux, Windows, and macOS checks complete; code commit `e2e3aa3` pushed.

## Scope

Compose the existing pure-Dart line-alignment and word-range models into a complete ordered row projection. This slice does not render a diff editor, load files, change Rust/FFI, or implement the full EDT-17 feature.

`computeDiffViewModel` returns unchanged, modified, inserted, and deleted rows with zero-based unified row indices and 1-based source line numbers. Replacement lines are paired by order inside each line hunk; unmatched lines remain one-sided. Modified pairs carry 0-based, end-exclusive UTF-16 word ranges relative to each source line. LF is removed from the row text while a CR immediately before it is retained. BOMs and trailing empty lines remain in their source text.

The row projection validates hunk sequence and equal gaps, then verifies exact-once ordered coverage of both source texts. When line alignment or output bounds prevent a safe projection, it returns no partial rows and retains both complete inputs with a typed fallback reason. When inline word budgets are exhausted, it retains the complete changed row, emits a whole-line range, and records the row-level fallback reason.

Hard limits are 2,000,000 combined UTF-16 input units, 16,384 combined output/source rows, 262,144 aggregate word-input units, and 2,000,000 aggregate reserved word-work steps. The line and word model limits remain enforced as secondary caps.
