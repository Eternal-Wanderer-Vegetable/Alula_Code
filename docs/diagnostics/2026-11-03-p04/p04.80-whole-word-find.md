# P04.80 / EDT-13a: Whole-word find

Date: 2026-11-03. Implementation commit: `75c0690`.

## Scope

The editor find bar now has an independent whole-word toggle. The existing default word-separator characters and whitespace define boundaries; U+FEFF is also treated as a boundary so a UTF-8 BOM does not join the first word to an invisible prefix. The same filtered match list feeds result count, navigation, editor decorations, minimap markers, current replacement, and replace-all. Regex, selection-scope, multiline, and find-history behavior remain later EDT-13 slices.

Case-insensitive literal matching now runs against the original Dart string instead of a lowercased copy. This keeps reported UTF-16 ranges stable when a lowercase mapping expands a character (for example, U+0130).
