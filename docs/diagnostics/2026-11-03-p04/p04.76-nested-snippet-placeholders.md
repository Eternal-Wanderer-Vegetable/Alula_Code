# P04.76 / EDT-12c3: Nested Snippet Placeholders

## Scope and compatibility target

P04.64 introduced the base snippet session and explicitly left nested placeholders unsupported. This slice adds nested placeholders in placeholder defaults, aligned with the pinned Code-OSS 1.145.0 TextMate snippet parser and session behavior. The parser gathers the first non-empty default for an index, fills later mirrors with a clone of that default tree, and visits positive tabstops by ascending index before `$0`.

- [`snippetParser.ts` at `4bda7217`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetParser.ts)
- [`snippetSession.ts` at `4bda7217`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetSession.ts)

No Rust crate or FFI ABI changed. Edits continue through the existing Rust authoritative text, undo, dirty, and save path. This slice does not add snippet transforms or user snippet configuration.

## Acceptance criteria

- Recursively parse `${1:outer ${2:inner}}` defaults while preserving escaped literal braces and UTF-16 offsets.
- Replicate nested placeholder trees into linked outer mirrors and keep repeated nested tabstop occurrences linked.
- Track enclosing parent ranges as a child changes and child ranges when a parent changes, including empty children at edit boundaries.
- Preserve ascending tabstop order and the final `$0` stop.
- Bound nested parsing and rendered range growth; fail closed on depth, placeholder, or expansion limits.
- Workbench fixtures cover nested mirrors, parent/child navigation, emoji coordinates, CRLF save/readback, and Windows/Linux/macOS TargetPlatform runs.
- Full repository DoD and hosted PR CI pass. Hosted platform builds are not native macOS DnD/IME or P15 device evidence.

## Implementation

- `snippet_template.dart` now parses default text into nested segments, assigns each rendered occurrence a stable identity for that expansion, and records the ancestry chain on each placeholder range. Nested defaults are rendered into each mirror occurrence so the child tabstop remains linked. The maximum nesting depth is 32; the parser tree and output ranges remain bounded by the configured limits.
- `snippet_session.dart` carries occurrence ancestry when ranges move. Child edits expand enclosing parents; parent edits transform nested descendant ranges with explicit boundary affinity, keeping an empty child at a deterministic caret after its parent is replaced.
- Placeholder counting is performed on the final parse tree, not while tentatively scanning an incomplete outer placeholder. This avoids counting a nested placeholder twice when malformed outer text is retried as literal text.
- Parser/session/workbench tests cover nested default replication, multiple child mirrors, UTF-16 emoji coordinates, parent and child range tracking, tabstop navigation, edit limits, incomplete outer syntax, and save/readback with CRLF on disk.
- Flutter tooling added `macos/**` and `linux/**` to `app/analysis_options.yaml` while `init.sh` ran its analyzer migration. This generated configuration change is included so future analysis runs keep using the migrated platform-directory exclusions.
