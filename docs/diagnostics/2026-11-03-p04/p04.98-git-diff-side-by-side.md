# P04.98 / EDT-17f：Git unified diff 并排视图

日期：2026-11-03
状态：本地 DoD、Linux/Windows hosted 验收与 macOS ARM64 构建/启动通过；macOS 原生 DnD 因 hosted pointer route unavailable 跳过。

## 实现范围

- Git Diff 视图增加 inline / side-by-side 模式切换。并排投影复用已有 unified-patch 行与词级变化范围，源行对象保持引用；不重新解析成无来源的文本副本。
- 上下文、文件/hunk 元数据和 no-newline marker 跨双栏对齐；连续删除/新增按序配对，余行只在对应一侧显示。左右行号独立，rich text 仍可选择并保留词级高亮。单一有界行列表保证垂直行同步。
- 窄于 640 logical px 时停用并排切换并保留 inline 视图。畸形/超限输入继续走完整 raw-patch fallback，不产生半截投影。
- 复用 2,000,000 UTF-16 input / 16,384 patch rows 上限，投影 O(n)，不引入常驻无界缓存。无 Rust、FFI/ABI 改动，数值化内存优化仍按用户要求延后。
- EDT-17 后续仍包括 moved blocks、忽略空白选项、未变区域折叠、差异导航与更完整的 diff-editor 集成。
