日期：2026-11-03

## 实现范围

- 新增纯 Dart unified-patch word-range projection，在每个 hunk 的连续删除/新增块里按两侧行序配对；context、hunk、metadata 会切断配对，无末尾换行 marker 不会切断块。多余删除/新增行保持单侧。
- 调用既有 UTF-16 computeWordDiff；将旧行和新行的范围映射回对应 patch row，并以可选择的 rich text 分别着色。Git Diff patch 解析失败或超过已有 parser 限制时，仍呈现完整原始 patch。
- 预算：最多 8,192 对、聚合输入 262,144 UTF-16 code units、聚合 word work reservation 2,000,000；每对串行 trace 上限 1,000,000 cells。预算耗尽、word model fallback 或 pair cap 会把整对退回整行范围并在纯数据结果保留 fallback reason。没有 Rust、FFI/ABI 或数字化内存改动。
