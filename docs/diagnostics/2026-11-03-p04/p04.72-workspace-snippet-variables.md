# P04.72 / EDT-12b8：工作区片段变量

## 范围与固定上游行为

本 slice 支持 `$WORKSPACE_NAME` 与 `$WORKSPACE_FOLDER`。参考固定 Code-OSS 1.145.0，commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 的 [`WorkspaceBasedVariableResolver`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetVariables.ts)：单文件夹工作区的名称是根目录 basename，路径是根目录绝对 `fsPath` 并规范化 Windows 盘符；没有工作区时变量未设置，默认值或空字符串生效。

Alula 当前只有一个打开的文件夹，因此直接按单文件夹语义解析。工作区路径不使用文档路径变量的 home 缩写。没有打开文件夹时显式传入空变量；模板未使用这两个变量时不计算。

## 实现

- `snippetWorkspaceVariables` 统一规范化 POSIX、Windows drive 与 UNC 工作区路径，返回 basename 和绝对路径；Windows drive 字母小写。
- `_insertSnippetTemplate` 只在模板有可解析引用时构造工作区变量，并复用既有 Rust 输入、undo、dirty 与保存路径。
- 没有 Rust 或 FFI ABI 变更。
