## Behavior

Code-OSS resolves `TM_CURRENT_LINE` from the active selection position's model line. Alula now reads that logical line through the Rust-authoritative `lineBoundary` and bounded `readRange`, excludes its LF/CRLF terminator, and inserts the content literally without reparsing it as snippet syntax.

The workbench checks whether the template actually has a recognized `$TM_CURRENT_LINE`, `${TM_CURRENT_LINE}`, or `${TM_CURRENT_LINE:default}` reference before reading the line. Escaped references, suffix lookalikes, and text inside another variable's default do not trigger the read. This preserves ordinary snippet behavior on long lines and avoids extra bridge work for templates that do not use this variable.

If the line is longer than the 16,384 UTF-16 input-window limit, the Rust version changes, or the returned range is incomplete, the operation aborts before editing. There is no partial expansion. The rule is local to `$TM_CURRENT_LINE`; it does not cap unrelated snippets.

No Rust, FFI, or ABI source was changed. Existing Rust line/read APIs and the current save/undo route are reused.
