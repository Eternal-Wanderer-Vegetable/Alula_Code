## 范围

片段展开现支持 `$TM_FILENAME` 与 `$TM_FILENAME_BASE`。工作台在 flush 当前输入后，从活动命名文档的现有 `OpenDoc.name` 读取 basename，并传入通用变量 map；未命名文档（`uri == null`）把两个变量明确解析为空字符串。base 只去掉最后一个扩展名，多段扩展名保留前面的部分，点开头的隐藏文件不把首个点当作扩展名。变量值作为纯文本展开，不创建额外 tabstop；替换继续复用 Rust authoritative input、undo 与保存回读路径，没有 Rust/ABI 变化。

固定参考是 Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。其 [`ModelBasedVariableResolver`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetVariables.ts) 对 `TM_FILENAME_BASE` 取 basename 最后的点之前内容，且在点索引小于等于零时保留原名。Alula 当前 untitled 文档没有 URI，故这一个子项按空字符串定义；没有改变文档命名模型。
