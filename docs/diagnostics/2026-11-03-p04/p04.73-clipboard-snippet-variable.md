# P04.73 / EDT-12b9：剪贴板片段变量

## 范围与固定上游行为

本 slice 增加 TextMate `$CLIPBOARD`、`${CLIPBOARD}` 与 `${CLIPBOARD:default}`。参考固定 Code-OSS 1.145.0，commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 的 [`ClipboardBasedVariableResolver`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetVariables.ts)：读取纯文本剪贴板；空值视为未解析，使变量 default 生效，否则无 default 时展开为空；非空文本逐字插入。

Alula 的剪贴板 API 是异步的，因此只在模板确实引用该变量时读取一次。等待后必须确认活动文档、Rust 文档版本、输入窗、选区、输入值和字段实例仍与读取前一致；变化、读取异常或超时会取消本次插入，避免把旧状态的变量应用到新编辑状态。剪贴板文本上限为 256 Ki UTF-16 单元，超限不插入。文本按纯文本展开，不创建额外 tabstop；无 Rust 或 FFI ABI 变更。

## 实现

- `snippetClipboardVariables` 保留非空 clipboard 文本；空 clipboard 留待 `${CLIPBOARD:default}` fallback。
- parser 对已知 `CLIPBOARD` 的空值采用变量 default 或空字符串；其他未知变量仍保留原式。
- `_insertSnippetTemplate` 在异步读取后重新校验文档和输入快照，再将纯文本变量交给既有 expansion、Rust 输入、撤销与保存路径。
- 本机未启动 GUI 或 Narrator。
