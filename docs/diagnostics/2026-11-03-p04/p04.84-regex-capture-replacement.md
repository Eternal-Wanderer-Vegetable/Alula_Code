## Scope and reference behavior

This slice implements regex replacement syntax and capture-group expansion in
the Find/Replace workbench, following the pinned Code-OSS 1.145.0 source:

- [`replacePattern.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/find/browser/replacePattern.ts)
- [`findModel.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/find/browser/findModel.ts)

Replacement strings support `$&`, `$0`, `$1`–`$99`, `$$`, `\n`, `\t`, `\\`,
and the capture case operators `\u`, `\U`, `\l`, and `\L`. Current-match
replacement follows VS Code navigation semantics; Replace All uses the same
bounded worker. Worker results are checked against the current query, document,
version, generation, and replacement input before an edit is applied. The
existing 750 ms isolate timeout, cancellation, 19,999-match cap, bounded output,
selection scope, zero-width advancement, stale-result rejection, and one Rust
undo transaction are preserved. Invalid, canceled, timed-out, or truncated
results do not partially write text. Preserve-case remains a later EDT-14
slice.
