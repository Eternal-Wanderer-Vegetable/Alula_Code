## 范围与参考

为片段模板补齐 `$TM_DIRECTORY`、`$TM_DIRECTORY_BASE`、`$TM_FILEPATH`。固定参考为 Code-OSS 1.145.0，commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 的 [`snippetVariables.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetVariables.ts) 与 [`labels.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/base/common/labels.ts)。路径值采用主机路径风格并规范化；非 Windows 用户 home 下路径缩写为 `~`；Windows 盘符小写；没有父目录名称的根目录 basename 为空。Alula 的 untitled 文档没有 URI，因此三个变量都解析为空字符串。

纯 Dart helper 用 `package:path` 的显式 POSIX/Windows context 处理目录、basename、驱动器与 UNC；工作台在 flush 当前输入后，以当前命名文档的 `OpenDoc.path` 生成变量，并把它们和已有变量一并传给 snippet parser。值按纯文本展开，编辑仍走现有 Rust 权威输入、undo、dirty 与保存链路；未修改 Rust 或 FFI ABI。`RELATIVE_FILEPATH` 需要 workspace root，上下文尚未接入，留待后续切片。
