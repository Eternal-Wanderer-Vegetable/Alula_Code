# P04.78 / EDT-12d2: Snippet Placeholder Transforms

## Scope and compatibility target

This slice implements Code-OSS 1.145.0 TextMate transforms attached to snippet tabstops, using the fixed source snapshot at commit [`4bda7217`](https://github.com/microsoft/vscode/tree/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e). A transform is evaluated when leaving its current tabstop, before Tab or Shift+Tab moves the selection. Each transformed occurrence uses its own current placeholder value. No Rust crate or FFI ABI changed.

- [`snippetParser.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetParser.ts)
- [`snippetSession.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetSession.ts)
- [`snippet.md`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippet.md)

## Implementation

- The parser records `${n/regex/format/options}` on placeholder occurrences and defers evaluation until navigation leaves that tabstop. Tab, Shift+Tab, and accepting a choice all use the same navigation path.
- Every occurrence is transformed from its own current text, so mirrors may diverge as Code-OSS permits. A failed regex leaves the original text alone unless the format contains a nonempty else/default branch. The format supports the existing bounded transform worker and capture/conditional/default/case-format behavior.
- The workbench reads Rust-authoritative ranges in bounded chunks, checks the document version, input window, active document, selection, editing value, controller, and snippet session again after the async worker completes, then applies all replacements in one Rust transaction. Stale results are discarded. Updates are undoable and refresh sibling views/find results.
- Multiline replacement text is normalized to the document's internal LF representation and continuation lines receive the indentation captured at snippet insertion. The existing save path restores CRLF where applicable.
- Transform count, aggregate input/output, and worker-time limits remain bounded. Overlapping ranges, invalid offsets, size violations, and transform errors fail before navigation writes a stale snapshot. The Rust transaction remains the source of truth.
