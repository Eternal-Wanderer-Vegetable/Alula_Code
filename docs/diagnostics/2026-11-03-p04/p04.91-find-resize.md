# P04.91 / EDT-15f：Find/Replace 查找栏水平调整

> Status: local DoD, PR CI, and Linux/Windows/macOS hosted build/package validation passed. PR #2 remains OPEN/draft.

## Contract and pinned source

Match Code-OSS 1.145.0 Find widget sizing: start at 419 logical pixels; drag the left vertical sash left to expand, never below 419 while the editor can fit that width; cap at the editor's usable width and keep clear of the minimap; double-click between the default and maximum widths. Closing and reopening Find/Replace retains the selected width. Find and Replace input widths stay synchronized. In a narrower editor the bar shrinks to the available width and its actions reflow instead of overflowing.

Pinned source: [`findWidget.ts` at `4bda7217`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/find/browser/findWidget.ts) (`FIND_WIDGET_INITIAL_WIDTH`, `IVerticalSashLayoutProvider`, drag and double-click handlers).

## Implementation and local evidence

- The Find/Replace bar stores its width in the workbench state, starts at 419 logical pixels, and uses an opaque 10-pixel left sash hit target with a visible vertical grip. Dragging left expands; rightward movement clamps at 419. Double-click toggles the default and maximum widths.
- The maximum excludes the editor's 82-pixel minimap and its 6-pixel gap when the existing editor layout shows the minimap. The bar right edge stops 12 pixels before that region. At narrower widths, the saved width is temporarily capped by current space and returns when the editor grows.
- In the narrow toolbar layout, search controls wrap below the query field; Replace controls wrap below a same-width input. This prevents horizontal RenderFlex overflow and preserves access to actions.
- Dedicated fixture `app/test/workbench_find_resize_test.dart` checks 419 default/minimum, left-drag expansion, editor maximum, minimap clearance, double-click maximum/reset, same Find/Replace field widths, narrow-window reflow, width/query persistence after close/reopen, and unchanged selection, document text/version/dirty state, and disk bytes.
