# P04.87：Find 输入框 Shift+Enter 导航上一个命中

日期：2026-11-03。仓库：`Eternal-Wanderer-Vegetable/Alula_Code`。分支：`codex/vscode-parity-p00`。代码 commit：`7523df2`。

## 行为

- Find 输入框聚焦时，裸 `Shift+Enter` / `Shift+NumpadEnter` 导航到上一个命中；不带修饰键的 Enter 仍由现有提交路径导航到下一个命中。
- Replace 输入框的 `Shift+Enter` 不触发 Find 导航。Ctrl、Alt、Meta 组合不进入上一个命中路径。
- 导航沿文档 UTF-16 绝对偏移循环，更新当前选区；不编辑文本、不改文档版本、dirty/savepoint 或文本 undo。

固定参考：Code-OSS 1.145.0 [`findController.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/find/browser/findController.ts) 中 Find 输入框聚焦时的 `PreviousMatchFindAction`（Shift+Enter）与 `NextMatchFindAction`（Enter）。
