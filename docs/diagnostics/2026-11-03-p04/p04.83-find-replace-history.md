# P04.83 / EDT-13d: Find and Replace history

Date: 2026-11-03. Repository: `Eternal-Wanderer-Vegetable/Alula_Code`.
Implementation is local; hosted validation is pending.

## Scope and behavior

This slice implements the Find/Replace history requirement deferred by P04.81
and listed under EDT-13 in `docs/11-VSCode功能对照矩阵.md`. It follows the
pinned Code-OSS 1.145.0 behavior: `editor.find.history` and
`editor.find.replaceHistory` accept `workspace` or `never` and default to
`workspace`; each input has a 100-entry MRU history, duplicate values move to
the newest position, and Up/Down navigation restores the draft typed before
browsing.

The workbench records nonempty queries after a 500 ms debounce. Workspace
histories are isolated by normalized workspace identity and written through
the existing recoverable `SessionStore` journal. The journal caps each query
at 524,288 UTF-16 code units, each input at 100 entries, each history file at
2 MiB, and retained workspace files at 16. Corrupt or oversized records fall
back to empty history. A `never` setting keeps that input's history in memory
only and does not load or write it. No Rust or FFI change was needed.
