# P04.86：Find 栏 Alt+Enter 选择全部命中

日期：2026-11-03。仓库：`Eternal-Wanderer-Vegetable/Alula_Code`。分支：`codex/vscode-parity-p00`。代码 commit：`f24e605`。

## 行为

- Find 与 Replace 输入框在 Find widget 可见时响应 Alt+Enter 和 Alt+NumpadEnter；Ctrl/Meta/Shift 组合不触发该命令。
- 使用当前 literal/regex query、大小写、全字和 Find-in-Selection 选项。正则结果到达后再次核对 generation、文档 id/version、query、选项、selection scope 和活动文档；非法、超时、取消和过期结果不改选择。
- 最多选择 `editor.multiCursorLimit` 的 10,000 个命中。当前选区恰好是命中时保留其方向并作为 primary，否则以首个文档命中为 primary。所有范围保持文档 UTF-16 绝对偏移。
- 通过现有 `_setDocSelections` 一次记录此前 selection set；不应用文本编辑，不改变 dirty、savepoint 或文本 undo。
- 超过多光标上限时保留前 10,000 个命中并在状态栏显示截断信息。

固定参考：Code-OSS 1.145.0 的 [`findController.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/find/browser/findController.ts) 与 [`findModel.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/find/browser/findModel.ts)。
