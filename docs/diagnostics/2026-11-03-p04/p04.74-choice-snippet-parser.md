# P04.74 / EDT-12c1: Choice Placeholder Parser and Session Metadata

## Scope

This slice implements the bounded parser and session data needed for TextMate choice placeholders. It does not implement the suggestion list or choice acceptance UI; that remains a separate open EDT-12 slice. No Rust code or FFI ABI changed. No desktop GUI or Narrator was started.

The compatibility target is the pinned Code-OSS source at commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`:

- [`snippetParser.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetParser.ts): choice parsing, first-option string value, and escaped comma/pipe/backslash behavior.
- [`snippetSession.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetSession.ts): choice belongs to the first active placeholder occurrence in the tabstop group.

## Implementation

- Parse `${n|option1,option2|}` for positive tabstop indices. The first option is inserted as the initial value; all linked mirrors share it.
- Decode `\,`, `\|`, and `\\` inside options. Empty options, trailing separators, incomplete expressions, and index zero remain literal text, matching the pinned parser's rollback behavior.
- Attach immutable choice options to the exact placeholder range. `SnippetSession.activeChoiceRange` exposes the active first occurrence only, and range rebasing preserves its metadata after Rust-confirmed mirror edits.
- Keep UTF-16 coordinates and existing template/expansion/tabstop/occurrence bounds. A project safety cap limits each choice to 256 options.
