# P04.85 / EDT-14b：替换保留大小写

## 范围与实现

按固定 Code-OSS 1.145.0 实现 Find/Replace 的 Preserve Case：默认关闭的替换栏开关具有可访问选中态；普通文本、正则当前替换和全部替换共用静态替换大小写规则，覆盖全大写、全小写、首字符大小写及同形 kebab/snake 分段。空匹配返回原替换文本；捕获组及 `\u` / `\U` / `\l` / `\L` 等动态替换模板不再套一层 Preserve Case。Unicode 映射采用 Unicode 16 默认全量映射，并覆盖多码点大写、土耳其点号 I 和上下文词尾 sigma。

替换仍使用现有有界正则 worker、取消和 stale-result 防护、selection scope、命中/输出上限与单次 Rust undo transaction；UTF-16、CRLF、emoji、零宽匹配和保存读回路径保持验证。

参考实现：[Code-OSS `replacePattern.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/find/browser/replacePattern.ts)、[`findModel.ts`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/find/browser/findModel.ts)；Unicode 映射来源：[Unicode 16 `SpecialCasing.txt`](https://www.unicode.org/Public/16.0.0/ucd/SpecialCasing.txt)。
