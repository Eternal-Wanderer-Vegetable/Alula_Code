## Scope

Implements editor regex Find against pinned Code-OSS 1.145.0 (`4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`). This is the regex search/navigation slice of EDT-13. Regex Replace and capture expansion remain EDT-14; selection-scoped search and search history remain later EDT-13 work.

## Behavior

- Adds the `.*` Find toggle and composes it independently with case-sensitive and whole-word modes.
- Runs each regex request in a short-lived isolate. A 750 ms timeout terminates it; a newer query, document change, closing Find, or disposing the workbench cancels the previous worker immediately.
- Limits expressions to 1,000 UTF-16 units and displayed results to 19,999. Invalid expressions, timeout, and truncated result sets are visible in the Find bar.
- Searches ordinary expressions line by line so `^`/`$` use editor line boundaries. Expressions containing explicit line separators (`\n`, `\r`, or actual line breaks) and `\W` use whole-document matching after CRLF normalization. A monotonic mapper converts matches to original UTF-16 offsets without allocating a per-code-unit offset table.
- Uses the same ordered match list for count, navigation, editor decorations, and minimap markers. Zero-width matches advance through the list when cycling. Regex replacement controls are disabled until EDT-14 implements capture/replacement semantics.
- Checks request generation, document id/version, query, and active options before applying asynchronous results. No Rust/ABI change.
