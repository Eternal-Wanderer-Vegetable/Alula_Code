# P04.89 / EDT-15d：Find 从光标处单词初始化 query

日期：2026-11-03。固定上游：Code-OSS 1.145.0，commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。

## 行为与实现

- `editor.find` / Ctrl+F 从关闭状态打开 Find 且主选区为空时，从光标处的默认 Code-OSS word definition 初始化 query；非空选区仍由 P04.88 规则处理。光标位于单词内或恰好落在其边界时可取得该词；正则模式将其作为字面文本搜索。
- 查找词沿用 Code-OSS 1.145.0 `DEFAULT_WORD_REGEXP` 和 `getWordAtText` 的默认行为，最多读取 1,000 UTF-16 code units 的光标上下文。文本来自版本校验后的 Rust 权威范围读取，窗口边界会避开代理对中间位置。无单词、过期输入/文档、IME 组合输入或读取失败时保留旧 query。
- 查找只更改 Find query 和已有结果状态，不更改光标、Rust 文本/版本、dirty/savepoint、磁盘字节或文本 undo。
