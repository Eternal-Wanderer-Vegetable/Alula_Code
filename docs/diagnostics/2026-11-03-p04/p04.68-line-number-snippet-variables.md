## 范围与参考

为 snippet 模板加入 `$TM_LINE_INDEX` 和 `$TM_LINE_NUMBER`。固定参考为 Code-OSS 1.145.0 commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e` 的 [`SelectionBasedVariableResolver`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/contrib/snippet/browser/snippetVariables.ts)：`TM_LINE_INDEX` 为从 0 开始的行索引，`TM_LINE_NUMBER` 为从 1 开始的行号；二者都根据选区活动端点计算。

工作台在 flush 并验证活动选区之后，把 `selection.extentOffset`（绝对 UTF-16 单元偏移）交给既有 `AlulaDoc.positionAt`，读取 Rust 权威 `DocumentPosition.line`，再经 `snippetLineVariables` 形成两个十进制字符串。变量按纯文本展开并复用既有 Rust 输入、撤销、dirty 和保存路径；没有修改 parser 的展开算法、Rust crate 或 FFI ABI。负行号 helper 输入显式拒绝。
