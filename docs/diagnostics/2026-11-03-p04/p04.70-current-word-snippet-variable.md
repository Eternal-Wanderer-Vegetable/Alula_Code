## 行为对照

- 变量从活动选区的 position（extent）取行、列，再调用 `getWordAtPosition`；没有 word 时返回 `undefined`。
- `getWordAtPosition` 使用当前位置语言的 `wordDefinition`，无语言配置时采用 Code-OSS 默认正则。Alula 当前没有每语言 `wordPattern` 设置，因此此切片实现该默认定义；将来接入语言配置时需让解析器使用对应 pattern。
- 超长行查找只保留光标附近最多 1000 个 UTF-16 单元，未命中的变量继续由现有 snippet parser 保留原表达式。

## 实现与覆盖

工作台只在模板含可解析的 `$TM_CURRENT_WORD` 引用时查询。它 flush 输入后用 Rust `lineBoundary`、`positionAt` 和 `readRange` 取得光标上下文；position、范围与输入窗版本必须一致。读取最多 1000 个 UTF-16 单元，若范围起点落在代理对内则移到合法边界。CRLF 行终止符不参与 word lookup。解析结果作为纯文本交给既有 Rust 输入、撤销与保存路径，没有 Rust 或 FFI ABI 改动。
