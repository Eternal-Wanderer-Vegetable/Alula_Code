## Scope and implementation

- Added `parseGitDiffPatch`, a bounded scanner for Git unified text patches. It emits metadata, hunk headers, context/add/remove rows, old/new 1-based line numbers, and no-newline markers. It checks every hunk's declared old/new counts and rejects malformed or truncated patches as a whole.
- Hard limits are 2,000,000 UTF-16 code units and 16,384 display rows. Over-limit, binary/metadata-only, and unsupported input returns no partial rows; the view displays the complete original patch instead.
- Added a lazy `ListView.builder` renderer with separate old/new gutters, colored hunk/add/remove rows, horizontally scrollable selectable source lines, and cached parsing until the patch changes. The existing SCM Git Diff panel now uses it.
- This slice does not implement whole-document compare inputs, side-by-side layout, word highlights, moved blocks, unchanged folding, diff navigation, Rust/ABI, or numeric memory targets.
