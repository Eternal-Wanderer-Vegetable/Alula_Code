# P04.88 / EDT-15c：Find 从单行选区初始化 query

日期：2026-11-03。固定上游：Code-OSS 1.145.0，commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。

## 行为与实现

- `editor.find` / Ctrl+F 在 Find 栏从关闭状态打开时，读取主选区并初始化 query；Find 已打开时的关闭操作不重置 query。空选区、多行选区、长度达到 524,288 UTF-16 code units、输入窗或文档版本过期、存在未提交输入/IME 组合、Rust 范围读取失败时，保留原 query。
- 用 Rust `lineBoundary` 验证选区两端属于同一行，再通过已有版本校验的 `_readDocumentRange` 读取权威文本。种子长度按 Code-OSS 的严格 `< 524288` 限制；超长输入在读取前拒绝。正则模式对选区使用 `RegExp.escape`，使它仍按字面文本搜索。
- query 填入后经现有 Find 结果路径刷新命中和历史；不改变编辑器选区、Rust 文档内容/版本、dirty/savepoint、磁盘字节或文本 undo。Ctrl+H Replace 启动与光标处单词种子不在此切片，后者登记为 P04.89。
