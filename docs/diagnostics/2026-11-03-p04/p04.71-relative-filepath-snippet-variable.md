Alula 当前提供单个打开文件夹根目录。根目录内的命名文档解析成不带根名的相对路径，使用宿主路径分隔符；文档路径与根目录相同则为空。untitled 文档解析为空；没有根目录或文档不在该根内时回退到规范化的绝对路径标签。变量仅在模板确实引用时计算。

## 实现与覆盖

新增 `snippetRelativeFilePathVariables`，基于 `package:path` 的 POSIX/Windows path context 规范化路径。Windows 根目录匹配不区分大小写；相对结果保留宿主分隔符；不在 workspace 内时复用已有绝对路径标签与 POSIX home 缩写逻辑。工作台将活动文档路径与 `_workspaceRoot` 传给 resolver，再交给原有 snippet parser 和 Rust 输入/撤销/保存路径。无 Rust 或 FFI ABI 改动。

定向 parser/workbench 46 项通过，覆盖 POSIX 子目录、根目录相等、untitled、workspace 外 home 路径 fallback、Windows 分隔符与大小写不敏感匹配，以及工作台插入和磁盘保存回读。完整 `bash init.sh` EXIT=0（Rust workspace、Clippy、build_core、Flutter 669）；`cargo fmt --all -- --check` 通过，`flutter analyze --no-pub` 0 issues。CI 自动扩充的 `app/analysis_options.yaml` 已恢复，本次没有纳入提交。本机 GUI/Narrator 未启动。
