# P04.94 / EDT-17b: bounded character and word diff ranges

> Status: complete for the pure range model. It is not connected to line hunks or a visible diff editor.

## Scope

P04.93 aligns changed lines. This slice adds a bounded character-level range model and the fixed Code-OSS small-change word expansion heuristic. It does not alter the workbench, Git panel, SCM flow, or editor document state.

The pinned source is Code-OSS `4bda7217`: [`LinesSliceCharSequence`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/diff/defaultLinesDiffComputer/linesSliceCharSequence.ts) defines ASCII letters/digits as word characters, and [`extendDiffsToEntireWordIfAppropriate`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/editor/common/diff/defaultLinesDiffComputer/heuristicSequenceOptimizations.ts) expands a paired word when `3 * equalCharacters < originalWordLength + modifiedWordLength`.

## Implementation

- Added `computeWordDiff` with a Myers shortest-edit-path over UTF-16 code units. It returns paired zero-based, end-exclusive text ranges.
- Word expansion uses the pinned ASCII `[A-Za-z0-9]` boundary rule and strict two-thirds similarity threshold. Punctuation, whitespace, and non-ASCII letters are not treated as word characters by this default model.
- Changed ranges expand outward at surrogate-pair boundaries. A final invariant pass verifies that every gap outside the hunks is exactly equal on both sides; mismatching gaps are merged into a changed range, and any remaining inconsistency falls back to a whole-text hunk with `alignmentInvariant` reason.
- Bounds: 262,144 combined UTF-16 code units, 1,000,000 copied Myers frontier cells, and 2,000,000 search/expansion operations. Input/work exhaustion returns one full-text hunk with an explicit reason.
- Added nine focused tests and 200 seeded random text pairs. Coverage includes unchanged text, word expansion threshold, local character edits, punctuation boundaries, repeated characters, BOM, Emoji, CRLF, limits, monotonic ranges, equal gaps, and surrogate safety.
