## 范围

- Explorer、Search、Outline、Source Control 四个既有 ID 均默认 pinned。
- 视图 item context menu 的 Keep/Hide action 和 bar context menu 的 view checklist 共用 pin 状态。右键 menu checked 状态、可用性、动作回调与当前 Activity Bar view 顺序一致。
- Hide 只解除 pin，不销毁 view/action；当前 active 但 unpinned 的 view 保持显示，直到用户切换到另一个已 pin 或 active view。被取消固定的非活动 view 从 bar 与键盘遍历中移除，仍可从 context menu Keep 恢复。
- 最后一个 pinned view 不可 Hide。Manage 保持当前固定禁用占位，不进入 pin 集合。
- 在现有 WbSplit 根 metadata 增加 activityBarPinned ID 列表并写入既有 layout JSON。旧 JSON 缺字段时迁移为四项全 pin；读取时过滤未知/重复 ID，并按 activityBarOrder 顺序规范化。Side/Top/Bottom/Hidden 与 Default/Compact 切换不清除 pin 状态；save/remount 后还原 checked menu state 与可见视图。
- 保留当前活动 view ID、可见 Sidebar、视图点击路由与键盘焦点语义。Pin/unpin 不改 SideBar/Panel/Editor split tree 或尺寸权重。
