# P05.8 / LAY-02b：标题栏 Command Center 入口

日期：2026-11-06。分支 `codex/vscode-parity-p05`，draft PR #3。固定参考 Code-OSS 1.145.0-dev，commit `4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`。

## 范围

在 Flutter 自绘标题栏中提供一个 Command Center 入口，显示本窗口当前标题并支持鼠标点击、Tab 焦点、Enter/Space 激活。激活时调用现有 `view.commandPalette` 命令，复用当前 `QuickInput` 和 command registry；执行命令后继续回到工作台。入口只在 custom chrome 显示，不绘制到 macOS 原生标题栏上。Command Center 只是入口，custom title 模板/配置/Profile、完整 Quick Access 模式、Quick Open 统一搜索、布局控制按钮和 LAY-02 整体关闭均不在此项内。

Code-OSS 功能对照行：`docs/11-VSCode功能对照矩阵.md` 的 LAY-02 要求命令中心和布局按钮状态/键盘路径一致。本切片只交付第一条可验证路径；完整矩阵仍开放。
