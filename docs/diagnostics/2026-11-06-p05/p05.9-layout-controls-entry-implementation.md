## 实现

- 产品提交：`04b11b79a2d6ff796685b7cfeca1ed13112cf283`（`feat(p05): add titlebar layout controls`）。
- `app/lib/workbench/title_bar.dart`：custom chrome 增加“布局控制”按钮与菜单，只放置已有命令；Tooltip、Semantics、勾选状态、菜单可见/启用状态、Tab/Enter/Space、方向键、Escape 及触发按钮焦点返回均有覆盖。native chrome 与 macOS 原生菜单栏不重复显示。

- 测试：`app/test/title_bar_test.dart` 覆盖标题栏入口及键盘/焦点行为；`app/test/widget_test.dart` 覆盖两项布局切换、重开菜单后的状态刷新，以及 View > Appearance / Ctrl+B 现有路径。
- Configure Layout、布局类型设置、其他未实现模式与 Activity Bar 不属于本切片。完整范围和差异见 [P05.9 scope](p05.9-layout-controls-entry-scope.md)。
