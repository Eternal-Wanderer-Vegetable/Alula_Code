# P05.12 / feat-064 — Activity Bar Top/Bottom 位置

## 状态

`done`。这是 LAY-03 的单项子任务，扩展 P05.11 已交付的 Side/Hidden 位置为 Side/Top/Bottom/Hidden 四态；仅关闭本子项，不关闭 LAY-03 或 P05。

## 固定对照

- 固定 VS Code / Code-OSS `1.145.0`，提交 [`4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e`](https://github.com/microsoft/vscode/tree/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e)。`ActivitybarPart` 注册 `workbench.action.activityBarLocation.top` / `.bottom`，分别把位置值设为 Top / Bottom；Activity Bar Position 菜单顺序为 Side、Top、Bottom、Hidden，当前项 toggled/checked。[`SidebarPart`](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/sidebar/sidebarPart.ts) 在 Top/Bottom 下改用其水平 Composite Bar 并置于 primary sidebar 的顶部/底部；`layout.ts` 对切换到 Top/Bottom 的配置变化会确保 Custom Title Bar 不被 `never` 隐藏。
- 本切片只实现 Activity Bar 的 Side/Top/Bottom/Hidden 布局位置、布局树 JSON 往返、ActivityBar 横/纵向呈现与对应键盘方向、View > Appearance 命令菜单。位置选择不是把图标条铺满整个 Workbench：Top/Bottom 条带随 primary sidebar 一起排在其上方/下方。

## 代码现状与边界

- 当前 `defaultLayout()` 是纵向根分割：主横向行含固定 44px `activity`、可折叠 `sidebar` 与 `editor`，其下是 `panel`。`ActivityBar` 当前是纵向 `Column`；生产装配、菜单和自动保存都在超过 512 KiB 的 `app/lib/workbench/workbench_page.dart` 中。
- 新位置需把唯一的固定 `activity` 叶子移到 primary sidebar 的纵向子分割顶端或底端；Side 保持现有左侧固定 44px 叶子。Top/Bottom 将 44px 固定主轴尺寸解释为高度，ActivityBar 内容改为横向排列。编辑器组与 Panel 的次序、大小权重、当前 Sidebar view、固定尺寸和隐藏态须保留。
- 位置写入现有根布局 JSON；不改 `LayoutStore` 的 save/load API。旧 JSON 无位置字段时按其 `activity` 叶子 collapsed 状态兼容解析：折叠视为 Hidden，否则为 Side。隐藏后保留叶子所在树枝；选 Side/Top/Bottom 命令须恢复可见并按目标位置重新安置。
- 注册 `workbench.action.activityBarLocation.top` / `.bottom`；保留并沿用 `.default`（Side）与 `.hide`（Hidden）。Appearance 菜单四态 checked 且命令执行后即时刷新；命令只在目标态非当前态时显示在 Command Palette。Top/Bottom 的 Tab、Enter/Space 和鼠标激活保持；方向键按水平/垂直呈现选择左右/上下，边界不循环。
