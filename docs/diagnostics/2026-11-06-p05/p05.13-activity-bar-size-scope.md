## 代码现状与边界

- 当前 `defaultLayout()` 的 Activity 叶子固定为 44 px；`ActivityBar` 活动项使用 20 px 图标，垂直 padding 为 10 px。根 JSON 已持久化 `activityBarLocation`，没有大小字段。
- 生产 `ActivityBar` 在被 GitNexus 大文件上限跳过的 `workbench_page.dart:16882` 装配，并由 `WorkbenchGrid` 依据 Activity 叶子的 `fixedExtent` 分配尺寸。P05.12 的 location migration 与 Workbench 更新通知可复用，但本切片只扩展大小状态，不改 ActivityBar 位置行为。
- 新增根节点 `ActivityBarSize` / `activityBarSize` Default/Compact 状态。P05.12 JSON 缺少大小字段时迁移为 Default。Side 位置下 Activity 叶子宽度为 48/36 px，活动项为 48/28 px，图标为 24/16 px。Top/Bottom 仍使用原先 44 px 横向高度，不应用 Compact 密度；大小元数据继续保留，切回 Side 后恢复对应宽度。
- 在 Side ActivityBar 区域提供右键 `Activity Bar Size` 级联子菜单，Default/Compact 两项按当前布局显示 checked；选择后即时更新并持久化。该操作保留当前 view、sidebar 折叠态、Editor 分割树与 Panel/Editor 权重。Top/Bottom/Hidden 不显示 Size 子菜单。
- 本切片只向 ActivityBar 上下文菜单加入 Activity Bar Size 子菜单；Activity Bar Position 子菜单、Toggle Primary Side Bar Position/Visibility、排序拖放、徽标、Accounts/Manage 和 Command Palette 注册不在范围内。Top/Bottom 水平条及位置/持久化行为不改。
