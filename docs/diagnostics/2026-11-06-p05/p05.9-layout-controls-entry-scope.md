## 范围

1. 只在 custom chrome 中显示标题栏布局控制按钮；native chrome / macOS 原生菜单栏不重复绘制。
2. 按钮有明确 Tooltip、Semantics label/hint 和 Tab 焦点；点击、Enter、Space 可开关菜单。菜单使用 Flutter 原生菜单键盘模型；方向键导航、Escape 关闭并回到触发按钮。
3. 菜单仅包含当前已实现的 view.toggleSidebar 与 view.togglePanel；启用/可见性跟随 CommandService，两项在当前 Workbench 中均有效。
4. 菜单项显式呈现当前侧栏/面板开关状态；状态从 WorkbenchLayout.isCollapsed() 读取，打开菜单时反映最新布局，不为每次 divider 拖动添加常驻 listener 或轮询。
5. 两项使用既有 CommandService.execute，不复制或更改布局切换语义。窗口标题、Command Center、菜单 mnemonic、拖动区与窗口控制保持可用。
