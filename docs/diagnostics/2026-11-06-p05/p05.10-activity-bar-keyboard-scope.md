## 当前实现

`app/lib/workbench/activity_bar.dart` 中 `ActivityBar` 为无状态 Widget，绘制 Explorer、Search、Outline、Source Control 四项，点击经 `onSelectView` 回调；高亮由 `activeView` 与 `sidebarCollapsed` 决定。动作项使用 Tooltip/InkWell，没有显式按钮/选中语义、受控方向键焦点移动或独立 widget 测试。底部 Manage 是禁用占位。

## 本切片验收

1. 四个已实现视图项均能以稳定、唯一的可访问名称呈现为按钮；选中语义与现有视觉状态一致（仅当侧栏展开且该视图活动时选中）。侧栏折叠时不报告任何视图项选中。
2. Tab 按 Explorer、Search、Outline、Source Control 的显示顺序进入和遍历四个可用项；禁用 Manage 占位不进入顺序。
3. 上/下方向键只移动焦点、不执行动作，并在首尾循环；Enter 与 Space 各自激活焦点项，调用既有 `onSelectView` 路由一次。
4. 鼠标点击路由、视觉状态和 workbench 装配保持现状。添加独立 `activity_bar_test.dart` 覆盖上述语义、展开/折叠状态、键盘焦点/激活和点击行为。
5. 完成 Rust/Dart 格式与静态检查、本地完整 `bash init.sh`，更新 `feature_list.json` / `progress.md` / `session-handoff.md`；提交前执行 GitNexus `detect-changes` all-scope 与 compare-to-main，保留所有 `UNKNOWN`、高风险与图谱覆盖限制。推送后等待 PR CI；此 UI 切片依现有计划使用 Linux/Windows/macOS Intel x64 Platform Availability。
