## 固定参考事实

- 固定版本 `fileActions.contribution.ts` 将 File 菜单按 `1_new`、`2_open`、`4_save`、`5_autosave`、`6_close` 分组：Save、Save As 位于 `4_save`；Revert File 位于 `6_close`。`workspaceActions.ts` 将 Open Folder 放在 `2_open` 的第 2 项；`windowActions.ts` 在同组注册 Open Recent 子菜单。[fileActions.contribution.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/files/browser/fileActions.contribution.ts)、[workspaceActions.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/actions/workspaceActions.ts)、[windowActions.ts](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/actions/windowActions.ts)
- 现有 Alula 注册的 File 命令为 `file.openFolder`、`file.save`、`file.saveAs`、`file.revert`、编码操作、EOL 选择及 compare 命令。只有打开文件夹、保存、另存为和磁盘还原属于此菜单可映射的默认动作；New Text File、Open File/Workspace/Recent、Save All、Auto Save 和 Close 动作尚未实现，不得以无处理器菜单占位。
- Encoding/EOL 与 Compare 命令保留其已有命令面板/快捷键入口，不在本切片的 VS Code 默认 File 菜单中呈现。File 菜单顺序为 Open Folder、分隔、Save、Save As、分隔、Revert File。Revert 在活动文档有磁盘路径时可见；Save/Save As 在活动编辑器存在时可见，并继续由 CommandService 决定是否可执行。
- 唯一生产菜单装配点在超大文件 `app/lib/workbench/workbench_page.dart:16656–16718`；命令注册和上下文同步也位于该文件。Focused widget 集成在 `app/test/widget_test.dart`；递归菜单渲染在 `app/lib/workbench/title_bar.dart`。
