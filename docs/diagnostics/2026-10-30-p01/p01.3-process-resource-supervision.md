# P01.3 进程监督与资源状态

日期：2026-10-30

## 交付范围

- 新增 `editor-process` crate，统一登记受监督的进程，按需枚举进程树及 RSS，并可按进程类型结束树。RAII 子进程句柄在 Rust 侧负责回收；工作区/外部子进程可登记与注销。
- `editor-lsp` 将 LSP 服务子进程接入监督器；Dart Git 与搜索进程通过 ABI 注册，结束后注销。
- ABI 升至 v7。Dart bridge 提供资源压力采样、进程树快照和子进程登记接口。
- 资源状态按需采样，不设置常驻 OS 监视线程。工作台有工作区时立即采样并每 30 秒刷新状态栏。
- Critical 转换取消待处理补全并回收 Search 进程树；Git 修改命令不因压力被中断，编辑和保存入口不依赖压力状态。
- Warn/Critical 状态带恢复滞回；资源回收范围以明确登记的进程类型为界。
