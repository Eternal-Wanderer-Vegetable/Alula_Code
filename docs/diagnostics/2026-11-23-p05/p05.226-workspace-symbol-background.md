# P05.226 / feat-278 · 工作区符号后台打开

工作区符号复用 QuickInput 的右方向键和中键后台接受入口。右方向键在查询末尾接受，选择查询文本时先收起选区。普通后台接受在当前组保留目标，修饰键可在右组保留目标。后台打开定位到已校验范围的起点，选择器持续保留查询、候选和输入焦点。普通确认仍关闭选择器并聚焦目标。未向 rust-analyzer 提交文档文本时，磁盘 UTF-8 BOM 计入首行的服务端位置。选择器记住查询发出时的文档文本来源，按该来源换算 UTF-16 列。[固定版工作区符号后台接受](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/search/browser/symbolsQuickAccess.ts#L73-L75) · [固定版方向键入口](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/platform/quickinput/browser/quickInputActions.ts#L230-L247)
