# P05.230 / feat-282 · 面包屑选择器跟随所选段

文件、目录和符号选择器使用所属编辑组的当前所选段。先根据已有滚动逻辑换算选中段即将到达的位置，再把可见部分换算到弹层坐标系。固定版选择器从所选节点取坐标，垂直间距为 8。[固定版 Code-OSS 实现](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/browser/parts/editor/breadcrumbsControl.ts#L676-L705)

旧版控件测试中，右组所选段的左边为 1519.76，选择器首行的右边为 176.0。新的回归检查覆盖左右组鼠标和键盘锚点，以及长路径中需要先横向滚入的段。
