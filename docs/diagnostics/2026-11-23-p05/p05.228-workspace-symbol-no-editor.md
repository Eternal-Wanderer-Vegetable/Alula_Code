# P05.228 / feat-280 · 无活动编辑器时搜索工作区符号

固定版从工作区的符号提供程序请求候选。旧构建关闭最后一个编辑器后，Ctrl+T 显示没有可用的提供程序，即使 rust-analyzer 仍在运行。Linux 原生夹具在前置产品 219f1062 上复现。[固定版工作区符号请求](https://github.com/microsoft/vscode/blob/4bda7217fc83e8e838b1edd9ebaf21bb9b498c7e/src/vs/workbench/contrib/search/browser/symbolsQuickAccess.ts#L116)

语言服务启动时登记一个与工作区同寿命的空请求文档。Ctrl+T 优先使用已挂接的活动文档，空编辑区使用该请求文档。切换工作区或退出时释放请求文档，延迟启动和请求结果同时检查工作区代次。该文档最多一个，仅用于请求，编辑器组、会话与诊断轮询仍以可见文档为来源。
