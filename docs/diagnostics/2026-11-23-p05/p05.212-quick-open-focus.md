# P05.212 / feat-264 · 空工作台 Quick Open 前台确认焦点

P05.210 在关闭所有编辑器后观察到，从 Quick Open 普通确认可以打开文件，但编辑器未取得焦点。此次将无位置后缀的前台确认接入现有布局后聚焦路径。右方向键后台打开继续保留选择器输入焦点。[P05.210 观察](p05.210-goto-without-editor.md)

- Windows 11 125% DPI 实机与 Linux Xvfb + xfwm4 各通过 11 个原生观测点。从空工作台按 Ctrl+P，按文件名查询并按 Enter，文件打开后直接获得编辑器焦点。右方向键打开第二个文件时输入框仍获焦，随后普通确认复用已打开文档并将焦点交给编辑器。重开选择器后按 Escape 恢复编辑器焦点。两份测试文件的 SHA-256 前后一致，编辑器全文与 Rust 权威全文一致。[原生记录](p05.212-quick-open-focus/native.json)
