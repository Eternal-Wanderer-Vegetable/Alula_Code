# P03.2 Rust 按行 UTF-16 地址查询

日期：2026-10-30

状态：完成

阶段：P03 / feat-025 编辑器输入与绘制

范围：ABI v13 新增 Rust 行号到绝对 UTF-16 起点的查询，供可视区分页定位；不修改工作台控件。

## 实现

- `TextBuffer::line_offset_utf16` 使用 Rope 的 `line_to_char` 和 `char_to_utf16_cu` 直接查询 0-based 行首，不扫描或物化前序文本。
- `DocRegistry::line_offset_utf16` 提供文档级访问；新增 FFI `alula_doc_line_offset`，响应同一快照的版本、全文 UTF-16 长度、行数、行号和行起点。
- Dart `AlulaDoc.lineOffset` 包装查询并同步 Rust 快照版本。越界行返回 `InvalidLine`；Dart 入口对负行号抛 `RangeError`。
- ABI v11→v12 的范围读取保留；本切片升至 ABI v13 并双侧握手。没有 Dart 全文扫描，也没有改变既有编辑、保存与恢复路径。
