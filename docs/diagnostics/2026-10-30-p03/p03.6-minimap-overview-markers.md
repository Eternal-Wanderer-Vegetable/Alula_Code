# P03.6 bounded minimap overview markers

Date: 2026-10-30

## Delivered

- Added a 512-marker maximum to the minimap overlay. Each marker carries the Rust document id, document version, and zero-based logical line; stale documents, stale versions, invalid lines, and local pending input are filtered before painting.
- LSP error, warning, information, and hint markers use severity colors. The currently selected workspace-search result adds one blue line marker. Marker rows map onto the full minimap height and paint in a narrow right-edge strip above the viewport outline.
- Diagnostic input inspection is capped at 4,096 entries per build and the resulting marker list at 512. A selected search marker reserves one slot when the marker limit is reached.
- The existing LSP decoration provider, `EditorRangeDecoration`, Rust text operations, IME path, and ABI v17 remain unchanged. No per-marker Rust line queries or document text scans were added.
