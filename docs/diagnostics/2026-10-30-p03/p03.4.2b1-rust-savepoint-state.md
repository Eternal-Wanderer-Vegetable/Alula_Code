# P03.4.2b1 Rust savepoint 状态合同

日期：2026-10-30
范围：P03.4.2b 的第一个基础子切片；不代表工作台接入或 P03.4.2b 完成。

## 实现

- `TextBuffer` 持有 Rust Rope savepoint 快照。Rope 根使用共享节点；标记当前已保存只复制根引用。dirty 和外部文本比较逐 UTF-8 字节精确比较，不从 Rope 物化整份 Dart/Rust `String`，也不以哈希碰撞作为相等判断。
- 支持将当前 Rope 标为 savepoint，也支持恢复 journal 时把另一份磁盘文本设为基线。两种操作都不改变编辑版本；Rust 文本回到 savepoint 时 dirty 恢复为 false。
- ABI 由 v14 升至 v15。Rust FFI 与 Dart `AlulaDoc` 双侧提供 `setSavepoint`、`markSaved`、`isDirty` 和 `savepointMatches`；未知文档有明确错误。
- UTF-16 代理对口径仍由既有 `TextOp` 应用处理；测试使用 CJK、emoji、BOM 与 CRLF 文本，并验证版本不变与精确还原。
