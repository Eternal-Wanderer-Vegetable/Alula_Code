## 本阶段实现

- 新增 UTF-16 多选编辑 formatter：把 Flutter 主光标的插入、选区替换、退格和删除同步到次级光标/选区；删除按扩展字素边界处理 emoji 和组合字符。主选区替换不会误删折叠次级光标之后的字符。
- 工作台加入 Ctrl+Alt+↑/↓、Ctrl+D、Ctrl+Shift+D、Ctrl+Shift+L、Alt+Shift+方向键列选、Esc 清除次级选择，以及 Ctrl+U / Ctrl+Shift+U 独立的光标状态撤销/重做。
- `RustTextInputField` 在现有有界输入控件中绘制次级 caret/highlight；输入 formatter 的变更继续沿 P03.4 Rust authoritative input window 提交，不创建全文 Flutter 副本。
- 支持多选复制/剪切；多光标 Ctrl+V 会在剪贴板行数等于 selection 数时按文档顺序分配各行，否则把完整剪贴板内容粘贴到每个光标/selection。行为依据固定范围的 VS Code 多光标文档（[Basic editing — Multiple selections](https://code.visualstudio.com/docs/editing/codebasics)）。每个 `OpenDoc` 保留独立 selection history，标签切换时状态分离。
