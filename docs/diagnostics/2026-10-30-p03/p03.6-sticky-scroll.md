# P03.6 Sticky Scroll

Date: 2026-10-30

## Implemented

- `editor-lang::Symbol` now includes an inclusive, 1-based `end_line`. The C JSON shape adds `end_line`; Rust and Dart ABI handshakes both move to version 19.
- The Workbench overlays up to five enclosing Rust scopes at the editor viewport top. It requires a matching document/input-window version and hides old headers while input is pending. Scope headers follow vertical scrolling; clicking one selects its definition in the owning editor group.
- Symbol lookup is debounced by 350 ms after a committed document version. Scroll updates reuse the cached symbol list and do not call FFI.
