# P03.6 LSP semantic token provider

日期：2026-10-30

## 交付范围

- LSP initialize 现在声明 UTF-16 position encoding 与 semantic-token 类型、modifier、relative format 能力；读取服务端 `semanticTokensProvider.legend`，只在其支持 full 请求时启用该 provider。
- Rust LSP client 发起可取消的 `textDocument/semanticTokens/full` 异步请求，并按 LSP 5 元组 delta 编码解码 token type 和 modifier。
- FFI 新增 start/poll/cancel 入口，ABI 从 v15 升至 v16。响应仅在原 Rust 文档版本仍有效时转换为绝对 UTF-16 范围；关闭、编辑、URI 变更、LSP 停止及工作区关闭都会取消挂起请求。单文档响应最多保留 100,000 个 token，挂起请求最多 16 个，同一文档的新请求会取代旧请求。
- 工作台按文档版本缓存 semantic tokens；仅当前已提交 Rust 文本窗口采用 semantic 结果，未支持、空结果、陈旧版本或 pending 输入继续使用现有 Tree-sitter `.rs` 回退。既有 bounded TextSpan 绘制继续保留 IME composing 下划线。
