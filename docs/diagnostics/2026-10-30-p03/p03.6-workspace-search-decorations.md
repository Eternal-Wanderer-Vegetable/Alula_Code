# P03.6 workspace-search 装饰 provider

## 实现范围

- `SearchHit` 可携带相对搜索行的 UTF-16 半开范围。Ripgrep JSON 的子命中偏移以 UTF-8 byte 表示；解析器逐 Unicode scalar 验证 byte 边界并换算为 UTF-16，越界或切开 UTF-8 code point 的范围会被丢弃。行文本保留尾随空格，只去掉搜索协议中的 LF。
- git grep 不提供子命中范围，因此绘制整条命中行作为后备。搜索后端和匹配语义未更改。
- 点击搜索结果后，工作台用 Rust `lineOffset` 定位并移动 caret。只有加载行仍与命中快照相同，且活动文档 id/version、输入窗口版本一致、没有 pending 输入时才显示装饰。文档编辑会使原装饰因版本不匹配而消失。
- provider 只构建当前有界输入窗口可见行上的范围；现有 range painter 负责将范围裁到窗口。Find 与 LSP diagnostic 装饰仍按原 provider 处理。
