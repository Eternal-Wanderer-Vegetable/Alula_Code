# P03.6 折叠后的 minimap 与 sticky scroll 视口投影

日期：2026-10-30
状态：实现与自动化验证完成；P03.6 仍待跨平台像素对照签收

## 目标

Rust scope folding 会压缩 `RustTextInputField` 的绘制行数，但 minimap viewport marker 和 sticky scope 仍按未折叠输入窗行数估算滚动位置。折叠较长 scope 后，滚动比例因此会落到错误的绝对行。

## 实现

- 用零基、左闭右开绝对文档行范围描述折叠区；嵌套/重叠/相接范围会先合并。
- `EditorDocumentLineProjection` 统一实现文档行到可见行、可见行到文档行以及窗口可见行数映射。隐藏行定位到其可见 scope header，折叠范围后的可见行保持绝对源行坐标。
- `RustTextInputField` 在文档与 Tree-sitter 符号版本一致时，报告当前所有已折叠 scope；版本过期或本地输入待提交时报告空集。Workbench 按文档实例与输入窗版本拒绝过期回调，并将同一范围列表传给 minimap 与 sticky scroll。
- Minimap 根据折叠后的输入窗可见行数投影纵向滚动比例；viewport marker 的末端使用折叠映射反算，点击/拖动仍以 Rust 文档绝对行导航，避免改变 UTF-16 输入坐标或源文本。
- Sticky scroll 复用同一 viewport projector，因此在折叠 scope 后正确选取当前包围视口的 Rust 符号。
