## 实现

- 从 Rust Tree-sitter 符号表读取 `function`、`struct`、`enum`、`trait`、`impl`、`mod` 与 `macro` 的闭合行范围。读取延迟 350 ms，并要求 Rust 文档版本与输入窗版本一致、没有 pending 文本；一次最多处理 4,096 个落在当前有界窗口内的候选符号。
- 折叠只给隐藏行的 `TextSpan` 应用透明零字号/零行高样式，关闭默认强制行高后让 Flutter 压缩这些行。TextEditingValue 与 Rust 文档仍保存完整源文本；Flutter 选择、IME composition、装饰范围和 FFI 增量继续使用原 UTF-16 偏移。
- gutter 显示可展开/折叠 disclosure，隐藏范围内不绘制行号；正文、gutter、缩进/空白、range decoration 和次级 selection 共用折叠后的 TextSpan 几何。光标、选区或 composition 进入折叠范围时展开该范围；含活动 caret/composition 的范围不能折叠。
- 折叠开关只接到 `.rs` 工作台编辑器。窗口部分落在已有折叠作用域内部时仍按源行范围隐藏当前窗口中的行；嵌套折叠和 CRLF/emoji 使用相同 UTF-16 行模型。
