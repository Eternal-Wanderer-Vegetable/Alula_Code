# P03.4.2c 原生 IME 平台证据

日期：2026-10-30。目标是在工作台已接入 Rust 权威文本与有界 Flutter 输入窗后，检查真实桌面输入法的组合、候选定位、提交、取消与焦点离开行为。测试只使用隔离的临时用户目录，不登录账户、不访问在线服务。Alula 与 Code-OSS 测试进程已退出，测试用户目录已清理。

Linux 发行构建复用了 Windows Flutter 安装已缓存的、与 lockfile 匹配的 pub.dev 包，以离线方式生成 Linux 插件链接；`app/pubspec.lock` SHA-256 未变化。测试二进制来自 HEAD `f7b6f343ac4f9b32b464bd2f931778f55a39b9c0` 加当时已有的脏工作树；此证据切片未修改产品源码。该样本是 WSLg/X11，不是原生 DRM Linux 桌面。输入回放后的首次 X11 `windowclose` 直接销毁窗口，只作为输入证据采集的 teardown，日志另存 `linux-x11-windowclose-teardown.log`；关闭路径以独立 Alt+F4 实测为准。Linux 截图裁到 Alula 窗口范围，避免包含其他前台应用内容。

## 结论与边界

Windows Alula 与固定 Code-OSS 在组合、提交、取消和失焦后原始拼音处理上相符。Linux WSLg 的 Fcitx5 产品回放也通过上述基本路径，但不能替代原生 DRM 主机验收。候选条只在普通窗口位置验证了靠近插入光标；屏幕边缘的候选窗夹取没有覆盖。WSLg 启动输出提示 DRI3 不可用，Alt+F4 关闭虽返回 0，仍出现 GLib critical 与 Flutter 隐式 view 移除告警；这不证明原生 DRM 主机或其他平台的关闭行为，留待 P03.7 资源生命周期门复测。输入几何、有界窗口、超限恢复与单槽背压由 P03.4.1/.2a/.2b 的 Dart↔Rust / Flutter fixtures 覆盖，不把这些 fixture 冒充为原生操作系统 IME 样本。

因此 P03.4.2c 记录为部分完成，P03.4 保持进行中；macOS 原生 IME 与原生 DRM Linux 仍是平台签收缺口，P03 整体不能据本报告签收。后续继续 P03.5 架构工作时保留这些平台门，不将 WSLg 或 Code-OSS 探针替代品作为完成证据。此阶段未做 500 MiB 数值优化或整机内存验收；按用户优先级，该目标仍属于 P14。
