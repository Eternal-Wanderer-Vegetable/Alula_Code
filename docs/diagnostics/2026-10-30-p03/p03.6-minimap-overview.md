# P03.6 Rust-backed minimap overview

日期：2026-10-30

## 交付范围

- Rust TextBuffer 新增独立 minimap sample API，ABI 升至 v17。每个快照均匀覆盖文档首尾，最多 512 个代表行；每行只返回最多 48 个 UTF-16 单元的标量安全前缀，并附完整行长度、文档总 UTF-16 长度、行数和版本。Rust 从 Rope 读取行，不物化全文。
- Dart FFI 校验 ABI 与采样上限；Rust/Flutter 同步版本号。请求返回的样本若与当前文档/输入窗口版本不一致则丢弃。文本变更后 120 ms 合并刷新，不在每次绘制或滚动中轮询。
- 工作台在编辑区宽度至少 720 logical pixels 时显示固定宽度 minimap；较窄编辑区隐藏它以保留正文输入空间。中性线条条带显示采样文本长度和缩进；点击/拖动按纵向比例定位绝对行，并通过 Rust lineOffset 与已有工作台 selection/窗口重定位路径跳转。
- viewport marker 根据当前 Rust 有界输入窗口的起始行数、逻辑行数和 ScrollController 的 scroll fraction 映射；地图和编辑器共享每文档滚动控制器。未更改 Rust TextOp、输入窗口、IME composition 或语义/诊断 range 协议。
