# P03.6 编辑器绘制系统阶段记录

日期：2026-10-30
状态：in-progress（基础绘制层已接入；P03.6 其他 renderer 能力未签收）

## 本次实现

- `RustTextInputField` 新增 Rust-backed 行号 gutter。输入窗起始绝对 UTF-16 offset 通过 Rust `lineOffset` 二分定位到逻辑行；只查询行元数据，不读取或复制全文。行号随窗口、Rust 版本、滚动和当前 bounded editing value 更新。
- 新增独立 `editor_rendering.dart`：逻辑行投影保留 UTF-16 范围，CRLF 作为一个换行，尾部换行产生空末行；缩进 guides 支持 tab stop，空白标记支持 none/trailing/all。
- gutter 固定在左侧；正文绘制层使用 EditableText 的主题合成 TextStyle、TextDirection、TextScaler、输入窗文本与竖向 ScrollController。`wordWrap` 默认为关闭：按有界输入窗测量未换行宽度，把仍可多行输入的 TextField 放在独立横向滚动视口中；主 caret 越出视口时按 ScrollPosition 轴方向（含 RTL）自动显露。显式开启 `wordWrap` 时仍按正文视口宽度换行。实现没有设置单行 maxLines，因此不会启用 Flutter 单行输入 formatter 或丢失换行符。
- gutter 固定左置并且滚动坐标与正文区分离；CJK、组合字符、ZWJ emoji、RTL、CRLF、LF、超长逻辑行与编辑值更新 fixture 均执行。未扫描/复制 Rust 文档全文。
- 本次不修改 FFI ABI、Rust 文本 delta、IME composition/selection 提交合同或文档所有权；renderer 仍只观察 Flutter 有界输入窗。P03.6 剩余范围：可配置字体回退、minimap/overview、sticky scroll、折叠、行级 decorations、诊断/搜索/语义 provider 接线与跨 OS/DPI/主题的像素对照 fixture。未对新增长行测量/paint 代价做优化，归入 P14。

## 后续 wrap/横向视口子切片

- `RustTextInputField.wordWrap` 默认 false，以匹配代码编辑器默认关闭软换行；外层水平视口按 bounded input window 的实际 TextField 主题字体计算宽度，TextField 仍为多行输入并保留 LF。显式设为 true 时使用正文可视宽度换行。
- 键盘/程序 selection 移动或输入变更后，读取 `RenderEditable` 的 caret 几何并按水平 `ScrollPosition.axisDirection` 调整视口；测试覆盖 LTR/RTL。可注入独立 `horizontalScrollController`，不与垂直滚动/文档 selection 共用状态。
- 影响面为 `RustTextInputField` 上游 71 symbols / 114 processes / 20 modules / 2 direct，风险 CRITICAL；调用链仍包括有界输入 flush、IME composition、Workbench `_buildEditor` 与多选格式化。实现只增加水平视口和主题度量，没有改这些输入提交路径。

## 版本化范围装饰子切片

- 新增 `EditorRangeDecoration`，范围使用 Rust 文档绝对、半开 UTF-16 坐标，并携带 `documentVersion`。绘制只接受与当前 `RustTextInputWindow.version` 一致的装饰，再裁剪到当前有界输入窗；过期版本和窗口外范围不绘制。
- 支持背景、圆角边框和下划线。背景层绘制在 EditableText 文字下，边框/下划线在文字上；共享当前输入窗 text/style/TextDirection/TextScaler/padding 与竖向滚动坐标。API 尚未由 LSP diagnostics、搜索结果或语义 token provider 供数；这是 renderer API slice，不等于诊断 provider 已接通。
- fixture 验证绝对范围两端裁剪、文档版本失配过滤、TextPainter selection 几何与背景/下划线像素；widget fixture 验证非零窗口起点的版本化 decorations 接入有界控件。
- 变更前 `EditorTextDecorationPainter` upstream impact 为 exact CRITICAL（59 symbols、123 processes、18 modules、2 direct）；调用链包含 `RustTextInputField`、多选输入与工作台构建。本切片增加独立 range painter，并在高影响控件中挂接；Rust delta、IME、ABI 和 buffer 所有权未改。
