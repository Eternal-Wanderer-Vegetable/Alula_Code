# P03.6 编辑器绘制系统阶段记录

日期：2026-10-30
状态：in-progress（基础绘制层已接入；P03.6 其他 renderer 能力未签收）

## 本次实现

- `RustTextInputField` 新增 Rust-backed 行号 gutter。输入窗起始绝对 UTF-16 offset 通过 Rust `lineOffset` 二分定位到逻辑行；只查询行元数据，不读取或复制全文。行号随窗口、Rust 版本、滚动和当前 bounded editing value 更新。
- 新增独立 `editor_rendering.dart`：逻辑行投影保留 UTF-16 范围，CRLF 作为一个换行，尾部换行产生空末行；缩进 guides 支持 tab stop，空白标记支持 none/trailing/all。
- gutter 固定在左侧；正文绘制层使用当前 TextStyle、TextDirection、TextScaler、输入窗文本与 ScrollController，并与 Flutter TextField 的换行和竖向滚动同步。RTL fixture 校验 gutter 顺序保持在正文左侧；CJK、组合字符、ZWJ emoji、RTL 与 CRLF fixtures 均执行。
- 本次不修改 FFI ABI、Rust 文本 delta、IME composition/selection 提交合同或文档所有权；renderer 仍只观察 Flutter 有界输入窗。P03.6 剩余范围：可配置字体回退、显式 wrap/横向滚动模式、minimap/overview、sticky scroll、折叠、行/范围 decorations，以及跨 OS/DPI/主题的像素对照 fixture。
